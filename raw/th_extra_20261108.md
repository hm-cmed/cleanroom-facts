## 3. 確認できなかった点・申し送り

- **出典の重複確認**：新規候補2件（Chaker 2017、Canaris 2000）について、出典マスター（repo_current2/data/sources/sources.yaml）を DOI・PMID・著者名で検索し、これまでの納品分（ワークスペース内の納品 Markdown）も DOI・PMID で検索した。いずれも同一文献の登録は無く、両件とも新規出典として扱った（既存 SRC の再利用は発生しなかった）。Chaker 2017 は TH-仮1 と TH-仮3 の2枚で共用する（うつ病下書きで CANMAT 2023 を複数カードで共用した前例と同じ扱い）。
- **condition の書き方について**：既存 TH カードでも `condition` の形は一様ではなく、TH-005・TH-007・TH-018 は `region`＋`design`、TH-033 は `region`＋`対象` である。本下書きは前者にそろえた。登録時にスキーマ側の指定があれば付け替えること。
- **TH-仮3 と TH-018 の重複判定**：TH-018 の主張は「潜在性は顕性へ進行しうる軽度の機能障害で、治療方針は TSH の偏位の程度と併存疾患で判断する」という位置づけと方針であり、生化学的定義そのものは述べていない。TH-仮3 は顕性・潜在性の定義（TSH と遊離T4 の組み合わせ）と「定義が生化学的である理由」を主張するもので、実質重複には当たらないと判断して作成した。最終判定は登録側に委ねる。
- **浮腫を代表例に入れなかった理由**：動画側の希望例に浮腫があったが、Chaker 2017 の Table 1 では粘液水腫は頻度の低い所見（*印）として区別されていたため、TH-仮1 の「代表的な臨床像」には含めなかった。浮腫を扱う場合は、重症側の所見としての別カードか、TH-006（粘液水腫性昏睡）の範囲で扱うのが正確である。
- **Canaris 2000 の本文未確認**：TH-仮2 は抄録の範囲に限定した。各症状の頻度・感度の数値、TSH 上昇の有病率（抄録では 9.5%）など本文級の数値は、登録時に本文を照合してから必要なら別途反映すること。
- **curriculum は空欄**：kokushi・core_curriculum とも null。登録依頼文の表から、番号と同じ行の不変 id を機械的に抜き出して転記すること（既存 TH カードでは 医学各論 Ⅹ-2-A-②（甲状腺機能低下症、a）に付いた例があるが、決め打ちはしない）。
- **動画との関係**：本下書きは THY_001（作り直し版、レビュー待ち）の根拠には使わない。登録が済めば、「症状から甲状腺の病気を考える」切り口の動画（症状の列挙は TH-仮1、症状だけでは決められない点は TH-仮2、生化学的診断の基本は TH-仮3）の根拠カードとして使える。

## 3. 確認できなかった点・申し送り

- **出典の重複確認**：新規候補2件（George 2017、Penttilä 2014）と裏付け候補1件（Marshall 2005）について、出典マスター（origin/main の data/sources/sources.yaml）を DOI・PMID で検索し、ワークスペース内の過去の納品 Markdown も DOI・PMID で検索した。いずれも同一文献の登録は無く、George 2017・Penttilä 2014 は新規出典として扱った。DSM-5-TR は既存の SRC-4976 を再利用した（MD-009〜MD-017 で使われた扱いと同じ）。
- **既存 SZ カードとの重複判定**：origin/main の SZ.yaml は SZ-001〜SZ-010 の10枚。SZ-002 は診断基準Aを診断手順の枠組みとして簡潔に述べており、SZ-仮1 は症状の具体像そのものが主張で焦点が異なる。SZ-009（破瓜型）・SZ-010（緊張型）は ICD-10 亜型の臨床像であり、SZ-仮1 の DSM-5-TR 基準Aの症状像とは分類体系も主張も異なる。前駆期（SZ-仮2）と DUP（SZ-仮3）を扱う既存カードは無かった。最終判定は登録側に委ねる。
- **SZ-仮1 の書籍本文は未照合**：MD-009 の前例どおり、DSM-5-TR 本文（統合失調症の診断基準の掲載箇所）は本下書きでは直接照合しておらず、国内ガイドライン英語版（SRC-3622）の PMC 全文の診断の章で基準Aの構成と症状記述を照合した。登録時に書籍本文で最終照合すること。
- **SZ-仮2 の数値は入れていない**：前駆期の変化から統合失調症への移行率、超ハイリスク（UHR）基準の陽性率などは、総説（George 2017）の範囲では確定値として扱わず、主張に入れていない。動画や登録で数値が必要になれば、一次資料（コホート研究・メタ解析）を別途照合してから追加すること。裏付け候補として、前駆症状を陰性・陽性-前精神病・陽性-解体の3群に分類した研究（Gourzis P, et al. Schizophr Bull. 2002;28(3):415-429、PMID 12645674、抄録照合済み）も申し送る。
- **SZ-仮3 の本文未確認**：Penttilä 2014 は抄録の範囲に限定した。各転帰ごとの相関係数の内訳や感度解析の結果は、登録時に本文を照合してから必要なら反映すること。
- **curriculum は空欄**：kokushi・core_curriculum とも null。登録依頼文の表から、番号と同じ行の不変 id を機械的に抜き出して転記すること（既存 SZ カードでは 医学各論 Ⅱ-2-B-① 等に付いた例があるが、決め打ちはしない）。

# ME-002（共用試験の公的化）合格者名称の訂正パッケージ

対象：ME1 成果物（~/workspace/ME1_medical_education.md）のカード ME-002 について、合格者の呼称を現在の正式名称「臨床実習生（医学）」に改める更新パッケージ。本文書はレポジトリへ直接入れず、取り込み側の確認を経て反映する前提の raw Markdown である。

## 1. 何を・なぜ直すか

- **なぜ**：三原の指摘（2026-11-26）。「スチューデントドクター（Student Doctor）」は現在の正式名称ではなく、合格者は「臨床実習生（医学）」と呼ばれている。専門家も参照するカードなので、現行名称で正確に記す。
- **一次情報での確認**：公益社団法人医療系大学間共用試験実施評価機構（医師法に基づく指定試験実施機関）のお知らせ「令和5年度からの臨床実習前共用試験の合格判定について」（令和5年6月20日付）で、CBTとOSCEの両方に合格した医学生には合格証が届き、「臨床実習生（医学）」と記された認定証（ネームカード）を付けて診療参加型臨床実習へ進むことが明記されている。同お知らせに掲載されたネームカードのイメージ図でも、表面に「臨床実習生（医学）」と記されている（英字表記は "Clinical Clerkship Student"）。URL：https://www.cato.or.jp/cms/file.php?kubun=notice&id=3
- **何を**：assertion の「いわゆるStudent Doctorの規定」という言い方を改め、合格者の名称（臨床実習生（医学））と旧称との関係を1文で加える。uncertainty の該当箇所もそろえ、名称の確認根拠を追記する。制度の内容（共用試験の定義、第17条の2の医業、第11条第1号の受験資格、施行時期、経過措置）は変更しない。
- **変えないもの**：SRC-5103（厚生労働省 医道審議会医師分科会報告書、令和2年5月）の題名にある「いわゆるStudent Doctor」は当時の文書名そのものなので、出典表記としてはそのまま残す。ME5・ME6（歯学・薬学ほか）も確認したが、Student Doctor の語は使われておらず、今回の訂正対象は ME-002 のみ。

### 旧文と新文の対照（assertion、変更箇所のみ）

- 旧：「…医業（政令で定めるものを除く）を行うことができる（医師法第17条の2、いわゆるStudent Doctorの規定で、2023年4月1日施行）。」
- 新：「…医業（政令で定めるものを除く）を行うことができる（医師法第17条の2、2023年4月1日施行）。合格者には「臨床実習生（医学）」と記された認定証（ネームカード）が交付され、この名称で臨床実習に参加する（従来、共用試験に合格した医学生はスチューデントドクター（Student Doctor）と呼ばれていた）。」

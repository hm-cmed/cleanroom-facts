# 医療者教育（ME）第2弾・第1陣：ME-011〜019（カード9件）

依頼文（ME2_request_for_muse.md、2026-11-23登録）に基づく第2弾・第1陣の9枚。決定事項の適用は次のとおり。

- 接頭辞は ME。カード番号は ME-011〜019（ME-008 は保留中のカードのために空けてあり、本回も使わない）。区分は subdomain に書いた（制度：ME-011、評価：ME-012、教育手法：ME-013〜016、横断：ME-017〜019）。出典番号は SRC-5114〜5160 の範囲を使い、本回は新規に SRC-5114〜5123 を割り当てた（SRC-5124〜5160 は未使用）。
- 対象範囲は医療系の全職種（2026-11-23 三原の決定）。本回の9枚は医師の養成と医療専門職教育が中心であり、各カードの主張文と condition.対象 に職種を明記した。歯学・薬学・看護学の共用試験とコア・カリキュラムは第3弾（ME3）の候補として扱い、本回には含めない。
- カリキュラム欄：制度のカード（ME-011）は国試の欄を空欄とし、レポジトリ側で出題基準から付番する扱いとした。教育者向けの理論・教育手法のカード（ME-012〜017）はカリキュラム欄を空欄とし、condition.対象 を「教育者」とした。ME-018・019 は学習者・医師に関する横断テーマの根拠データであり、特定のコアカリ項目には対応づけず空欄とした。
- RESTRICTED の出典では、定義文・結論文を和訳して使わず、概念の説明は自作の文で組み立てた（依頼文の注意1。第1弾 ME-008 の保留を受けた措置）。数値はすべて抄録で確定させた（注意2）。ME-018 には自殺念慮に関する注意を uncertainty に明記した（注意3）。ME-011 の CBT の数値は資料の時点（2024年）を明記し、公的化の前後の違いを分けて書いた（注意4）。識別子は API で確認したものだけを書き、著者原稿の PMCID はライセンス区分を変えずに記載した（注意5）。
- 既存出典の再利用は ME-011 の主出典 SRC-5102（医師法）と補助の SRC-5104・SRC-5101 の3件。新規出典10件（SRC-5114〜5123）は、出典マスター全体（2,387件）と第1弾までの納品分と DOI・PMID で照合し、重複がないことを確認した。

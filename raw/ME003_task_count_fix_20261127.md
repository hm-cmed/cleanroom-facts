# ME-003（臨床実習前・後OSCE）課題数の訂正パッケージ

対象：ME1 成果物（~/workspace/ME1_medical_education.md）のカード ME-003 について、OSCE の課題数の断定を現行の実施形態に改める更新パッケージ。本文書はレポジトリへ直接入れず、取り込み側の確認を経て反映する前提の raw Markdown である。

## 1. 何を・なぜ直すか

- **なぜ**：三原の指摘（2026-11-27）。「前OSCEの課題数は必ずしも6ではない」。現行カードは「課題は6課題が必須」と断定しているが、その裏づけは日本医師会の寄稿（SRC-5104、二次資料）のみで、カード自身の uncertainty にも「実施機関（CATO）の現行の実施要項での再確認が望ましい」と残っていた。動画（ME_003）側は数字を外して対応済みで、カード側を現行制度にそろえる。
- **一次情報での確認（2026-11-27）**：実施機関である公益社団法人医療系大学間共用試験実施評価機構（CATO）の現行資料で確認した。
  - 課題構成：CATO「令和5年度からの臨床実習前共用試験の合格判定について」（令和5年6月20日付お知らせ。2026年度ガイドの附録にも収録）では、令和5年度に設定された課題は ①医療面接、②全身状態とバイタルサイン、③頭頸部、④胸部、⑤腹部、⑥神経、⑦基本的臨床手技、⑧救急 の **8課題** と明記されている。あわせて「令和7年度には、⑨四肢と脊柱の診察、⑩感染対策を加え、全10課題とすることについて検討中」とされ、厚生労働省・医道審議会医師分科会医学生共用試験部会の意見概要（令和4年5月）も「令和5年度からは8課題を実施。令和7年度までに10課題を実施することを検討」としている。実際の運用では四肢と脊柱・感染対策を加えるかどうかは大学により、課題数は一律ではない（厚生労働省の実施状況資料では、2023年度は8課題71大学・9課題3大学・10課題8大学、2024年度は8課題69大学・9課題2大学・10課題11大学：二次資料経由で確認）。
  - 試験時間：CATO「2026年度医学生共用試験臨床実習前OSCE学修・受験ガイド」の試験実施手順に「試験時間は、医療面接は10分、その他の領域は5分です」と明記されている。**時間の記述は現行カードのままで正しい**。誤りは課題数のみ。
  - 「6課題」の由来：公的化前の実施形態では基本6ステーション（医療面接、頭頸部、胸部・全身状態とバイタルサイン、腹部、神経、基本手技・救急）とされていた時期があり（2019年の医道審議会医師分科会への CATO 提供資料）、日医寄稿の記述はこの時期の実施形態に基づくとみられる。2023年度の公的化に伴い8領域に再編された。
  - 臨床実習後OSCE：CATO「2026年度医学生共用試験臨床実習後OSCE学修・受験ガイド（機構課題）」で、機構課題は35の症候から作られ、医療面接と身体診察で12分、情報整理と指導医への報告で4分の計16分を1つの試験室で行うこと、大学独自課題が併施されることを確認した。課題数の基本形と実績は、厚生労働科学研究費補助金総合研究報告書「Post-CC OSCEを国家試験化するにあたっての妥当性・信頼性・公平性等の検証に関する研究」（21IA2010、CATO 理事長らが研究代表・分担者）によれば、機構課題3課題＋大学独自課題3課題程度の6課題が基本形で、大学独自課題の数と内容は実施大学の自由とされた。2023年度の実績では、機構課題を実施した81大学の内訳は3課題66大学・2課題12大学・1課題3大学で、大学独自課題は1〜13課題と幅があった。したがって現行カードの「大学の独自課題1〜3課題」という範囲の断定も実態に合わない。
- **何を**：assertion の Pre-CC OSCE の課題数の文を現行の構成（8領域が基本、大学により最大10領域、課題数は一律でない）に差し替え、Post-CC OSCE の課題数の文を基本形＋大学の自由という形に改める。corroboration を日医寄稿から CATO 現行資料への参照に差し替え、uncertainty の「再確認が望ましい」を確認済みの記録に改める。
- **変えないもの**：制度の位置づけ（共用試験の公的化、臨床実習開始の可否の判定、Post-CC OSCE は共用試験に含まれず卒業判定の資料）、主出典（SRC-5103、厚生労働省 医道審議会医師分科会報告書、令和2年5月）、region・対象、curriculum、publication_info。SRC-5104（日医寄稿）は出典表からは外さず、corroboration での役割を終えたものとして扱いは取り込み側に委ねる。

### 旧文と新文の対照（assertion、変更箇所のみ）

- 旧（Pre-CC）：「課題は6課題が必須で、医療面接（10分）と、その他の課題（各5分）からなる。」
- 新（Pre-CC）：「課題は、医療面接、全身状態とバイタルサイン、頭頸部、胸部、腹部、神経の身体診察、基本的臨床手技、救急の8領域が基本で、四肢と脊柱の診察と感染対策を加える大学もあり、実施される課題数は大学によって8〜10領域と異なる。試験時間は医療面接が10分、その他の領域は各5分である。」
- 旧（Post-CC）：「実施機関が用意する3課題に各大学の独自課題1〜3課題を加えて実施され」
- 新（Post-CC）：「実施機関が作成する機構課題3課題を基本に、各大学が独自に作成する課題（3課題程度が目安とされるが、数と内容は各大学の自由）を加えて実施され」

## 3. 検証結果

- 課題数（8領域が基本、大学により8〜10領域）と時間（医療面接10分・その他5分）は、CATO の現行公式文書（2026年度学修・受験ガイド本文と、その附録の令和5年6月20日付お知らせ）で直接確認した。旧版の「6課題が必須」は現行制度では成り立たない。
- 臨床実習後OSCE は、CATO の2026年度ガイド（機構課題）で機構課題の構成（35症候、12分＋4分）と大学独自課題の併施を確認し、課題数の基本形と実施実績の幅は厚生労働科学研究の総合研究報告書（21IA2010）で確認した。
- 現行カードとの差分は、assertion の課題数の2文、corroboration の差し替え、uncertainty の末尾の確認記録のみ。主出典（SRC-5103）、region・対象、curriculum、publication_info は現行と同一。
- provenance に locator なし、ライセンス3欄の欠落なし、differential／common_misconception は null。差し替え後カードの YAML はパース確認済みで、現行カードとの差分は上記3フィールドのみであることも機械照合した。

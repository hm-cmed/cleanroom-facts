## 3. 重複を避ける範囲

- 深部静脈血栓症は循環器 VS で作成済み。呼吸器では肺血栓塞栓症だけを扱う。
- 睡眠時無呼吸と高血圧は HT-016 で作成済み。
- 結核・インフルエンザ・COVID-19 は感染症（Ⅻ）、血管炎・膠原病は Ⅺ、悪性リンパ腫は Ⅶ と重なる。呼吸器では肺の病変に絞る。
- 小児の呼吸器疾患（細気管支炎を除く）は小児（Ⅰ）で扱う。

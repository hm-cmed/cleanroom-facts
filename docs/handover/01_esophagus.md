## 3. 決定事項

1. **タグを2つに分ける。** `basis_tag` を `legal_basis`（SOPの利用根拠A〜G）と `source_class`（出典ライセンス）に分ける（CLAUDE.md 第2節）。
2. **ライセンスの判定は Crossref の license 欄を正とする。**
   - Elsevier の OA 論文でも、CC の表示がなければ RESTRICTED とする。
   - Baveno VII と JGES 食道ESD/EMR GL は RESTRICTED とする。
3. **PMID は、APIで照合できたものだけを書く。** 記憶由来の候補は全件削除済み。
4. **欠番は作らない。** 出典が取れなかった次の7件は、第7回後の「欠番補完ラウンド」でまとめて扱う。
   - ES-076：裂孔ヘルニア

   - ES-078：カンジダ食道炎
   - ES-082：Plummer-Vinson症候群

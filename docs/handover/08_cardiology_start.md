## 3. 重複を避ける範囲

- 肺血栓塞栓症は呼吸器（Ⅳ）で扱うため、循環器では扱わない。深部静脈血栓症は VS で扱う。
- 腸間膜動脈閉塞症・NOMI は消化器（AB）の範囲。
- 消化器の抗血栓薬関連（低用量アスピリン潰瘍：GD、抗血栓薬の再開：UG・IN）は扱い済み。循環器では、抗血栓療法そのものの適応・選択を扱う。

# 医療者教育（ME）第2弾・第2陣（6枚）の作成依頼

依頼者：三原弘（2026-11-23）。第1弾・第2弾第1陣と同じ形式で、カード本文・出典表・未解決事項・引き継ぎメモを1つの Markdown（ME3_medical_education.md）にまとめてください。

## 前提

- 接頭辞は ME。カード番号は ME-020 から振る。ME-008 は保留中のカードのために空けてあるので使わない。出典番号は SRC-5124〜5160。
- 対象範囲は医療系の全職種（2026-11-23 三原の決定）。カードごとに、主張文と `condition.対象` に職種を書く。
- カリキュラム欄の扱いはこれまでと同じ。
  - 教育者向けの理論・教育手法は、カリキュラム欄を空にし、`condition.対象` を「教育者」とする。
  - 日本の制度（専門医制度、マッチング）は、国試の欄を空にしてよい。番号はレポジトリ側で付ける。
  - 学生が学ぶ内容（患者安全、多職種連携）には、コアカリ第1層の不変 id を付ける。レポジトリに登録されている 2022年版コアカリの第1層 CSV で id を確かめる。

## 作り手への注意

1. **定義文・結論文を和訳して使わない。** 概念の説明は、自分の言葉で組み立てる。数値・方向性・概念名は使ってよい。
   - **ME-025 の IPE の定義：** 「互いについて・互いから・互いと共に学ぶ」は、英国の CAIPE の定義に由来する有名な定義文である。主張文にはこれを訳して入れない。IPE が何を指すかは自分の言葉で説明し、定義の出どころ（WHO の枠組みが CAIPE の定義を採用していること）は `uncertainty` に書く。
   - **ME-024 の 11 のトピック：** トピック名を概念名の並びとして挙げるのはよい。各トピックの説明文は訳さない。
   - **抄録の要約の書き方：** 抄録の結果の部分を、順番どおりに一文ずつ日本語にするまとめ方は避ける。第1陣の ME-014・ME-017 は、監修のときに表現を確かめる扱いになった。必要な事実（研究数、効果の方向、条件）を選び、自分の構成で書く。
2. **数値は一次資料で確定させる。**
   - ME-020：基本領域の数、新制度の開始年、専門医の更新の周期。
   - ME-021：マッチングの参加者数などの数値を書く場合は、年度を書く。
   - ME-022・ME-023：統合した研究数と、報告された効果の方向。
3. **ME-021 のアルゴリズム：** 「受入保留方式（Gale–Shapley）」は概念名として書いてよい。どちら側が申し込む形か（研修希望者側か病院側か）を書くときは、公式資料で確かめた範囲に限る。
4. **識別子（PMID・DOI・PMCID・ISBN）：** API や公式の登録情報で確かめたものだけを書く。
5. **YAML の書き方：** 値に「 #」が入る場合は、値全体を引用符で囲む。
6. **既存の出典との重なり：** 出典マスター（SRC-5101〜5123 を含む）と重ならないことを確かめる。重なる場合は、既存の SRC 番号を再利用する。

# 第15〜19回（腎・泌尿器・生殖器）調査の依頼文

作成：Claude Code（2026-10-28）。消化器・循環器・呼吸器の取り込みと、第14回の試行（2つの作り手の比較、`reports/trial_eval_14_result.md`）で見つかった点にもとづく。

## 使い方

1. この分野は、主に **Muse に第15回から順に**作ってもらう（少しずつ進めてよい）。claude.ai の事実票 Project のチャットで作ってもよい。
2. 下の「---」から下の全文を貼り、最後に「**今回は第15回です**」のように回の番号を書き足して送る。1回分を何度かに分けて作る場合も、ID と SRC 番号はその回の範囲の続きから使う。
3. 返ってきた成果物を `15_ku_a.md`（第15回）、`16_ku_b.md`、`17_ku_c.md`、`18_ku_d.md`、`19_ku_e.md` という名前にして Claude Code に渡す。
4. Claude Code は取り込む前に **受け入れ検査**（`python scripts/accept_round.py <成果物> --spec docs/tasks/specs/round15.yaml`）を行う。「差し戻し」のときは、検査結果の「差し戻しの内容」をそのまま作り手に渡して直してもらう。
5. 合格したら取り込み、カードのない小項目と未解決事項の一覧を出す。その抜けを Claude が三原の確認のもとで補完する。

## 1-2. 作り手への追加の注意（第14回の試行で見つかった点）

2つの作り手を比べた試行で、次の点が取り込み側の手間になりました。受け入れ検査でも確認します。

1. **論文の出典には、DOI と PMID を必ず書いてください。** 有名な試験（大規模 RCT など）ほど DOI・PMID は簡単に確認できます。調べても確認できなかったときだけ空欄にし、出典表の「確認経路」にその理由を書いてください。
2. **薬の名前が出るカードには、`uncertainty` に国内の承認・保険適用の確認状況を書いてください**（例：「国内承認は PMDA の添付文書で確認」「国内の適応は未確認」）。
3. **ライセンスは、Crossref の license 欄または出版社ページで CC BY と確認できたら `OPEN` にしてください。** 確認できないものは `UNKNOWN` で構いませんが、BMC・Frontiers・PLOS など CC BY の雑誌を `UNKNOWN` のままにしないでください。CC BY-NC・ND は `RESTRICTED` です。
4. **`condition.region` は全件に書いてください**（日本・米国・欧州・国際など）。日本と海外で基準や推奨が違う点（CKD の重症度分類と eGFR 式、尿路感染症の抗菌薬、PSA 検診、子宮頸がん検診と HPV ワクチンなど）は、地域ごとに別のカードにしてください。
5. 成果物には、作成に使ったツール名・モデル名・サービス名を書かないでください。

## 2. 出力形式（これまでの取り込みで実際に問題になった点）

1. **YAML の中に脚注番号（[1] など）を入れないでください。** 出典の対応は provenance と、YAML の外の表で示してください。
2. **アンカー（&）とマージキー（<<:）は使わず、全件を展開形で書いてください。** YAML ブロックは1つにしてください。
3. 仮ID（GN-R01 など）は作らず、最初から最終IDで書いてください。
4. 各カードの `provenance.source_ref` に SRC 番号を入れてください。
5. `legal_basis` と `source_class` の2欄で書いてください（`basis_tag` は使わない）。
6. `status` はすべて `draft`、`verifier` は `null` にしてください。`verified_sources` への昇格は、リポジトリ側で API 照合した後に行います。
7. 主張文に「（要確認）」などの括弧書きを入れないでください。不確かな点は `uncertainty` に書いてください。
8. **`curriculum` 欄は必ず埋めてください。** 番号は第7節の表から選び、表にないものは推測せず `null` にしてください。KX のうち各論に当てはまらないもの（症候・検査・透析・移植など）は `kokushi: null` とし、コアカリは別表2-8・2-9 の番号を使ってください。循環器・呼吸器では、この方式でほぼ全件に番号が付き、問題作成の配分計算に使えました。
9. `subdomain` には、第7節の表の大項目名か中項目名（例：「膜性腎症」「前立腺癌」）を入れてください。

## 3. 内容の確認（これまでの照合で見つかった誤りの傾向）

- **二次資料から写した数値が一次資料と違っていた。** 数値は一次資料（抄録か本文）で確認できたものだけを書き、確認できなかったものは `uncertainty` に「二次資料経由」と書いてください。
- **ガイドラインの本文にない記述が、そのガイドラインを出典として書かれていた。** ガイドラインを出典にするときは、その版の本文に書いてあることだけを書いてください。推奨の強さ・エビデンスレベルは、その版の表記どおりに書いてください。
- **1枚のカードに2つの文献の識別子が混在していた。** 1枚のカードの識別子は1つの文献にそろえてください。
- **表から読み取った数値**（重症度分類の基準値、病期分類、薬の用量など）は、`uncertainty` に「表から読み取り」と書いてください。
- **新しい版が出ていないか確認してください。** その分野の最新版を出典にし、旧版を使う場合は理由を `uncertainty` に書いてください。

## 4. 抽出元の候補とライセンスの目安

- **日本腎臓学会（JSN）・日本透析医学会・日本泌尿器科学会・日本産科婦人科学会・日本婦人科腫瘍学会・日本生殖医学会などの診療ガイドライン**：学会の著作物と考えられるため、表示を確認し、CC の表示がなければ `RESTRICTED`（数値と方向性だけを自作文で使う）。英語版が Clinical and Experimental Nephrology、International Journal of Urology、Journal of Obstetrics and Gynaecology Research などに掲載されている場合は、DOI のある英語版を出典にし、その license 欄を確認してください。
- **KDIGO、EAU、AUA、ACOG、ESHRE、NCCN などの海外ガイドライン**：通常は `RESTRICTED`。CC BY の表示があるものだけ `OPEN`。
- **主要 RCT・コホート研究**：CC BY の OA 論文は `OPEN`、それ以外は `RESTRICTED`。
- **国内統計**：厚生労働省の人口動態統計・患者調査、国立がん研究センターのがん統計（利用規約を確認）、日本透析医学会の統計調査（表示を確認）、日本産科婦人科学会の ART データブック（表示を確認）。
- **米国政府資料**：NIDDK、CDC、NCI PDQ など（`GOV_US`。PDQ は利用条件を確認する）。

抽出元にしないもの：教科書、UpToDate などの商用二次資料、問題集、国試過去問の文章、ニュースサイト。

## 2. 分割案の未決事項（§4）への回答

1. 接頭辞・番号帯：上のとおり。レポジトリで確かめたところ、EB は未使用でした。10件の DOI も出典マスターに登録がなく、方法論のカード（PICO、GRADE、PRISMA、RoB 2、p値、患者市民参画など）もありませんでした。
2. **Cochrane Handbook**：区分は RESTRICTED にしてください（© The Cochrane Collaboration）。章ごとに CC 表示がないかを確かめ、あれば区分を書き換えてください。uncertainty に、版（例：version 6.x）、章番号、参照した日を書いてください。
3. **識別子のない出典**（Richardson 1995、NIHR の文書）：題名・発行者・年・URL で登録してかまいません。PMID と DOI は null にしてください。
4. **ASA 声明**：登録してかまいません。ライセンスは、Crossref の license と出版社のページで確かめてください。
5. **GRADE Handbook**：主出典は、版が固定された論文にしてください（BMJ 2008、J Clin Epidemiol の GRADE guidelines シリーズ、BMJ 2016 の EtD）。Handbook は corroboration にとどめ、版（更新年月）を書いてください。
6. 依頼単位：12件を1回。
7. 動画との対応：上の §1-5 のとおり。

## 3. 作成の前に直す・確かめる点（レポジトリ側の検討より）

1. **EB-002「唯一の割付方法」**：言い過ぎのおそれがあります。出典に書かれている範囲に限ってください。また、RoB 2 の論文は「無作為割付がなぜ交絡を均すか」の説明の出典としては弱いです。割付の仕組みを説明している方法論の資料を主出典にしてください。CC BY のものがあれば優先してください。
2. **EB-003**：ASA の6原則は、原文の訳にならないよう、要点を自分の言葉で書いてください。原則の文をそのまま並べないでください。
3. **EB-007**：「合計点を付けない」は、RoB 2 の論文か公式文書にそう書かれていることを確かめてください。判定の3段階（low／some concerns／high）は、概念名として書いてかまいません。
4. **EB-008**：BMJ 2008 の GRADE の論文は、CC BY でない可能性が高いので、ライセンスを確かめてください。2008年の論文では "quality of evidence" と呼んでいましたが、現在は "certainty of evidence" と呼びます。この違いを uncertainty に書いてください。上げる要因を書く場合は、出典で確かめてください。下げる要因と上げる要因で1枚が過密になる場合は、分割案 §3 のとおり2枚に分けてかまいません。その場合は EB-013 として足し、§5 に書いてください。
5. **EB-010**：EtD の判断項目は、論文の表にあるものを過不足なく書いてください（分割案の要旨では、望ましい効果と望ましくない効果、利益と害のバランス、費用対効果などが分かれていません）。表そのものは写さないでください。
6. **EB-011「参画の評価は参加の有無ではなく、どの決定がどう変わったかで見る」**：解釈を含む書き方です。GRIPP2 の項目に書かれている範囲に限ってください。
7. **EB-012**：INVOLVE は2020年に NIHR の別の組織に引き継がれています。現行の NIHR の文書を主出典にし、元の INVOLVE の定義との関係を uncertainty に書いてください。NIHR の文書のライセンス（英国の Open Government Licence かどうかなど）は、確かめるまで UNKNOWN にしてください。日本の文脈の裏づけとして、日本医療研究開発機構（AMED）の「患者・市民参画（PPI）ガイドブック」が使えるかを確かめてください。区分は AMED のサイトの利用規約で判断してください。
8. **BMJ の論文のライセンス**：CC BY 4.0、CC BY-NC 4.0、CC 表示のない無料公開のどれもありえます。RoB 2（2019）、PRISMA 2020、GRIPP2（2017）、EtD（2016）、GRADE（2008）は、1件ずつ Crossref の license と論文のページで確かめてください。CC BY-NC は RESTRICTED です。
9. **EB-006**：見落としの数値は、論文の本文で確かめてから書いてください。

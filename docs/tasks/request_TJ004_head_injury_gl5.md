# 依頼（Muse 向け）：『頭部外傷治療・管理のガイドライン第5版』で TJ-004 を作り直す（2026-11-11）

- 背景：TJ-004 は「第4版（2019）が現行の標準」と主張しているが、作り手の調査バッチ8で第5版（2026-10-12、医学書院、ISBN 978-4-260-06661-7）の刊行が分かった。三原の承認により、第5版で新しいカードを作り、TJ-004 は廃止する。
- お願い：
  1. 第5版の書誌（正式書名、監修・編集、刊行年月日、ISBN、版元）を、版元・NDL などの一次情報で確認する。
  2. 新カード1枚の下書き（ID は仮表記）：第5版が現行のガイドラインであること、重症度の評価（GCS による軽症・中等症・重症の区分）が第5版でどう定められているか。第4版から重症度の定義が変わっていれば、それも書く。本文を確認できない部分は推測せず uncertainty に書く。
  3. 第5版で TJ-001〜TJ-010 など頭部外傷の既存カードに影響する変更（推奨の向き・閾値の変更）が分かれば、一覧にする。

### 1-2. 作り手への追加の注意（これまでの回で見つかった点）

2つの作り手を比べた試行で、次の点が取り込み側の手間になりました。受け入れ検査でも確認します。

1. **論文の出典には、DOI と PMID を必ず書いてください。** 有名な試験（大規模 RCT など）ほど DOI・PMID は簡単に確認できます。調べても確認できなかったときだけ空欄にし、出典表の「確認経路」にその理由を書いてください。
2. **薬の名前が出るカードには、`uncertainty` に国内の承認・保険適用の確認状況を書いてください**（例：「国内承認は PMDA の添付文書で確認」「国内の適応は未確認」）。HIPEC・ペメトレキセド（腹膜中皮腫）など、海外で使われていても国内で適応外の治療は、その旨を書いてください。添付文書の効能文言をそのまま根拠にしてください。
3. **ライセンスは、Crossref の license 欄または出版社ページで CC BY と確認できたら `OPEN` にしてください。** 確認できないものは `UNKNOWN` で構いませんが、BMC・Frontiers・PLOS など CC BY の雑誌を `UNKNOWN` のままにしないでください。CC BY-NC・ND は `RESTRICTED` です。
4. **`condition.region` は全件に書いてください**（日本・米国・欧州・国際など）。日本と海外で基準や推奨が違う点（薬剤の承認と保険適用、降圧目標、ガイドラインの版など）は、地域ごとに別のカードにしてください。
5. 成果物には、作成に使ったツール名・モデル名・サービス名を書かないでください。
6. **出題基準・コアカリの番号は、必ず第7節の表からそのまま写してください。表にない番号を作らないでください。** 当てはまる項目がなければ `kokushi: null` で構いません（第19回で、表にない番号を組み立てたため差し戻しになりました）。

8. **コアカリの不変 id は、番号と同じ行から写してください**（第20回で、表の隣の行の id を写した例がありました）。出典表を出す前に、表の中に同じ DOI が2回出ていないかも確かめてください（第20・21回）。
9. **StatPearls（NCBI Bookshelf の解説書）は二次資料として扱い、原則として出典にしないでください。** 一次資料（原著論文、診療ガイドライン、系統的レビュー、公的資料）がどうしても見つからないときだけ補助的に使ってよく、その場合は `uncertainty` に「二次資料経由（StatPearls）」と書いてください（2026-10-28 の決定。受け入れ検査で件数を数えます）。
10. **出典の既存判定は、現行の出典マスター全体（SRC-4145 まで、第57回の納品分を含む）で行ってください。** 出典リサーチのスナップショット（SRC-2202 まで）だけで判定すると、第38回以降の出典に新しい番号を付けてしまいます（第53回で起きかけた例）。
11. **最後に番号を振り直したら、「未解決事項」と「次回への引き継ぎ」の中の ID・SRC 番号も合わせて直してください。** 第44・45・50回で、下書きの段階の番号が残っていました。

## 3. 内容の確認（これまでの照合で見つかった誤りの傾向）

- **二次資料から写した数値が一次資料と違っていた。** 数値は一次資料（抄録か本文）で確認できたものだけを書き、確認できなかったものは `uncertainty` に「二次資料経由」と書いてください。
- **ガイドラインの本文にない記述が、そのガイドラインを出典として書かれていた。** ガイドラインを出典にするときは、その版の本文に書いてあることだけを書いてください。推奨の強さ・エビデンスレベルは、その版の表記どおりに書いてください。
- **1枚のカードに2つの文献の識別子が混在していた。** 1枚のカードの識別子は1つの文献にそろえてください。
- **表から読み取った数値**（重症度分類の基準値、病期分類、薬の用量など）は、`uncertainty` に「表から読み取り」と書いてください。
- **版を確認してください。** 胆道閉鎖症診療ガイドラインは第2版（2024年）、腸重積症の国内ガイドラインは改訂第2版（2022年）、リンパ浮腫診療ガイドラインは第4版（2024年）、高血圧は JSH2025、心不全は JCS/JHFS 2025 が現行です。転移性肝癌の ESMO ガイドラインは2026年の改訂の有無を確かめてください。

## 4. 抽出元の候補とライセンスの目安

- **国内の学会のガイドライン**：学会の著作物のため、CC の表示がなければ `RESTRICTED`。
- **海外のガイドライン・総説**：通常は `RESTRICTED`。CC BY の表示があるものだけ `OPEN`。
- **主要な原著論文**：CC BY の OA 論文は `OPEN`、それ以外は、表示を確認できなければ `UNKNOWN`、購読誌で CC の表示がなければ `RESTRICTED`。
- **国内の公的資料**（診療報酬・療養費の通知など）：`GOV_JP`。添付文書は製造販売業者の著作物なので `GOV_JP` にせず `UNKNOWN` にしてください（第55回の決定）。

抽出元にしないもの：教科書、UpToDate などの商用二次資料、問題集、国試過去問の文章、ニュースサイト。

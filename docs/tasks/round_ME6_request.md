5. **ME-101（O-8）**：総単位数「93単位から101単位以上」は、ME-082（理学療法士・作業療法士）と同じ数字です。取り違えでないかを、臨床工学技士の検討会報告書の本文で確かめてください。既に免許を持つ者の研修の期限（令和7年4月1日）は改正法の附則で、指定規則の改正省令の名称と適用される入学年度は改正省令の附則で確かめてください。確かめられない部分は書かないでください。

# StatPearls を出典にしたカードの出典のやり直し（依頼文）

作成：Claude Code（2026-10-28）。三原の決定（StatPearls は補助的な出典にとどめる）にもとづき、これまでに StatPearls の章を出典にした 23 件のカードについて、一次資料（論文・ガイドライン・公的資料）で出典を取り直してもらう。

## 使い方

1. 下の「---」から下を Muse に渡す。
2. 成果物は `redo_sp.md` という名前で Claude Code に渡す。受け入れ検査：`python scripts/accept_round.py <成果物> --spec docs/tasks/specs/redo_sp.yaml`。
3. 取り込み後、置き換えたカードの元のカードは `status: retired`、`superseded_by: <新しいID>` にする（三原の承認済み）。一次資料が見つからなかったカードは残し、`uncertainty` に「二次資料経由（StatPearls）」と追記する。

---

StatPearls の章を出典にしたカード 23 件の、出典のやり直しをお願いします。

## 1. 方針（今後のすべての回に共通）

**StatPearls（NCBI Bookshelf の解説書）は、教科書に近い二次資料として扱います。原則として出典にしないでください。** ほかに一次資料（原著論文、診療ガイドライン、系統的レビュー、公的機関の資料）がどうしても見つからないときだけ補助的に使ってよく、その場合は `uncertainty` に「二次資料経由（StatPearls）」と必ず書いてください。

## 2. 今回の作業

下の表の各カードについて、同じ内容（主張文の事実・数値）を一次資料で確認し、**新しいカード**として書き直してください。

- **ID** は接頭辞ごとに次の番号から連番で付けてください：BR-017、DT-037、MT-037、RP-063、SK-031。元のカードの ID は使わないでください（元のカードはこちらで廃止にして、新しいカードにつなぎます）。
- **SRC 番号**は SRC-1521〜1560 を使ってください。既存の出典と同じ文献は既存の番号を使ってください。
- **主張文は、一次資料で確認できた内容に合わせて書いてください。** 元のカードと数値や表現が変わってかまいません（一次資料で確認できない部分は削ってください）。
- `curriculum`（出題基準・コアカリ）は元のカードと同じものを使ってください（表にない番号は作らない）。
- 一次資料が見つからなかったカードは、新しいカードを作らず、対応表に「一次資料なし」と理由を書いてください。
- 形式・出典表・ライセンス・`condition.region` などのルールは、各分野の依頼文（例：`docs/tasks/round23_DS.md`）と同じです。

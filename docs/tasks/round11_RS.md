## 2. 出力形式（これまでの取り込みで実際に問題になった点）

1. **YAML の中に脚注番号（[1] など）を入れないでください。** 出典の対応は provenance と、YAML の外の表で示してください。
2. **アンカー（&）とマージキー（<<:）は使わず、全件を展開形で書いてください。** YAML ブロックは1つにしてください。
3. 仮ID（RI-R01 など）は作らず、最初から最終IDで書いてください。
4. 各カードの `provenance.source_ref` に SRC 番号を入れてください。
5. `legal_basis` と `source_class` の2欄で書いてください（`basis_tag` は使わない）。
6. `status` はすべて `draft`、`verifier` は `null` にしてください。`verified_sources` への昇格は、リポジトリ側で API 照合した後に行います。
7. 主張文に「（要確認）」などの括弧書きを入れないでください。不確かな点は `uncertainty` に書いてください。
8. **`curriculum` 欄は必ず埋めてください。** 番号は第6節の表から選び、表にないものは推測せず `null` にしてください。RX のうち各論に当てはまらないもの（症候・検査など）は `kokushi: null` とし、コアカリは別表2-6 の番号を使ってください。循環器（第8〜10回）では、この方式で 266件中 242件に番号が付き、問題作成の配分計算に使えました。
9. `subdomain` には、第6節の表の大項目名か中項目名（例：「市中肺炎」「慢性閉塞性肺疾患」）を入れてください。

## 3. 内容の確認（これまでの照合で見つかった誤りの傾向）

- **二次資料から写した数値が一次資料と違っていた。** 数値は一次資料（抄録か本文）で確認できたものだけを書き、確認できなかったものは `uncertainty` に「二次資料経由」と書いてください。
- **ガイドラインの本文にない記述が、そのガイドラインを出典として書かれていた。** ガイドラインを出典にするときは、その版の本文に書いてあることだけを書いてください。推奨の強さ・エビデンスレベルは、その版の表記どおりに書いてください。
- **1枚のカードに2つの文献の識別子が混在していた。** 1枚のカードの識別子は1つの文献にそろえてください。
- **日本と欧米で基準値や推奨が違う点**（肺炎の重症度分類、COPD の病期と吸入薬の選択、喘息の段階的治療、結核の治療期間など）は、`condition.region` と `condition.guideline` で区別し、1枚に混ぜないでください。
- **表から読み取った数値**（重症度分類の基準値、病期分類、薬の用量など）は、取得ツールの抜き出しで崩れることがありました。表の値を使ったカードは、`uncertainty` に「表から読み取り」と書いてください。
- **新しい版が出ていないか確認してください。** 循環器では、出典にした版のあとに改訂版が公表されていた例が複数ありました。その分野の最新版を出典にし、旧版を使う場合は理由を `uncertainty` に書いてください。
- 薬剤の承認・保険適用は国内の状況を書き、確認できなければ `uncertainty` に書いてください（抗線維化薬、生物学的製剤、分子標的薬、免疫チェックポイント阻害薬など）。

## 4. 抽出元の候補とライセンスの目安

ライセンスは Crossref の license 欄か出版社ページで確認し、確認できたものだけを書いてください。

- **日本呼吸器学会（JRS）などの診療ガイドライン**：日本語版は学会の著作物と考えられるため、表示を確認し、CC の表示がなければ `RESTRICTED`（数値と方向性だけを自作文で使う）。英語版が Respiratory Investigation などに掲載されている場合は、DOI のある英語版を出典にし、その license 欄を確認してください（循環器では、日本語版だけを出典にして DOI が空になったカードが多数ありました）。
- **日本肺癌学会、日本結核・非結核性抗酸菌症学会、日本呼吸器内視鏡学会、日本睡眠学会などの指針・診療ガイドライン**：同じ扱い。
- **GOLD（COPD）、GINA（喘息）、ATS/ERS/JRS/ALAT（IPF）、ERS/ESC（肺高血圧症・肺塞栓症）、IDSA/ATS（肺炎）**：通常は `RESTRICTED`。CC BY の表示があるものだけ `OPEN`。GOLD・GINA の報告書は独自の利用条件があるため、表示を確認してください。
- **主要 RCT・コホート研究**：CC BY の OA 論文は `OPEN`、それ以外は `RESTRICTED`。
- **国内統計**：厚生労働省の人口動態統計・患者調査・結核登録者情報調査年報、国立がん研究センターのがん統計など（`GOV_JP`。がん統計は利用規約の表示を確認する）。石綿健康被害救済制度・じん肺法は法令・行政資料（`GOV_JP` または `C`）。
- **米国政府資料**：CDC、NHLBI、NCI PDQ など（`GOV_US`。PDQ は利用条件を確認する）。WHO の Global Tuberculosis Report は CC BY-NC-SA のため `RESTRICTED`。

抽出元にしないもの（Project 指示文のとおり）：教科書、UpToDate などの商用二次資料、問題集、国試過去問の文章、ニュースサイト。

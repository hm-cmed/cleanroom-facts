## 決まったこと（2026-11-23 三原の決定）

1. 接頭辞は `ME` の1つだけ。区分（制度・評価・教育手法・横断・教員と学習者）は `subdomain` に書く。カード番号は ME-001 から振る。
2. **対象は医療系の全職種。** 第1弾の10枚は医師の養成についてのカードが中心になる。主張文と `condition.対象` には、どの職種の話かを必ず書く（例：「医学生」「医師（初期臨床研修医）」）。共用試験のように職種ごとに制度が違うものは、医師（医学）の制度だと分かるように書く。歯学・薬学・看護などの制度は第2弾以降で扱う。
3. カリキュラム欄は次の3通りに分ける。
   - 学生が学ぶ内容（プロフェッショナリズム、患者安全、多職種連携など）：コアカリの第1〜2層の不変 id（例：`PR (id: JnGV10M)`）。
   - 日本の制度（医師法、臨床研修、共用試験）：国試の必修・医学総論の該当項目。番号が分からなければ空欄にして、レポジトリ側が出題基準の PDF で付ける。
   - 教育者向けの理論（Miller、EPA、フィードバック、シミュレーション教育の効果など）：カリキュラム欄は空にする。`condition.対象` を「教育者」にする。
4. 出典番号は SRC-5101〜5160 を使う。

## 作り手への注意

1. **RESTRICTED の出典**（ME-006〜010 と ME-003 の補助資料）は、数値と方向性だけを自作の文で書く。図や表、定義文の訳はそのまま使わない。Miller の4層の名称（knows など）は概念名として書いてよい。説明文は自分の言葉で書く。
2. **自由に使える裏づけを探す。** CC BY の総説、BMC Medical Education、MedEdPublish などで、同じ事実を再掲しているものがあれば `corroboration` に書く。ライセンスは版ごとに確かめる（PMC の表示と Crossref の license を照らし合わせる）。
3. **数値は一次資料で確定させる。** 分割案の要旨の数字は、そのままでは使わない。とくに次の3点。
   - ME-002：共用試験の合格を国試の受験資格にする要件の施行時期と、対象になる受験者の範囲。改正医師法の附則の書き方に合わせる。
   - ME-004：「5年ごとの見直し」の根拠になる条文や資料。
   - ME-001：診療参加型臨床実習の期間（1診療科あたり何週か）。コアカリ本文で確かめる。分割案 A5 の内容を ME-001 に含める場合に限る。
4. 識別子（PMID・DOI・PMCID）は API で確かめたものだけを書く。分割案で誤った PMID 4件を差し替えた記録は、そのまま残す。
5. 法令（医師法）は `legal_basis` C、`source_class` GOV_JP とする。条番号を書く。
6. 形式は、これまでの調査ラウンドの成果物と同じにする（YAML のカード本文、出典マスター表、未解決事項、次回への引き継ぎ）。
7. **YAML の書き方の注意：** 値の中に「 #」（空白のあとに #）が入る場合は、値全体を引用符で囲む。囲まないと、それより後ろが読み捨てられる（第61回の FT-015 で実際に起きた）。

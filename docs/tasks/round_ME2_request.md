## 作り手への注意

1. **定義文や結論文を和訳して使わない。** 第1弾の ME-008 は、Ende の定義文をほぼそのまま和訳した疑いで取り込みを止めた。RESTRICTED の出典では、概念の説明を自分の言葉で組み立てる。原文の一文を日本語に置き換える書き方は避ける。数値・方向性・概念名（例：programmatic assessment）は使ってよい。
2. **数値は抄録・本文で確定させる。**
   - ME-014（PBL）：「異なる傾向」のようなあいまいな書き方はしない。どのアウトカムで、どちらの方向の差だったかを、抄録で確かめた範囲で書く。
   - ME-015・ME-016・ME-019：効果量、信頼区間、研究数、比較の相手を書く。
   - ME-018：抑うつ（症状）と自殺念慮の有病率の点推定と信頼区間、統合した研究数、対象の国・期間を抄録で確定させる。
3. **ME-018 は自殺念慮という扱いの難しい内容を含む。** カードは事実の記述にとどめる。動画などに使う場合は、相談窓口の案内を添え、方法には触れない。この注意を、このカードの `uncertainty` か備考に書く。
4. **ME-011 の数値は年度によって変わりうる。** CBT の問題数・時間は、資料の年度を書く。公的化（2023年度）の前後で変わった点があれば、分けて書く。
5. 識別子（PMID・DOI・PMCID）は API で確かめたものだけを書く。PMC 版がある論文（著者原稿を含む）は PMCID も書く。ただし、著者原稿は CC ではないので、ライセンスの区分は変えない。
6. YAML の値に「 #」が入る場合は、値全体を引用符で囲む。

## 第2陣（6枚）を出す前に、レポジトリ側から伝えておくこと

第2陣は、第1陣の取り込み後に別の依頼文で出す。

- **E3（WHO の IPE 枠組み）：** 「互いについて・互いから・互いと共に学ぶ」という定義は、英国の CAIPE の定義に由来する有名な定義文である。これを訳して主張文にすると、ME-008 と同じ問題になる。主張文は自分の言葉で書き、定義の出どころは `uncertainty` に書く。
- **E2・E3（WHO の文書）：** 2010年・2011年の文書は CC の表示がないか、CC BY-NC-SA で、どちらでも RESTRICTED になる。
  - E2 の11のトピック名の列挙は、概念名の並びとしてなら使える。説明文の訳は使わない。
- **B3（専門医制度）：** 日本専門医機構の資料は RESTRICTED とする。主出典は厚労省の「専門医の在り方に関する検討会」報告書や、医道審議会の資料（GOV_JP）を優先する。基本領域の数は、資料の時点を書く。
- **B4（マッチング）：** マッチング協議会の手引きは RESTRICTED（権利表記を確かめる）。主出典は厚労省のマッチングのページ（GOV_JP）を優先する。
- **C5・D4：** 出典はどちらも RESTRICTED。注意1と同じく、定義文や結論文の和訳はしない。

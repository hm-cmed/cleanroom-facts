# 試行の評価手順と採点表（第14回 呼吸器の補完）

同じ依頼文（`docs/tasks/round14_RS_supp.md`）を2つの作り手に渡し、成果物を作り手を伏せて比べる。目的は「事実票の調査を任せられるか」の判断で、文章のうまさは評価しない。

## 1. 手順

| # | やること | 誰が |
|---|---|---|
| 1 | 依頼文の「---」から下を、2つの作り手にそのまま渡す（同じ日に） | 三原 |
| 2 | 成果物を `trial_A.md`・`trial_B.md` に名前を変える。対応は自分だけが記録する | 三原 |
| 3 | 2つのファイルを Claude Code に渡す。レポジトリには入れない | 三原 |
| 4 | `python scripts/eval_trial.py trial_A.md trial_B.md --spec docs/tasks/round14_RS_supp.yaml` で客観指標を出す | Claude Code |
| 5 | PC で `--online` を付けて再実行し、DOI・PMID・ライセンスを Crossref・NCBI で照合する | 三原（PC） |
| 6 | `reports/trial_sample_14.csv` の抜き取り（各8枚）を、出典の抄録・本文と照らして判定する | Claude Code（下書き）→ 専門医 |
| 7 | 下の採点表で点を付け、A・B の対応を明かす | Claude Code → 三原 |
| 8 | 採用するほう（または良いカードだけ）を `raw/14_rs_supp.md` として取り込む：`python scripts/ingest_round.py raw/14_rs_supp.md RI,RO,IL,LC,PL --append` | Claude Code |

- 採用しなかったほうのカードは取り込まない。両方から良いカードを選ぶ場合は、ID と SRC 番号が重なるので、Claude Code が採用分の番号を振り直した原本を作り、その対応表を残す（主張文と数値は変えない）。
- 評価する Claude Code は作り手の一方と同系統のため、身内びいきのおそれがある。点の大半は機械的な指標と出典との照合で決め、判断の入る項目（第2節の「内容」）は専門医の判定を優先する。

## 2. 採点表（100点）

| 区分 | 指標 | 配点 | 付け方 |
|---|---|---|---|
| 正確さ（50） | 抜き取りの数値が出典と一致 | 25 | 一致の割合 × 25（「確認できず」は不一致として数える） |
| | DOI・PMID が実在し、題名が一致 | 10 | 一致した出典の割合 × 10（`--online`） |
| | ライセンス判定が Crossref の license 欄と一致 | 5 | 一致の割合 × 5。食い違いのうち OPEN と誤ったもの（制限のある出典を OPEN とした）は1件ごとに −2 |
| | ガイドラインの本文にない記述・識別子の混在がない | 10 | 抜き取りで見つかった1件ごとに −3（下限0） |
| 指示の順守（20） | 形式（YAML 1ブロック・脚注なし・スキーマ適合・status/verifier） | 8 | 問題1件ごとに −2 |
| | ID・SRC 番号の指定どおり（範囲・連番・既存文献の再利用） | 6 | 違反1件ごとに −1 |
| | 出題基準・コアカリの番号が正しい | 6 | 正しいカードの割合 × 6 |
| 網羅（15） | 対象小項目（16）のカバー | 10 | カバーの割合 × 10 |
| | テーマ（6）のカバー | 5 | カバーの割合 × 5 |
| 誠実さ（15） | 分からないことを `uncertainty` に書いている（二次資料経由・表から読み取り・承認の未確認） | 8 | 抜き取りで、書くべき不確かさが書かれていない1件ごとに −2 |
| | 既存カードとの重複がない | 4 | 類似（0.6以上）で実質同じものが1件ごとに −1 |
| | 主張文が原典の文言の写しでない | 3 | 写しの疑い1件で0点（その場合は §1-6 により作業を止めて報告する） |

### 判断の目安

- **80点以上**：調査を任せてよい。以後も Claude Code の取り込み・照合と専門医の監修は同じように行う。
- **60〜79点**：範囲を限って任せる（例：統計・疫学のような識別子の照合がしやすいテーマ）。
- **60点未満、または写しの疑い・制限のある出典を OPEN と誤る例が複数**：任せない。

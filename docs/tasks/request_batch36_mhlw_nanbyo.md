# Muse への依頼：バッチ36（RC）・43（HS）の指定難病の診断基準を、厚労省の資料で確かめ直す（2026-11-11）

## 背景
バッチ36で A 4件（RC-011・017・018・023）と B 2件（RC-013 の一部・RC-025）の根拠にした「難病情報センター」のページは、公益財団法人 難病医学研究財団のサイトで、政府の資料ではありません（©同財団、利用規約は未確認）。これまでのバッチでも根拠にしていません。そのため、この6件は反映していません。

## 依頼
同じ診断基準・重症度分類は、厚生労働省が自身のサイトで公表しています（「指定難病一覧」の各疾患の「概要、診断基準等」の PDF）。次の4疾患について、厚労省のサイト（mhlw.go.jp）にある PDF を実際に開き、カードの主張と一致するかを確かめてください。
- 自己免疫性溶血性貧血（指定難病61）：RC-011、RC-013（寒冷凝集素価・C3d の部分）
- 再生不良性貧血（指定難病60）：RC-017（診断基準）、RC-018（重症度分類 Stage 4・5）
- 発作性夜間ヘモグロビン尿症（指定難病62）：RC-023
- 後天性赤芽球癆（指定難病283）：RC-025
- 血栓性血小板減少性紫斑病（指定難病64）：HS-006（ADAMTS13 活性10%未満・インヒビターの部分。バッチ43）
- 自己免疫性後天性凝固因子欠乏症（指定難病288）：HS-026（診断基準）、HS-027（バイパス止血療法・免疫抑制療法）（バッチ43）
- オスラー病（指定難病227）：HS-031（診断基準・責任遺伝子）（バッチ43）

## 返してほしいもの（カードごと）
- 判定（A／B／C）
- 厚労省の PDF の URL と、ページの題名・掲載日（または改正日）
- 一致した部分・一致しない部分
- 令和9年4月1日の一部改正の予定が、そのカードに関わるか

## 守ること
- 難病情報センターのページと、調査研究班の参照ガイドは根拠にしない。
- 主張文と数値は変えない。

## 今後のバッチでも
難病情報センター（nanbyou.or.jp）は GOV_JP として扱いません。指定難病の診断基準を使うときは、厚労省のサイトの PDF を出典にしてください（既存の SRC-247 のように「厚生労働省. 指定難病 XX ○○ 概要、診断基準等」の形）。

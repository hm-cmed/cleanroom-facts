# 医療者教育（ME）第3弾：5領域の46件の作成依頼

依頼者：三原弘（2026-11-24）。モコの分割案（ME_split_5areas.md、2026-11-24）の候補46件（TL 9・AS 10・CD 9・EM 8・IT 10）をすべて、カード本文にしてください。作業の前に、hm-cmed/cleanroom-facts の最新版を取得してください。

## 1. 決まったこと

- **46件すべてを今回作る**（三原の決定、2026-11-24）。分量が多いので、成果物は領域ごとに分けてかまいません。ファイル名は ME4_TL.md、ME4_AS.md、ME4_CD.md、ME4_EM.md、ME4_IT.md とし、1つにまとめる場合は ME4_medical_education.md とします。
- カード番号は ME-026 から通し番号で振る（TL→AS→CD→EM→IT の順）。出典番号は SRC-5300〜5399 を使う。既存の出典を使う場合は、その番号を書く。
- **subdomain は、次の名前のどれかを書く**（既存の ME-001〜025 も付け替え済み）。

  | 記号 | subdomain に書く名前 |
  |---|---|
  | TL | ティーチング＆ラーニング |
  | AS | アセスメント |
  | CD | コースディベロップメント |
  | EM | 教育管理 |
  | IT | ICTを用いた教育 |
  | ― | 制度（法令・資格制度そのものが主題のもの） |
  | ― | 横断（専門職性・学習者の健康など） |

- 対象は医療系の全職種。看護・薬学などを含む医療専門職教育の研究も使ってよい。その場合は、主張文と `condition.対象` に対象を書く。
- カリキュラム欄：教育者向けの理論・手法は空にし、`condition.対象` を「教育者」とする。学生が学ぶ内容になるものだけ、コアカリ第1層の不変 id を付ける。
- 法令を出典にするカード（EM-4・EM-5・EM-7）は、既存の ME-002・ME-004 と同じ作りにする（legal_basis C、source_class GOV_JP、条文番号を書く）。
- 初等中等教育向けの生成 AI ガイドライン（文部科学省）は、今回は入れない。

## 2. 分割案から直す・確かめる点（レポジトリ側の検討より）

1. **EM-4（FD の義務化）**：大学設置基準は令和4年（2022年）に大きく改正されている。旧第25条の3の規定が、現行ではどの条文にあるかを e-Gov の現行法で確かめて書く。EM-5（学校教育法施行規則第165条の2）、EM-7（学校教育法第109条）も、現行形で確かめる。
2. **AS-10（多面評価）**：分割案の題名は論文の題名と合っていない。Donnon らの系統的レビューの正しい書誌を確かめる。
3. **IT-4・IT-5（LLM の試験成績）**：数値は本文で確定させ、モデル名・版・試験の年度・研究の時点を主張文か `uncertainty` に書く。より新しい研究があれば、`uncertainty` に「より新しいモデルでの結果がある」ことと、その書誌を書く。
4. **IT-2（UNESCO、CC BY-SA 3.0 IGO）**は RESTRICTED とする。
5. **「識別子は今回未確認」の候補**（TL-8・TL-9、AS-4・AS-6・AS-8・AS-10、CD-2・CD-4・CD-6〜9、EM-1〜3・EM-8、IT-10 など）は、API で確かめた識別子だけを書く。確かめられなければ null にして、理由を `uncertainty` に書く。
6. **RESTRICTED の原典（AMEE Guide、教科書、古典論文）**：CC BY の総説で同じ内容を裏づけられれば、そちらを主出典にし、原典は corroboration に書く。
7. 製品名（ChatGPT など）は、出典の書誌の中にとどめる。主張文では「大規模言語モデル（LLM）」などの一般名を使う。

## 3. これまでと同じ注意

- 定義文・結論文を和訳して使わない。抄録の結果を、順番どおりに一文ずつ日本語にするまとめ方も避ける。
- 数値は一次資料（本文）で確定させる。抄録だけで確かめた場合は、そう書く。
- 識別子（PMID・DOI・PMCID・ISBN）は、API や公式の登録情報で確かめたものだけを書く。
- YAML の値に「 #」が入る場合は、値全体を引用符で囲む。
- 形式は第1弾・第2弾と同じ（出典表、カード本文の YAML、カリキュラム対応表、未解決事項、引き継ぎメモ）。

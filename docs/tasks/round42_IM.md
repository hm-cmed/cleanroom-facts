### 1-2. 作り手への追加の注意（これまでの回で見つかった点）

2つの作り手を比べた試行で、次の点が取り込み側の手間になりました。受け入れ検査でも確認します。

1. **論文の出典には、DOI と PMID を必ず書いてください。** 有名な試験（大規模 RCT など）ほど DOI・PMID は簡単に確認できます。調べても確認できなかったときだけ空欄にし、出典表の「確認経路」にその理由を書いてください。
2. **薬の名前が出るカードには、`uncertainty` に国内の承認・保険適用の確認状況を書いてください**（例：「国内承認は PMDA の添付文書で確認」「国内の適応は未確認」）。
3. **ライセンスは、Crossref の license 欄または出版社ページで CC BY と確認できたら `OPEN` にしてください。** 確認できないものは `UNKNOWN` で構いませんが、BMC・Frontiers・PLOS など CC BY の雑誌を `UNKNOWN` のままにしないでください。CC BY-NC・ND は `RESTRICTED` です。
4. **`condition.region` は全件に書いてください**（日本・米国・欧州・国際など）。日本と海外で基準や推奨が違う点（診断基準の構成、治療薬の承認と保険適用、ガイドラインの版など）は、地域ごとに別のカードにしてください。
5. 成果物には、作成に使ったツール名・モデル名・サービス名を書かないでください。
6. **出題基準・コアカリの番号は、必ず第7節の表からそのまま写してください。表にない番号を作らないでください。** 当てはまる項目がなければ `kokushi: null` で構いません（第19回で、表にない番号を組み立てたため差し戻しになりました）。

## 3. 内容の確認（これまでの照合で見つかった誤りの傾向）

- **二次資料から写した数値が一次資料と違っていた。** 数値は一次資料（抄録か本文）で確認できたものだけを書き、確認できなかったものは `uncertainty` に「二次資料経由」と書いてください。
- **ガイドラインの本文にない記述が、そのガイドラインを出典として書かれていた。** ガイドラインを出典にするときは、その版の本文に書いてあることだけを書いてください。推奨の強さ・エビデンスレベルは、その版の表記どおりに書いてください。
- **1枚のカードに2つの文献の識別子が混在していた。** 1枚のカードの識別子は1つの文献にそろえてください。二誌同時掲載の論文は、登録された版の書誌にそろえてください。
- **表から読み取った数値**（診断基準の基準値、分類基準の配点、薬の用量など）は、`uncertainty` に「表から読み取り」と書いてください。
- **新しい版が出ていないか確認してください。** その分野の最新版を出典にし、旧版を使う場合は理由を `uncertainty` に書いてください。本分野では特に：鼻アレルギー診療ガイドラインは2024年版（第10版）が現行で既存 SRC-1373（2020年版）は旧版、蕁麻疹診療ガイドラインは2026年版（第4版）が現行、多発性筋炎・皮膚筋炎診療ガイドラインは2025年版が現行で既存 SRC-1768（2020年暫定版）は旧版、Sjögren症候群・全身性強皮症の国内ガイドラインも2025年版が現行です。
- **撤回された論文を出典にしないでください。** 本分野ではアバコパンの ADVOCATE 試験（NEJM 2021）が2026年に撤回されています（§1 の注意参照）。

## 3. 分割案の未決事項（§4）への回答

2. **PS-004（ME-116）**：Marx 2001 のプライマーは、報告書（機関発行）として登録してかまいません。
   - 区分は RESTRICTED にしてください。国立心肺血液研究所（NHLBI）の助成で作られていますが、発行者は Columbia University の Trustees で、米国連邦政府の著作物ではありません。
   - URL は、できるだけ発行者に近いものにしてください。第三者のアーカイブ（mers-tm.net など）は、入手先として uncertainty に書いてください。
   - 3分類（human error／at-risk behavior／reckless behavior）は、出典確定メモのとおり、主出典（2001）と裏づけ（Marx 2019）の組み合わせで書いてください。2001年版の4つの概念との違いは uncertainty に書いてください。
3. **PS-002（ME-114）**：To Err Is Human は National Academies Press の著作物で、RESTRICTED です。NCBI Bookshelf に載っていても、政府の著作物ではありません。ISBN は出版社のページで確かめてください。推計が2つの研究からの外挿であることは、分割案のとおり uncertainty に書いてください。
4. **WHO の文書**：CC BY-NC-SA 3.0 IGO は RESTRICTED です。表示は1件ずつ確かめてください。Bulletin of the WHO の論文（Sheikh 2017）は、論文のページのライセンス表示を確かめてください。CC BY 3.0 IGO であれば OPEN です。
5. **PS-011（ME-122）**：DOI だけで登録してかまいません（EB-003 の ASA 声明と同じ扱い）。
6. 依頼単位：11件を1回。

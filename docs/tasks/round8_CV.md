## 2. 出力形式（消化器の取り込みで実際に問題になった点）

1. **YAML の中に脚注番号（[1] など）を入れないでください。** 出典の対応は provenance と、YAML の外の表で示してください。
2. **アンカー（&）とマージキー（<<:）は使わず、全件を展開形で書いてください。** YAML ブロックは1つにしてください。
3. 仮ID（AR-R01 など）は作らず、最初から最終IDで書いてください。
4. 各カードの `provenance.source_ref` に SRC 番号を入れてください。
5. `legal_basis` と `source_class` の2欄で書いてください（`basis_tag` は使わない）。
6. `status` はすべて `draft`、`verifier` は `null` にしてください。`verified_sources` への昇格は、リポジトリ側で API 照合した後に行います。
7. 主張文に「（要確認）」などの括弧書きを入れないでください。不確かな点は `uncertainty` に書いてください。
8. **`curriculum` 欄は必ず埋めてください。** 消化器の第6回（急性腹症）・第7回（横断項目）では出題基準の番号が空のカードが多く、問題作成の配分計算に使えませんでした。番号は第6節の表から選び、表にないものは推測せず `null` にしてください。CX のうち各論に当てはまらないもの（症候・検査など）は `kokushi: null` とし、コアカリは別表2-5 の番号を使ってください。
9. `subdomain` には、第6節の表の大項目名か中項目名（例：「心房細動」「急性冠症候群」）を入れてください。

## 3. 内容の確認（消化器の照合で見つかった誤りの傾向）

- **二次資料から写した数値が一次資料と違っていた。** 数値は一次資料（抄録か本文）で確認できたものだけを書き、確認できなかったものは `uncertainty` に「二次資料経由」と書いてください。
- **ガイドラインの本文にない記述が、そのガイドラインを出典として書かれていた。** ガイドラインを出典にするときは、その版の本文に書いてあることだけを書いてください。推奨の強さ・エビデンスレベルは、その版の表記どおりに書いてください。
- **1枚のカードに2つの文献の識別子が混在していた。** 1枚のカードの識別子は1つの文献にそろえてください。
- **日本と欧米で基準値や推奨が違う点**（降圧目標、抗凝固のスコア、心不全の分類など）は、`condition.region` と `condition.guideline` で区別し、1枚に混ぜないでください。
- 薬剤の承認・保険適用は国内の状況を書き、確認できなければ `uncertainty` に書いてください。

## 4. 抽出元の候補とライセンスの目安

ライセンスは Crossref の license 欄か出版社ページで確認し、確認できたものだけを書いてください。

- **日本循環器学会（JCS）などの診療ガイドライン**（日本語版・Circulation Journal 英語版）：多くは学会の著作物と考えられるため、表示を確認し、CC の表示がなければ `RESTRICTED`（数値と方向性だけを自作文で使う）。
- **AHA/ACC、ESC のガイドライン**：通常は `RESTRICTED`。CC BY の表示があるものだけ `OPEN`。
- **主要 RCT・コホート研究**：CC BY の OA 論文は `OPEN`、それ以外は `RESTRICTED`。
- **国内統計**：厚生労働省の人口動態統計・患者調査など（`GOV_JP`）。日本循環器学会の循環器疾患診療実態調査（JROAD）報告は表示を確認する。
- **米国政府資料**：NHLBI、CDC など（`GOV_US`）。

抽出元にしないもの（Project 指示文のとおり）：教科書、UpToDate などの商用二次資料、問題集、国試過去問の文章、ニュースサイト。

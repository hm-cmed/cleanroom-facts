## 登録時の決定（この依頼文の他の箇所に「案」と書いてあっても、こちらが優先）

1. 6回に分ける。出典番号は第62回 SRC-4521〜4620、第63回 4621〜4720、第64回 4721〜4800、第65回 4801〜4880、第66回 4881〜4960、第67回 4961〜5060。
2. **既存のカードは直さない。** 各項目に、既存カードで欠けている側面（下の表の「2件目に書く側面」）のカードを足す。既存カードの単一研究の数値を置き換えるのではなく、一般像（定義・臨床像・診断・治療原則）のカードを加える。
3. 接頭辞は表のとおり。原則は既存カードと同じ接頭辞の続き番号。例外：アルコール性肝障害（Ⅵ-6-E-③）は LV、偽痛風（Ⅺ-2-E-②）は SA、ウイルス性髄膜炎（Ⅻ-1-A-⑱）は VI、性器クラミジア（Ⅻ-2-A-②）は CM、淋菌感染症（Ⅻ-2-B-⑥）は BA、三叉神経痛（Ⅸ-5-C-①）は PN。
4. 開始番号が「続き」の接頭辞は、前の回（第61回を含む）で同じ接頭辞を使うため、前の回で最後に使った番号の次から振る。
5. **章をまたいで同じ内容になる項目は、1枚のカードに両方の番号を付ける**（例：淋菌性尿道炎 Ⅷ-5-D-① と淋菌感染症 Ⅻ-2-B-⑥、三叉神経痛 Ⅸ-5-C-① と Ⅲ-8-C-②）。そのため、性器クラミジアと淋菌は第64回で尿道炎と一緒に作る。
6. ガス壊疽（Ⅻ-2-B-⑳）は、臨床像・治療は SD-034 が担っている。2件目は病原性（α毒素）と検査所見に絞る。
7. 件数の目安は各項目1〜3件。上限は目安で、超えてもよい。

## 1. 作り手への注意

1. 出典の既存判定は、現行の出典マスター全体で行う（第61回の取り込み後の最新）。既存カードと同じ出典（ガイドラインの未使用部分）で作れる場合は、既存の SRC 番号を使う。
2. 薬の名前が出るカードは、uncertainty に**薬剤名を特定して**国内の承認・保険適用を書く。
3. 最後に番号を振り直したら、「未解決事項」と「次回への引き継ぎ」の番号も合わせて直す。

## 2. 出力形式（これまでの取り込みで実際に問題になった点）

1. **YAML の中に脚注番号（[1] など）を入れないでください。** 出典の対応は provenance と、YAML の外の表で示してください。
2. **アンカー（&）とマージキー（<<:）は使わず、全件を展開形で書いてください。** YAML ブロックは1つにしてください。
3. 仮ID（AB-R01 など）は作らず、最初から最終IDで書いてください。
4. 各カードの `provenance.source_ref` に SRC 番号を入れてください。
5. `legal_basis` と `source_class` の2欄で書いてください（`basis_tag` は使わない）。
6. `status` はすべて `draft`、`verifier` は `null` にしてください。`verified_sources` への昇格は、リポジトリ側で API 照合した後に行います。
7. 主張文に「（要確認）」などの括弧書きを入れないでください。不確かな点は `uncertainty` に書いてください。
8. **`curriculum` 欄は必ず埋めてください。** 番号は各回の表から選び、表にないものは推測せず `null` にしてください。総論のカードを作る場合は `kokushi: null` で構いません。
9. `subdomain` には、各回の表の大項目名か中項目名（例：「虚血性腸炎」「肝損傷」）を入れてください。

## 3. 内容の確認（これまでの照合で見つかった誤りの傾向）

- **二次資料から写した数値が一次資料と違っていた。** 数値は一次資料（抄録か本文）で確認できたものだけを書き、確認できなかったものは `uncertainty` に「二次資料経由」と書いてください。
- **ガイドラインの本文にない記述が、そのガイドラインを出典として書かれていた。** ガイドラインを出典にするときは、その版の本文に書いてあることだけを書いてください。推奨の強さ・エビデンスレベルは、その版の表記どおりに書いてください。
- **1枚のカードに2つの文献の識別子が混在していた。** 1枚のカードの識別子は1つの文献にそろえてください。
- **表から読み取った数値**（重症度分類の基準値、病期分類、薬の用量など）は、`uncertainty` に「表から読み取り」と書いてください。
- **版を確認してください。** 胆道閉鎖症診療ガイドラインは第2版（2024年）、腸重積症の国内ガイドラインは改訂第2版（2022年）、リンパ浮腫診療ガイドラインは第4版（2024年）、高血圧は JSH2025、心不全は JCS/JHFS 2025 が現行です。転移性肝癌の ESMO ガイドラインは2026年の改訂の有無を確かめてください。

## 4. 抽出元の候補とライセンスの目安

- **国内の学会のガイドライン**：学会の著作物のため、CC の表示がなければ `RESTRICTED`。
- **海外のガイドライン・総説**：通常は `RESTRICTED`。CC BY の表示があるものだけ `OPEN`。
- **主要な原著論文**：CC BY の OA 論文は `OPEN`、それ以外は、表示を確認できなければ `UNKNOWN`、購読誌で CC の表示がなければ `RESTRICTED`。
- **国内の公的資料**（診療報酬・療養費の通知など）：`GOV_JP`。添付文書は製造販売業者の著作物なので `GOV_JP` にせず `UNKNOWN` にしてください（第55回の決定）。

抽出元にしないもの：教科書、UpToDate などの商用二次資料、問題集、国試過去問の文章、ニュースサイト。

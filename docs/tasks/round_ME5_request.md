## 2. 分割案から直す・確かめる点（レポジトリ側の検討より）

1. **ME-073・ME-083 の施行時期**：歯学の「令和6年4月（歯科医業）・令和8年4月（受験資格）」を、改正歯科医師法の附則と、経過措置を定める政令（またはその概要資料）で確かめてください。受験資格の条番号は、e-Gov の現行法で確かめて書いてください。ME-002 と同じ作りにします。
2. **ME-077 の問題数と日数（345問・2日間）**：二次資料の確認にとどまっています。厚生労働省の公表資料（出題基準、試験の施行についての公告など）で確定させてください。確定できなければ、数値を主張文に入れないでください。
3. **ME-083 の薬学の部分**：「薬学の共用試験には法律上の位置づけがない」ことは、省庁の資料（文部科学省の薬学系人材養成の検討会の資料など）で裏づけてください。実施機関（薬学共用試験センター）の資料だけでは主出典にしません。
4. **ME-079**：在学生への経過措置は、改正省令の附則の書き方に合わせてください。単位数の配分を書く場合は、現行の別表で確かめたものだけを書いてください。
5. **ME-081**：研修時間の総量は2019年の見直しで変わっています。書く場合は現行の省令・通知で確かめてください。38行為・21区分は、施行通知の時点を書いてください。
6. **ME-072・ME-075・ME-078**：資質・能力の項目数や構成を書く場合は、本文で確かめてください。各文書の適用される入学年度も書いてください。
7. **解釈を含む書き方を避ける。** 分割案 D-5・X-4 の「コアカリの改訂と歩調を合わせて」のような書き方は、資料にそう書かれている範囲に限ります（今回の12件にはありませんが、同じ注意です）。

## 3. 法令の出典の作り方

- 法律と省令（指定規則など）は、**1つの法令ごとに SRC を1件**登録してください。例：歯科医師法、薬剤師法、保健師助産師看護師法、保健師助産師看護師学校養成所指定規則、特定行為研修の省令、理学療法士作業療法士学校養成施設指定規則。
- `legal_basis` は C、`source_class` は GOV_JP とし、URL は e-Gov 法令検索の現行法のページにしてください。条番号は provenance か uncertainty に書いてください。
- 通知・ガイドライン・出題基準は、厚生労働省・文部科学省の掲載ページの URL を書いてください（GOV_JP）。

## 5. その他の職種の候補の追加（分割案の形式で）

三原の決定により、その他の職種の範囲を広げます。分割案で挙げた職種について、分割案と同じ表の形式で候補を足してください。カード本文はまだ書きません。

- 対象の例：臨床工学技士、言語聴覚士、視能訓練士、歯科技工士、義肢装具士、柔道整復師、あん摩マッサージ指圧師・はり師・きゅう師、准看護師。
- 各職種1〜2件を目安にしてください。根拠法・指定規則・国家試験（または都道府県知事試験）・修業年限など、法令と省庁の資料で確かめられる範囲に限ります。
- 2021年の法改正（タスク・シフト／シェア）で業務範囲が変わった職種は、業務範囲の拡大と、養成教育の見直し（指定規則の改正と適用年度）を別々の事実として書いてください。指定規則の改正を確かめられなければ、業務範囲の拡大だけにしてください。
- 新しい候補の仮番号は O-7 から続けてください。
- ファイル名：`ME_split_other_professions_add.md`

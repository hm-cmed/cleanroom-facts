# 医療者教育（ME）第4弾：医師以外の職種の養成制度の分割案の作成依頼

依頼者：三原弘（2026-11-24）。今回は**分割案（候補の一覧と出典の見通し）だけ**を作ってください。カード本文はまだ書きません。結果は1つの Markdown（`ME_split_other_professions.md`）にまとめてください。作業の前に、hm-cmed/cleanroom-facts の最新版を取得してください。

## 1. 目的

- ME の対象は、2026-11-23 の決定で「医療系の全職種」です。ただし、これまでの71枚（ME-001〜071）の制度のカードは、ほぼ医師（医学）の養成に限られています。
- 今回は、歯学・薬学・看護学などの**養成制度**（コア・カリキュラム、共用試験、国家試験、卒後の研修）を足すための分割案を作ってください。

## 2. 扱う職種と、例として考えられる論点

論点は例です。網羅ではありません。取捨選択と追加は作り手の判断で決めてください。**例に書いた年や数値は確定扱いにしないでください。** すべて一次資料で確かめてください。

| 職種 | 例として考えられる論点 |
|---|---|
| 歯学（歯科医師） | 医学／歯学教育モデル・コア・カリキュラム（令和4年度改訂版）の歯学部分、歯学の共用試験（CBT・OSCE）と公的化、歯科医師国家試験、歯科医師臨床研修の必修化と法的根拠 |
| 薬学（薬剤師） | 薬学教育モデル・コア・カリキュラム（令和4年度改訂版）、6年制課程、薬学共用試験（CBT・OSCE）、長期の実務実習（病院・薬局）、薬剤師国家試験 |
| 看護学（看護師・保健師・助産師） | 看護学教育モデル・コア・カリキュラム、保健師助産師看護師学校養成所指定規則と教育内容の改正、臨地実習、看護師国家試験、新人看護職員研修（努力義務とガイドライン）、特定行為研修 |
| その他の職種 | 理学療法士・作業療法士の養成施設指定規則の改正、臨床検査技師・診療放射線技師・管理栄養士・歯科衛生士・救急救命士などの養成の要点。数を絞ってよい |
| 職種横断 | 職種ごとのコア・カリキュラムに共通する考え方（資質・能力の示し方など）。比べるカードを作るなら、各職種の一次資料で確かめられる範囲に限る |

各職種でおおむね5〜10件、合計30〜40件を目安にしてください。

## 3. 既存のカードとの重なりを先に確かめる（重要）

新しく作る前に、すでにあるカードで足りないかを確かめてください。重なる場合は、新しい候補にしないで「既存カードで対応」と書いてください。

- 特に関係が深い既存カード：
  - ME-001（医学・歯学コアカリ。カードは医学部分だけを扱う）
  - ME-002（医師の共用試験の公的化と Student Doctor。歯科医師法の仕組みは対象外と書いてある）
  - ME-003（OSCE）、ME-011（医学の CBT）、ME-004・005（医師の臨床研修）
  - ME-025（多職種の専門性の理解）、多職種連携教育（WHO 2010）と患者安全カリキュラムガイド（WHO 2011、多職種版）のカード
- ME 以外の章にも、職種の養成や資格に触れるカードがないかを全文検索してください。検索語の例：「薬剤師」「看護師」「歯科医師」「特定行為」「指定規則」「国家試験」。
- 既存カードに歯学などの記載を足すほうが自然な場合は、新しい候補にせずに「既存カードの修正案」として別欄に書いてください。主張文の修正は三原の承認が必要です。

## 4. 出典の探し方

1. **すでに出典の一覧にあるものを先に使う。** `data/sources/sources.yaml`（約2,500件）に、使える出典がないかを確かめてください。例：SRC-5101（医学・歯学コアカリ）。
2. 新しく探すときは、自由に使える資料を優先してください。
   - 法令（歯科医師法、薬剤師法、保健師助産師看護師法、各職種の学校養成所指定規則など）：`legal_basis` C、`source_class` GOV_JP。条番号を書く。
   - GOV_JP：文部科学省・厚生労働省の資料（検討会の報告書、通知、ガイドライン、国家試験の出題基準・合格者の発表）、国立保健医療科学院、厚労科研データベースの報告書（資料に権利表記がないもの）
   - OPEN（CC BY・CC0）：ライセンスは論文ごとに確かめる
3. 共用試験の実施機関（医療系大学間共用試験実施評価機構、薬学共用試験センターなど）・職能団体・学会の資料は、権利表記がなければ RESTRICTED の見立てとしてください。制度の部分は、できるだけ省庁の資料や法令を主出典にします。実施機関の資料は事実確認の補助にとどめてください（ME-003 と同じ方針）。
4. **定義文・結論文を和訳して使わない**（これまでと同じ）。

## 5. 数値と時点についての注意

- 制度は改正が多い分野です。候補ごとに、**どの時点の制度か**（施行日・適用される入学年度など）を書いてください。
- 単位数・時間数・週数・問題数などの数値は、一次資料（法令・告示・省庁の資料）で確かめたものだけを「確定」と書いてください。未確認なら「未確認」と書いてください。
- 経過措置がある場合は、対象になる学生の範囲を附則の書き方に合わせて書いてください。

## 6. 書き方

1. 職種ごとの候補の表

| # | 職種 | 区分（subdomain） | 仮タイトル | 主張の要旨（1〜2文。数値は確定したものだけ） | 既存カードとの関係 | 出典の候補（書誌・識別子・URL） | 区分の見立て | 時点 | 確認の状態 |
|---|---|---|---|---|---|---|---|---|---|

   - 区分（subdomain）は、既存の7つ（ティーチング＆ラーニング、アセスメント、コースディベロップメント、教育管理、ICTを用いた教育、制度、横断）から選んでください。養成制度の多くは「制度」、コア・カリキュラムは「コースディベロップメント」、共用試験・国家試験は「アセスメント」になる見込みです。迷ったら理由を書いてください。
2. 第1陣のおすすめ（10〜15件）と、その理由
3. 既存カードの修正案（あれば。理由と根拠だけ）
4. 対象範囲で迷った点（例：その他の職種をどこまで入れるか、カリキュラム欄の付け方）

## 7. カリキュラム欄について

- 医師国家試験の出題基準と医学のコアカリは、医師以外の職種の養成制度には付けないのが原則です。このため、カリキュラム欄は空、`condition.対象` は「歯学生」「薬学生」「看護学生」「教育者」などとする見込みです。
- 医学生が多職種連携の文脈で学ぶ内容として付けたほうがよいものがあれば、付け方の案を書いてください。

## 8. 番号

- カード番号は、取り込みのときに ME-072 から振ります。分割案では仮番号でかまいません。
- 出典番号は SRC-5400〜5499 を使ってください。

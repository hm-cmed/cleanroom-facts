## 2. 提案から直す・確かめる点

1. **数値は本文で確かめてください。** 提案では、Lee 2013 の数値（91.2% 対 75.9%）は OUP の抄録ページ、Osaki 2017 の感度・特異度は PubMed の抄録で確かめた段階です。このレポジトリでは、抄録だけで確かめた数値は使いません。本文で確かめられない数値は書かないでください。
2. **Kawai 2008 の PMID**：PubMed で確かめて書いてください。確かめられなければ null のままにし、uncertainty に理由を書いてください。
3. **日本の診療の裏づけを、国の資料でとってください（重要）。** 主出典が韓国の試験なので、日本で検査ができることを国の資料で裏づけると、動画の締めに使いやすくなります。

   - 体外診断用医薬品として承認された検査キットがあれば、PMDA の承認情報で確かめてください。PMDA の資料は GOV_JP です（2026-11-11 の決定）。製品名は uncertainty にだけ書き、主張文には書かないでください。

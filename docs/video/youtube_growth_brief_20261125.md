# YouTube 再生回数を伸ばすための分析と改善の指示（第0版）

依頼者：三原弘（2026-11-25）／作成：登録側（Claude）／渡す相手：Muse（動画の作り手）

対象：再生リスト「根拠資料の事実票に基づく医療知識」（88本、1本あたりの再生回数は0〜約2,500）

> **この版の前提**：個々の動画の数値（再生回数・インプレッション・視聴維持など）はまだ受け取っていません。YouTube のページからは、外部から一覧を取れませんでした。このため第0版は、仮説と、測り方と、すぐ直せる点だけです。YouTube Studio のデータ（§6）が届いたら、上位と下位の動画を比べて第1版にします。数値の根拠がない断定は書いていません。

---

## 1. 結論（先に）

1. **再生回数の差（0〜2,500）は、主に「最初の1〜2秒で見続けてもらえたか」と「話題の需要」で決まっている可能性が高い。** ショートは、まず少数の人に試しに表示され、見続けた人の割合が高い動画ほど、次の人に広く表示されます。
2. したがって最初に直すのは、次の3つです。中身（事実カード）は変えません。
   - 冒頭（フック）
   - タイトル
   - 話題の選び方
3. 医療の分野では、YouTube の「健康情報の提供元」の認定が大きな手がかりになります（§4）。認定を受けたチャンネルは、検索結果の健康のセクションで目立つように表示されます。三原は医師なので、申請の対象になりえます。
4. 改善は、1つずつ変えて比べる形で行います（§5）。88本のデータがあるので、比べる材料は十分あります。

## 2. 0〜2,500 の差が生まれる仕組み（仮説）

| 段階 | 起きていること | 確かめる指標（YouTube Studio） |
|---|---|---|
| ① 表示 | ショートのフィードや検索に表示される | インプレッション数、トラフィックソース（ショートフィード・検索・再生リスト・外部） |
| ② 選択 | フィードでスワイプされずに見られる | 「視聴された割合」（スワイプされずに視聴した割合） |
| ③ 視聴 | 最後まで、または繰り返し見られる | 平均視聴時間、平均再生率（100%を超えるとループして見られている） |
| ④ 反応 | 高評価・コメント・共有・登録 | 高評価数、共有数、登録者の増減 |

- 再生回数が0〜数十の動画は、①の時点で試しの表示が少なかったか、②で多くスワイプされ、広がらなかった可能性が高いです。
- 1,000を超えた動画は、②と③が良かったか、検索の需要がある話題だった可能性があります。
- **どちらなのかはデータで分けられます。** 上位10本と下位10本で、②③の数値と、トラフィックソースの内訳を比べてください。

## 3. すぐに直せる点（中身を変えずに）

### 3-1. 冒頭の1〜2秒（いちばん効く見込み）
- 1枚目に**問い**か**意外な事実**を置きます。例：「胃のピロリ菌、除菌したらもう安心？」。病名や章の題名から始めるのはやめます。
- 1枚目の文字は大きく、短く（目安は15文字前後）します。スマートフォンの縦画面で、一瞬で読めることが条件です。
- 無音のまま見る人も多いので、字幕は必ず付けます。音声だけに頼らないでください。
- 「AIで作成」の表示は必須です（CLAUDE.md §8）。冒頭の主文と重ならない位置に、小さく常に出しておいてください。表示を消したり隠したりしないでください。

### 3-2. タイトル
- 視聴者が**検索しそうな言葉**を、タイトルの前半に入れます。例：「逆流性食道炎」「健康診断」「便秘」。症状名や、よく知られた病名が向いています。
- 専門用語は、一般名を併記します。
- 「【医師監修】」は、**監修が済んだ動画にだけ**付けてください。監修前の動画には付けません。誤認させる表示になるためです。
- 煽る表現（「絶対」「9割が知らない」など）は使いません。医療の信頼性と、YouTube の医療誤情報のポリシーに配慮するためです。

### 3-3. 長さと終わり方
- 主張は1本に1つにします。1本に2つ以上の事実を詰め込まないでください。
- 最後の1文を冒頭の問いの答えにすると、もう一度見たくなる作り（ループ）になります。
- 終わりに次の動画（同じ臓器・同じ症状の動画）を案内します。関連動画のリンク機能も使ってください。

### 3-4. 説明文・再生リスト
- 説明文の1行目に要点を1文で書きます。2行目以降に出典（事実カードの ID と出典の書誌）を書きます。出典を示すことは、このシリーズの強みです。
- 88本を1つのリストにまとめるだけでなく、**症状・臓器別の小さな再生リスト**（例：「胃の不調」「肝臓の検査値」）も作ってください。続けて見てもらいやすくなり、検索にも出やすくなります。

## 4. 医療チャンネルならではの手がかり：健康情報の提供元の認定

- YouTube は2023年8月29日から、日本で、医療従事者などのチャンネルが「健康情報の提供元」として申請できるようにしました（申請先は health.youtube）。
- 主な条件：
  - 医療従事者としての免許・資格を証明できること
  - 医学の専門団体や世界保健機関（WHO）などが共同で定めた情報発信のガイドラインに従っていること
  - チャンネルが良好な状態にあること
- 認定されると、動画の下に情報源を示すパネルが出ます。病気などの話題の検索結果では、信頼できる情報源の動画を集めたセクションに表示されます。
- 登録者数などの数値の条件は、日本向けの告知には書かれていません。**申請する前に、最新の申請要件のページで確かめてください。**
- **これは三原が判断することです。** Muse は、申請に使う資料（チャンネルの方針、出典の示し方、監修の手順）の下書きまでにとどめてください。

## 5. 比べ方（A/B の代わり）

YouTube のショートには、正式な A/B テストの機能が限られています。次のやり方で比べてください。

1. **1回の投稿で変えるのは1つだけ**にします（冒頭だけ、タイトルだけ、など）。
2. 同じ程度の話題で、5本ずつ投稿します。
3. 投稿から7日後の「視聴された割合」「平均再生率」「再生回数」を比べます。
4. 投稿する曜日と時刻は、そろえてください。

記録表（Muse が毎週つける）：

| 動画ID | 公開日時 | 事実カードID | 話題（症状・臓器） | 変えた点 | 冒頭の文 | タイトル | 7日後の再生回数 | 視聴された割合 | 平均再生率 | 主なトラフィックソース |
|---|---|---|---|---|---|---|---|---|---|---|

## 6. 第1版を作るために必要なデータ（三原にお願いすること）

YouTube Studio から書き出してください。

1. 「アナリティクス」→「詳細モード」を開く。
2. 期間を「全期間」、表示を「コンテンツ」の動画ごとにする。
3. 指標を次のとおりに追加する。
   - 視聴回数
   - インプレッション数、インプレッションのクリック率
   - 平均視聴時間、平均再生率
   - 視聴された割合（ショート）
   - 高評価数、共有数、登録者の増減
4. 右上の「書き出し」から CSV（またはスプレッドシート）で保存する。
5. 同じ画面で「トラフィックソースの種類」別の表も、同じように書き出す。

この2つの CSV があれば、上位と下位の比較、話題ごとの差、投稿時期の影響を分析できます。

## 7. 変えてはいけないこと（これまでと同じ）

- 事実カードの主張文と数値。動画の各場面には、根拠のカード ID を付けます。`video/check.py` で照合します。
- 一般向けの動画では薬剤名を出さない。実在の人物のアバターは使わない。AIで作成したことを表示する。
- 収益化はしない。CC BY-NC-ND の出典の図表は使わない。
- 公開は、監修者が承認したものに限ります。

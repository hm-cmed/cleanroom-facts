## D 区分の訂正（0件）

本章では主出典自体が CC BY のものはなかった。SRC-304・307・308（日本循環器学会系ガイドライン）と SRC-4391（書籍）は © 表示があり、SRC-4389・4390 は Crossref・Europe PMC の確認で自由ライセンスが無いことが分かり、いずれも現行 RESTRICTED が正しい。SRC-290 はライセンスの一次表示を確認できず UNKNOWN の据え置きが妥当で、CC BY-NC-ND の可能性が高いことから RESTRICTED への明確化の申し送りとした（発見5）。PMC に全文・著者稿が収載されていてもライセンス表示がないもの（SRC-4389・4390）は自由利用ではない前提で扱った。

## 方法と留保

- 新ルール（抄録・添付文書・医学百科は根拠にしない）を適用した。A・B の根拠は、実際に開いて確認した政府の全文文書（PMDA の審査報告書一覧と承認情報、NCI PDQ のリンパ浮腫ページ全文）、CC BY の全文（Europe PMC の全文 XML で Table 1 の定義と CC BY 4.0 の表示を確認）、ClinicalTrials.gov の登録レコード（API で結果数値を確認）のみである。厚労省の指定難病ページ（高安動脈炎）は検索結果に表示された本文で数値を確認し、裏づけにならないことを確認するために用いた。
- ライセンスは Crossref の version-of-record と Europe PMC の license 表示・オープンアクセス表示で個別に相互確認した。SRC-290 は Crossref に表示がなく Europe PMC でも非オープンアクセスだった。J-STAGE の PDF は取得がタイムアウトしたため再試行せず、ライセンス未確認として正直に記録した。Crossref は本調査中に1回、回数制限（429）になった。
- CC BY の候補として全文を取得して照合したが内容が合わず採用しなかったものが2件ある：大動脈解離の女性に関する総説（J Cardiovasc Dev Dis、PMC13116751）は Stanford 分類の定義文を確認できず、急性下肢虚血の系統的レビュー（Medicina、PMC12113467）は Rutherford 分類の定義を確認できなかった。照合できていない候補を B とはせず、C の注記にも残していない（VS-035 の状況欄に系統的レビューの確認結果のみ記した）。
- 数値の照合（主張チェック）は ClinicalTrials.gov の結果レコードと厚労省ページの表示数値とカードを突き合わせたもので、結果は発見4のとおりである。抄録は判定の根拠に使っていない。
- 候補のうち出典マスターに無いもの（Reviews in Cardiovascular Medicine の総説、PMDA 審査報告書、ClinicalTrials.gov の登録レコード、NCI PDQ）はいずれも新規登録候補であり、SRC 番号は付けていない（採番は登録側）。NCI PDQ と PMDA 審査報告書は、他の章のカードの裏づけにも使える可能性がある。
- 出典マスターの本章出典7件については DOI・PMID・PMCID を個別に照合し、二重登録はなかった。マスター全体の既知の重複は8組（バッチ16の記録）で、本章の出典は含まれない。

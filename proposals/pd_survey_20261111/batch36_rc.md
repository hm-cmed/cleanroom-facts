# バッチ36：RC 章（貧血・造血障害）32 件

対象：RC-001〜031・033（targets.json 掲載分。RC-032 は targets.json に掲載なし）。判定は A 置き換え可／B 裏づけ追加／C 見つからない／D 区分の訂正。主張文と数値は変更していない。

## 方法と留保

- レポジトリ側の指示（2026-11-11）による新ルールを適用した。**抄録・添付文書・医学百科は根拠にしない。** 判定の根拠は政府の全文文書（難病情報センターの指定難病 診断基準ページ、ClinicalTrials.gov の結果レコード）、CC BY の全文など、全文として読める一次・公的資料のみとし、抄録は数値の照合（主張チェック）と試験登録番号の同定にのみ用いた。
- 候補のライセンスは Crossref の version-of-record と Europe PMC の license 表示で相互確認し、判定・識別子に関わるものは **すべて個別に再照会して確定した**（一括照会の誤帰属を避けるため）。試験の数値は ClinicalTrials.gov API で登録ごとに個別に確認した。
- 本章の特徴は、主出典の約3分の1（10件）が厚生労働科学研究費の調査研究班による「診療の参照ガイド」（SRC-2463・2465・2467・2470・2472）であることである。これらの診断基準・重症度分類の多くは、同じ研究班が情報提供元である **難病情報センターの指定難病ページ（政府の全文）に同一内容で掲載** されており、本バッチの A・B の多くはこの経路による。難病情報センターの登録は出典マスター内でも区分が割れている（GOV_JP：SRC-1687・1694・1845／UNKNOWN：SRC-055・056）。本バッチでは「概要・診断基準等」の登録先例（GOV_JP 3件）に従って GOV_JP 候補として判定したが、参照ガイド自体の区分とあわせて最終判断は登録側に委ねる（申し送り参照）。
- 参照ガイド自体にも GOV_JP と RESTRICTED の先例が混在する（プリオン病班のガイドライン SRC-1636・1637 は GOV_JP、自己免疫疾患班の診療ガイドライン SRC-1768 は RESTRICTED）。本バッチでは参照ガイド自体の区分訂正（D）は行わず、外部の自由な全文で置き換え・裏づけができるかだけを判定した。

## 特に重要な発見

1. **難病情報センターの診断基準ページで、参照ガイド出典の6件が解決方向に進んだ。** 自己免疫性溶血性貧血（指定難病61）のページには溶血性貧血の診断基準（6項目中4項目以上）と直接クームス試験の二段階が、再生不良性貧血（指定難病60）のページには A（血液）＋B（骨髄）＋C（鑑別）の診断構造と Stage 4・5 の重症度基準が、発作性夜間ヘモグロビン尿症（指定難病62）のページには PNHタイプ赤血球1%以上と LDH 1.5倍以上の両基準が、いずれもカードの主張と同一の内容で掲載されている（RC-011・017・018・023 は A）。後天性赤芽球癆（指定難病283）のページは特徴部分の裏づけになる（RC-025 は B、成因の割合は対象外）。骨髄異形成症候群は指定難病ではないためこの経路がなく、RC-020 は C のままである。
2. **サーベイランス：日本透析医学会の腎性貧血ガイドライン2025年版が刊行されている。** 『腎と透析』99巻3号（2025年9月）の特集が2025年版の要点と作成過程を掲載している。RC-028 のカードは「正式な公表版は存在しない前提で2015年版を正とした」と記録しているが、その前提は崩れており、RC-028 と同じ主出典（SRC-649）を使う KF-021・022 とあわせて2025年版での照合直しの対象である。あわせて KDIGO の CKD 貧血ガイドライン2026年版も2026年1月に刊行されている（Kidney Int. 2026;109(1S):S1-S99、PMID 41485812）。
3. **RC-028 の D はバッチ34と同一出典・同一内容の訂正である。** 主出典 SRC-649（腎性貧血ガイドライン2015年版の英語版）は CC BY 4.0 で、出典マスターの UNKNOWN→OPEN が適切（カード側は既に OPEN で取り込み済み）。PMID・PMCID は存在しないことを本調査でも再確認した（Europe PMC の DOI 照会で該当なし）。
4. **AZA-001（RC-022）は登録レコードで全数値が一致した。** ClinicalTrials.gov NCT00071799 の結果に全生存期間中央値 24.46 か月対 15.02 か月とハザード比 0.58（95%CI 0.43〜0.77）が掲載され、カードの 24.5 か月対 15.0 か月・HR 0.58 と一致する。一方、RACE（NCT02099747）・TRIUMPH（NCT00122330）・ロキサデュスタット中国透析試験（NCT02652806）の3登録はいずれも **結果未掲載（hasResults=false）** で、数値が抄録にしかないため新ルールでは C とした（バッチ35の PEITHO と同じ扱い）。数値自体はいずれも抄録と一致している（主張チェック）。
5. **AASLD 2011 ヘモクロマトーシス実践ガイドライン（PMC3149125）はライセンス表示が食い違うため候補に採用しなかった。** Europe PMC は license=cc by と表示するが、Crossref の version-of-record には TDM ライセンスしか登録がない。RC-005 の裏づけは、Crossref・Europe PMC の双方で CC BY 4.0 を確認できた総説（Int J Lab Hematol 2026、PMC13357651）のみによった。なお同総説では男性のトランスフェリン飽和度の閾値が EASL の50%ではなく45%で、枠組み差異として両値を記録した。
6. **区分の明確化が1件ある（D ではない）。** SRC-988（BCSH コバラミン・葉酸ガイドライン2014、RC-006・007・009）は Crossref の version-of-record が Wiley の利用条件（CC ではない）で Europe PMC でも非OA であり、現行の UNKNOWN は RESTRICTED への明確化が適切である。SRC-2474（甲状腺疾患の貧血、Pol Arch Intern Med）は両経路ともライセンス表示がなく、出版社の論文ページもアクセス拒否（403）で一次表示を確認できなかったため、UNKNOWN の据え置きが妥当だった。
7. **識別子の誤りは0件。補完候補は3出典分。** SRC-164（BSG ガイドライン）に **PMID 34497146・PMCID PMC8515119**（カード側には登録済みだが
出典マスター未登録）、SRC-2468（IPSS-R 原著）に **PMCID PMC4425443**、SRC-2469（AZA-001 原著）に **PMCID PMC4086808**（いずれも著者稿でライセンス表示がなく、自由利用にはならない）。本章の出典に新規の二重登録はなかった（出典マスター全体の DOI 重複は既知の8組のみで、RC 章の出典は含まれない）。

## 主な申し送り

- **参照ガイド5出典の区分判断**：SRC-2463・2465・2467・2470・2472（特発性造血障害に関する調査研究班の診療の参照ガイド）は現行 UNKNOWN で、カード側も「GOV_JP とする判断は取り込み側に委ねる」と記録している。マスター内の先例は、プリオン病班のガイドライン（SRC-1636・1637）が GOV_JP、自己免疫疾患班の診療ガイドライン（SRC-1768）が RESTRICTED と割れている。GOV_JP と判断されれば、本バッチで C とした RC-020 を除く参照ガイド出典のカードの多くは主出典自体が自由区分になる。なお同じ研究班の AIHA ガイド令和4年度改訂版が SRC-2482 として別途登録されており（別版であり二重登録ではない）、版の使い分けは登録側で確認されたい。
- **難病情報センターの区分の統一**：本バッチの A 4件（RC-011・017・018・023）と B 2件（RC-013・025）は、難病情報センターの診断基準ページを GOV_JP とみなすことを前提とする。マスターでは同センターの「概要・診断基準等」が GOV_JP（SRC-1687・1694・1845）である一方、疾患概要ページは UNKNOWN（SRC-055・056）の先例もあるため、診断基準ページの区分の最終判断を登録側に委ねる。

# バッチ35：PV 章（肺血栓塞栓症・肺高血圧症・換気・在宅酸素・HHT）32 件

対象：PV-001〜032（targets.json 掲載分）。判定は A 置き換え可／B 裏づけ追加／C 見つからない／D 区分の訂正。主張文と数値は変更していない。

## 方法と留保

- レポジトリ側の指示（2026-11-11）による新ルールを適用した。**抄録・添付文書・医学百科は根拠にしない。** 判定の根拠は政府の全文文書（AHRQ エビデンスレポート）、CC BY の全文、試験登録レコード（ClinicalTrials.gov）など、全文として読める一次・公的資料のみとし、抄録は数値の食い違いの照合（主張チェック）にのみ用いた。
- PV 章は 2026-11-08 の自由利用調査（BL・GR・HF・PV 79件、旧ルール）の対象でもあった。その結果は登録側で既に反映されており、**PV-016〜023 の主出典は自由区分の出典（SRC-4994〜4998）に置き換え済み**、他の11件（PV-001・003・004・006・009・010・011・012・015・024〜026・029・030・032 のうち該当分）には corroboration として候補が記録済みである。本バッチは targets.json の32件全件を新ルールで再判定し、旧判定と食い違うものは理由とともに記録した。
- 候補のライセンスは Crossref の version-of-record と Europe PMC の license 表示で確認し、判定・識別子に関わるものは **すべて個別に再照会して確定した**（一括照会の誤帰属を避けるため。Kaufman 2025 は初回照会がタイムアウトしたため再照会した）。試験の数値は ClinicalTrials.gov API で登録ごとに個別に確認した。
- 本章の主出典は、2026年 AHA/ACC ほか急性肺血栓塞栓症ガイドライン（SRC-440、PV-002〜010・015 の11件）と 2022 ESC/ERS 肺高血圧ガイドライン（SRC-444）に集中する。SRC-440 は Crossref の version-of-record にライセンス表示がなく（出版側は Wolters Kluwer／AHA）、ガイドライン本文自体は自由利用ではない。SRC-444（ERJ 版）も Europe PMC でオープンアクセスではなくライセンス表示がないため、区分訂正（D）は不成立で RESTRICTED が正しい。

## 特に重要な発見

1. **PEITHO（PV-011・012）は新ルールで A から C に変更した。** 旧調査の A は原著の PubMed 抄録に全数値が載ることに基づいていた。ClinicalTrials.gov の NCT00639743 は本バッチでも **結果未掲載（hasResults=false）** で、登録レコードでは数値を裏づけられない。数値自体は抄録と一致する（主張チェック：7日以内の死亡/血行動態破綻 13/506（2.6%）対28/499（5.6%）、30日死亡 2.4%対3.2%、頭蓋外出血 6.3%対1.2%、脳卒中 2.4%対0.2%）。なお現在カードに記録済みの corroboration は ClinicalTrials.gov を GOV_US の裏づけとしているが、実際に数値の出所は抄録であり、新ルールのもとではこの裏づけ記録は成立しない点を申し送る。
2. **PV-025（INCREASE）は A から B に変更し、6分間歩行距離は両値記録を継続した。** カードの 31.12 m は論文の最小二乗平均差で、CMS の LCD 文書（Medicare 担当 contractor の coverage 文書の Literature Analysis）には載るが、一次資料でも政府の報告書でもないため新ルールでは置き換え根拠にしない。ClinicalTrials.gov（NCT02630316）の主要解析は Hodges-Lehmann 推定量 **21.0 m**（中央値変化量 プラセボ −9.0 m／トレプロスチニル +6.0 m、本バッチで API により再確認）で、同じデータの別推定法である。臨床的悪化 37/163（22.7%）対54/163（33.1%）と対象326人は登録結果と一致する。
3. **Pengo 2004（PV-013・014）は A から B に変更した。** 累積発生率（6か月1.0%・1年3.1%・2年3.8%）は CC BY 総説（Sharma & Levine, Medicina 2021、PMC8067524、license=cc by を個別に確認）の表に同じ値で掲載され裏づけられるが、「2年以降の発生なし」の明記は候補で確認できていない。PV-014 の関連因子は候補の表では3項目（PE既往・若年・大きな血流欠損）で、特発性PEとオッズ比は抄録のみの範囲である。
4. **MRC 在宅酸素試験（PV-027・028）は A から C に変更した。** 旧 A は PubMed 抄録のみに基づく。試験登録は時代的に存在せず、5年死亡 19/42 対 30/45 や死亡予測の記述を載せる CC BY の全文は見つからなかった（Cochrane 総説 CD001744 は CC BY ではない）。数値は抄録と一致している（主張チェック）。
5. **置き換え済みの8件（PV-016〜023）は新ルールでも A を維持できることを再確認した。** Simeone 2024（SRC-4994、Front Cardiovasc Med、CC BY）と Kularatne 2024（SRC-4996、J Cardiovasc Dev Dis、CC BY）の license は Europe PMC で個別に再確認した（いずれも cc by）。試験登録3件（CHEST-1 NCT00855465、AMBITION NCT01178073、STELLAR NCT04576988）は API で結果レコードを個別に確認し、数値がカードと一致した（CHEST-1 の解析値の差 45.69 m ≒ カードの46 m、AMBITION のイベント46件対77件・HR 0.502、STELLAR の推定差 40.8 m）。
6. **主張チェック2件（旧調査からの継続）。** (1) PV-005：カードの「確率が高い（50%超）」に対し、診断総説（Glazier 2024、自由利用でない）では高確率群の有病率「>40%」とされ、定義が異なる可能性がある。原典での再確認を勧める。(2) PV-006：カードは YEARS を COR 2b とするが、二次要約（GuidelineCentral の2026年ガイドライン要約）では YEARS は (2a, B-R) と記載されている。二次情報同士の食い違いであり、原典での再確認を勧める。なお ADJUST-PE の登録（NCT01134068）は結果未掲載のため、PV-006 の裏づけは CC BY 総説のみである。
7. **識別子の補完候補は5出典分。** SRC-440（2026 PE ガイドライン）に **PMID 41712677**、SRC-441（PEITHO）に **PMID 24716681**、SRC-442（Pengo 2004）に **DOI 10.1056/NEJMoa032274・PMID 15163775**、SRC-443（CHEST-1 原著）に **DOI 10.1056/NEJMoa1209657・PMID 23883377**、SRC-448（MRC 1981）に **PMID 6110912**、SRC-449（HHT ガイドライン）に **PMID 32894695**。いずれも出典マスター未登録で、PMID は本バッチで Europe PMC の個別照会により確認した（SRC-448 のみ Europe PMC に DOI 照会の結果がなく、PubMed の論文ページで PMID を確認）。SRC-445・446・447 の PMID はマスター登録値と一致し変更はない。本章の出典に新規の二重登録はなかった。
8. **薬剤の国内承認の注記は本調査では解消しなかった。** PV-023 のソタテルセプト（2025年6月に国内承認・販売名エアウィンとの報道）は報道のみで政府全文では確認しておらず、判定根拠には使わず登録時の確認事項とする。PV-018 のリオシグアト、PV-025 のトレプロスチニル吸入製剤の国内承認状況も同様に未確認のままである。

## 主な申し送り

- **判定の変更（旧調査→本バッチ）**：PV-011・012（A→C）、PV-013・014（A→B）、PV-025（A→B）、PV-027・028（A→C）。いずれも旧ルールの抄録・coverage 文書に基づく A が新ルールで成立しなくなったもので、カードの主張・数値自体に誤りが見つかったわけではない（数値は抄録・登録との照合で一致）。
- **裏づけ記録の見直し**：PV-011・012 のカードに記録済みの corroboration は ClinicalTrials.gov を根拠としているが、登録に結果はなく数値の出所は抄録である。新ルールのもとでは裏づけとして数えられないため、登録側で記録の扱いを判断されたい。
- **識別子の補完**：SRC-440 に PMID 41712677、SRC-441 に PMID 24716681、SRC-442 に DOI 10.1056/NEJMoa032274・PMID 15163775、SRC-443 に DOI 10.1056/NEJMoa1209657・PMID 23883377、SRC-448 に PMID 6110912、SRC-449 に PMID 32894695（いずれも出典マスター未登録、本調査で個別に確認済み）。
- **主張チェック**：PV-005 の高確率の閾値（カード「50%超」／診断総説「>40%」）と、PV-006 の YEARS の推奨クラス（カード COR 2b／二次要約 2a, B-R）は、原典（2026年ガイドライン本文）での再確認を勧める。
- **薬剤の国内承認の注記**：PV-018（リオシグアト）、PV-023（ソタテルセプト、報道では2025年6月承認）、PV-025（トレプロスチニル吸入）の国内承認状況は、本調査では政府の全文文書で確認できなかった（登録時の確認事項）。

## 重要な発見

1. **D 判定39件は4つの英語版ガイドラインに集中**。いずれも J Gastroenterol / Int J Clin Oncol の Springer 系ガイドライン論文で、Crossref の version-of-record ライセンスと Europe PMC の license 表示の両方で **CC BY 4.0** を確認した。マスターでは UNKNOWN のため、OPEN への訂正で既存出典のまま「自由な出典」になる。あわせて4出典とも PMID・PMCID がマスター未登録（null）で、補完候補を各行に記録した。
   - SRC-048（IBD ガイドライン2020英語版、Nakase 2021）→ IN-001〜010 の10件。PMID 33885977・PMCID PMC8137635
   - SRC-049（IBS ガイドライン2020英語版、Fukudo 2021）→ IN-017〜026 の10件。PMID 33538894・PMCID PMC7932982。バッチ3でも同じ訂正を報告済みで、本バッチのカードは英語版原典自体を出典とするため D とした（バッチ3の NG カードは日本語版の書籍を出典としており A・B の扱いだった）
   - SRC-051（大腸ポリープガイドライン英語版、Tanaka 2021）→ IN-036〜045・IN-089 の11件。PMID 33710392・PMCID PMC8005396
   - SRC-052（大腸癌治療ガイドライン2024英語版、JSCCR）→ IN-046〜053 の8件。PMID 41186794・PMCID PMC12644182
2. **A は2件とも「先例に基づく A」**（IN-034 慢性便秘の治療手順、IN-104 胃 MALT リンパ腫の除菌成績）。抄録レコードを置き換え出典と認めない運用では両方とも B に回り、非先例の A は0件になる。バッチ1・2から続く最大の判断点は本バッチでも同じ形で残る。
3. **識別子の誤りは今回なし**。補完候補は多数：上記4出典のほか、SRC-050（PMCID PMC11825134）、SRC-057（PMID 30625484）、SRC-062（PMID 34164674）、SRC-4214・4215・4216・4217・4219・4220・4221・4222・4223・4224・4225・4226 の PMID（一部 PMCID も）、SRC-4968（PMCID PMC3342598）。各行の notes と identifiers に記録した。
4. **区分の明確化（D ではない申し送り）**：SRC-4224（Tang 2025、アミロイドーシス総説）は Europe PMC で **CC BY-NC-ND** と確認され、マスターの UNKNOWN は RESTRICTED への明確化が適切（IN-105・106 の notes）。SRC-050・057・4217 の RESTRICTED はライセンス表示と整合し訂正不要。
5. **両値を記録した枠組みの違いが3件**（数値の誤りではない）：
   - IN-012：カード「発症から7〜8年を過ぎるとリスク上昇」／IBD ガイドライン英語版（SRC-048）は「発症8年後からサーベイランス開始（強い推奨）」。「7年」という下限はガイドラインにない
   - IN-068：膿瘍のドレナージ閾値。カード（日本のガイドライン）は概ね3 cm／5 cm、WSES 2020 は分類の境界が4 cm
   - IN-084：ベズロトクスマブの条件。カード（IDSA）は「過去6か月以内の再発」、ESCMID 2021 は「2回目以降の再発・再発高リスク」が中心。IDSA 自身の PubMed 抄録には推奨文が収載されておらず、裏づけは ESCMID の抄録に依った
6. **ガイドライン論文の抄録が PubMed に収載されていない問題**：ASCRS の肛門膿瘍・痔瘻ガイドライン（SRC-4219）と裂肛ガイドライン（SRC-4221）、ESMO 肛門癌ガイドライン（SRC-4220）、ACG 大腸虚血ガイドライン（SRC-4225）は PubMed レコードに抄録自体がなく、先例ルートが使えない。IN-096・097・099・101 は MedlinePlus・NCI PDQ・CC BY 総説で部分的に裏づけた。
7. **衛生行政報告例（GOV_JP）で受給者数を直接確認**：IN-011（潰瘍性大腸炎 令和5年度 146,702人）と IN-014（クローン病 同 52,108人）はカードと一致。令和6年度の新しい値（151,631人／53,664人）もあるが、カードは令和5年度値として明記されているため陳腐化ではない。年齢ピーク・男女比は年齢表からの導出で、本調査では再集計していない（登録時の e-Stat 確認を推奨）。
8. **IN-112 のガイドライン間の温度差**：進行小腸腺癌の化学療法について、NCI PDQ は「転移例に標準的化学療法はなく臨床試験を推奨」という書きぶりで、FOLFOX・CAPEOX を初回療法とするカード（NCCN 由来）とは温度差がある。裏づけは「限局例は外科切除が基本」の部分にとどまる。
9. C の10件は、日本のガイドライン固有の定義・格付け（IN-027・028・033）、GL が集約した個別調査の数値（IN-029・060・062・063・066）、国内承認の列挙（IN-035）、抄録に推奨文のない合意報告（IN-103）が中心だった。IN-028 では StatPearls に Rome IV 基準の転載があるが、二次資料として原則出典にしない方針のため候補化していない（判断材料として JSON に記録）。

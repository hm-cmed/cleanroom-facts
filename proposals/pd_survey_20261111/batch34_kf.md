## 方法と留保

- レポジトリ側の指示（2026-11-11）による新ルールを適用した。**抄録・添付文書・医学百科は根拠にしない。** 判定の根拠は政府の全文文書（CDC の臨床家向けページ、NCI PDQ）、CC BY の全文、試験登録レコード（ClinicalTrials.gov）など、全文として読める一次・公的資料のみとした。抄録は数値の食い違いの照合（主張チェック）にのみ用いた。
- 本章は第III相試験のカードが多く（PRESERVE・STARRT-AKI・ATN・EMPA-KIDNEY・OPAL-HK・FIDELIO-DKD・エクリズマブ第2相・ロキサデュスタット）、ClinicalTrials.gov の結果レコードが裏づけの主経路になった。登録レコードの解析値（未調整のオッズ比、最小二乗平均など）が論文の調整値・観測平均と異なる場合は、推定法の違いとして両値を記録した。
- 主出典のライセンスは Crossref の version-of-record と Europe PMC の license 表示で相互確認し、判定に関わるものは個別に再照会した。SRC-649 は Crossref の license 欄が空で、Europe PMC・PubMed・PMC のいずれにも収載がなかったため、論文ページ（Springer Nature Link）で全文が読めることを実際に開いて確認し、OpenAlex と Unpaywall の双方が出版版（publishedVersion）のライセンスを cc-by と記録していることで CC BY 4.0 と確定した。SRC-573（KDIGO 2024）は Crossref の VoR で CC BY-NC-ND を再確認した（バッチ25の KDIGO 系の確認とも一致）。
- 識別子の訂正（調査中の再検証による）：当初、SRC-649 に別論文の PMID・PMCID を帰属させる誤りと、SRC-653 の DOI の取り違えがあったため、個別照会で再検証して本ファイルと JSON の両方を訂正した。確定値は発見1・発見8と各行に記したとおりである。
- KF-018 の uncertainty（エンパグリフロジンの国内承認・保険適用は未確認）は、ユーザーが国内適用を確認済みで訂正候補として別途申し送り済みのため、本調査では再判定していない。本バッチの KF-018 の判定は EMPA-KIDNEY 試験の数値の裏づけに関するものだけである。

## 特に重要な発見

1. **D は2件、いずれも同じ主出典 SRC-649（日本透析医学会 腎性貧血ガイドライン2015年版の英語版、Renal Replacement Therapy 2017、KF-021・022）。** 同誌は BioMed Central の誌面で、論文の全文は **CC BY 4.0** であることを、OpenAlex と Unpaywall の双方が出版版のライセンスを cc-by と記録していることと、論文ページで全文が自由に読めることで確認した。現行の UNKNOWN は実態と異なり、OPEN への訂正が適切である。なお本論文は PubMed・PMC・Europe PMC のいずれにも収載されておらず、**PMID・PMCID は存在しない**。カード側の「出典論文のPMIDはPubMedで確認できず null とした」という記録が正しいことを再確認した（識別子の補完候補はない）。
2. **大規模試験7件は試験登録レコードで主要な数値が裏づけられた（いずれも B）。** PRESERVE（KF-004、NCT01467466）は複合イベント数（炭酸水素ナトリウム111・生理食塩液116、アセチルシステイン115・プラセボ112）とアセチルシステインの OR 1.02 がカードの割合と一致。STARRT-AKI（KF-005、NCT02568722）は90日死亡数643・639が 43.9%・43.7% と一致。ATN（KF-006、NCT00076219）は60日死亡302・289と OR 1.09 が 53.6%・51.5% と一致。EMPA-KIDNEY（KF-018、NCT03594110）は登録者数6,609人と主要複合 HR 0.72 が完全一致。OPAL-HK（KF-019、NCT01810939）は血清カリウム変化 −1.01 mmol/L と目標域到達76%が一致。FIDELIO-DKD（KF-020、NCT02540993）は主要複合の発生数504対600と HR 0.825 がカードと一致。エクリズマブ（KF-012）は血漿療法感受性群の TMA イベントフリー80%が、抵抗性群・感受性群あわせて4つの登録レコード（NCT00844545・00844844・00838513・00844428、計17例・20例）で一致した。
3. **主張チェック（両値記録）2件、いずれも推定法の違いである。** (1) PRESERVE の炭酸水素ナトリウムの OR は、カードの調整 OR 0.93 に対し登録側の解析は 0.95（0.73–1.24）。(2) エクリズマブ抵抗性群の血小板増加は、カードの 73×10⁹/L（論文の観測平均）に対し登録側は最小二乗平均 65.18×10⁹/L。どちらも結論（差がないこと、血小板が増えること）は変わらない。OPAL-HK の登録者数は登録側243人で、カードの解析対象237人とは母数の取り方が異なる。
4. **CDC の臨床家向けページ（GOV_US）で KF-010 が B。** CDC の E. coli／STEC 臨床家向けガイダンス（2024年5月14日更新）を全文で開き、抗菌薬が HUS のリスクを高めうること、腸管運動抑制薬は STEC 感染では避けること、早期の静注輸液が腎不全のリスクを下げうること、HUS の治療は支持療法（輸液・電解質管理、透析・輸血）がカードと一致することを確認した。O157:H7 が世界的に最も関連が強いことと、NSAIDs・麻薬性鎮痛薬の回避は CDC ページの範囲外である。
5. **NCI PDQ（GOV_US）で KF-041 が B（リンパ浮腫の部分）。** PDQ の Lymphedema 専門家版（cancer.gov）で、リンパドレナージの障害による間質への貯留という機序、硬く圧痕を残さない浮腫、二次性原因（腫瘍による閉塞、リンパ節郭清を含む手術、放射線治療）がカードと一致した。浮腫全体の鑑別の進め方、静脈不全、睡眠時無呼吸、MR 静脈造影は PDQ の範囲外である。
6. **ロキサデュスタット（KF-023）は登録はあるが結果未掲載で C。** ClinicalTrials.gov の NCT02652806 に登録があり登録者数305人はカードと一致するが、結果レコードが掲載されておらず、ヘモグロビン変化量などの数値は裏づけられない。中国の第III相試験で、結果は登録側に載らない形だった。
7. **KDIGO 系の区分は現行が正しいことを再確認した。** SRC-573（KDIGO CKD 2024）は Crossref の VoR で CC BY-NC-ND、SRC-651（KDIGO CKD-MBD 2017）も CC BY-NC-ND で、いずれも RESTRICTED が正しい。KF-013 の CGA 分類（G3a／G3b の分割と A1〜A3 の mg/g 区分）を同じ形で述べる政府の全文は見つからなかった（CDC の CKD 用語集は旧 KDOQI の5ステージで G3a／G3b の分割がなく、枠組みが異なる）。SRC-661（KF-036）は PMC に著者稿（PMC4491294）が収載されるがライセンス表示がなく OA ではなく、UNKNOWN の据え置きが妥当（PMCID は出典マスター未登録の補完候補だが、補完しても自由利用にはならない）。
8. **識別子の補完候補は他に1件。** SRC-653（KF-027）の DOI 10.12659/msm.881937 を Europe PMC の個別照会（2回、一致）で確認した（出典マスター・カードとも未登録）。SRC-665（KF-041）は Europe PMC でも DOI がなく、カードの null が正しい。出典マスター全体の DOI 走査で二重登録は既知の8組のみで、KF 章の出典は含まれない。本バッチで新規のサーベイランス事項（ガイドラインの新版等）は確認されなかった。

## 主な申し送り

- **区分の訂正（D）**：SRC-649（日本透析医学会 腎性貧血ガイドライン2015年版英語版）は CC BY 4.0 で、UNKNOWN→OPEN への訂正が適切（KF-021・022）。訂正すれば、この2件は主出典自体が自由区分になる。
- **識別子の補完**：SRC-653 に DOI 10.12659/msm.881937、SRC-661 に PMCID PMC4491294（著者稿で自由利用にはならない）。いずれも本調査で Europe PMC の個別照会により確認済み。SRC-649 は PMID・PMCID が存在しないことを再確認し（PubMed・PMC・Europe PMC のいずれにも未収載）、カードの null が正しい。

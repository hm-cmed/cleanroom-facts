## 方法と留保

- ライセンスは Crossref の version-of-record と Europe PMC の license フィールドで個別に確認した。PMC に全文や著者原稿があっても、ライセンス表示がなければ自由利用ではない前提で扱った（SRC-1103・1108 は PMC ページの著作権表示を実際に開いて確認）。
- 抄録は NCBI E-utilities（efetch）の XML と Europe PMC REST API（resultType=core）で取得して照合した。CC BY 候補（Ji 2020、Lubis & Putra 2026）は Europe PMC の全文 XML を取得し、定義・臨床像の記述まで確認した。NCI PDQ はサマリーのページを実際に開いて一般情報・予後の項を確認した。
- StatPearls 章（SRC-1096・1097・1100・1104・1105・1106・1123）は本プロジェクトの扱い（二次資料は原則出典にしない）に従い、それ自体を候補としては扱わず、一次資料・政府資料の裏づけを探した。DT-005・012 では CC BY の一次総説が見つかり B としたが、残る5件のうち4件は C となった（発見4）。
- 薬剤名のあるカードでは国内承認・保険適用の記述も出典側情報と照合した。セミプリマブは PMDA の審議結果報告書で承認内容を確認し、チモロールは JAPIC/KEGG の添付文書情報で効能を確認した（添付文書自体は裏づけ出典として使っていない）。光線力学療法の光感受性薬剤（DT-006）は国内の診療情報で承認を確認できなかったため「未確認」のままが妥当と記録した。
- 候補のうち出典マスターに無いもの（Ji 2020、Lubis & Putra 2026、NCI PDQ、ISSVA 2022総説）は新規登録候補であり、SRC 番号は付けていない（採番は登録側）。
- 皮膚リンパ腫診療ガイドライン2025の英語概要（PMID 41204060）は出典マスター未登録であることを DOI・PMID の grep で確認した。同ガイドライン本体（日本皮膚科学会の公開 PDF）の目次で臨床疑問の構成も確認した。
- PDF の新規保存は行っていない。Drive 台帳への IN 番号も付けていない。

# バッチ41 IH（虚血性心疾患・冠動脈疾患・川崎病）29件 再評価（新ルール）

- 対象: IH-001〜024・026〜030（29件）。IH-025（SRC-212、GOV_JP）と IH-031（SRC-4964、OPEN）は今回の対象外
- 判定: A 置き換え可 2件 / B 裏づけ追加 22件 / C 見つからない 5件 / D 区分の訂正 0件
- 適用ルール: 2026-11-11 の新ルール（抄録・添付文書・医学百科は根拠にしない。政府の全文文書・報告書、CC BY の全文、試験登録レコードなど全文として読める資料のみ候補）。抄録は数値の照合（主張チェック）にのみ使用
- 出典の説明は出典マスター（sources.yaml）の記載から機械的に取り、補完候補の識別子は PMID で個別に再照会して文献との一致を確認した

## 調査方法

- 主出典14件（SRC-202〜211・213〜216）は、Europe PMC の個別レコード（ライセンス・OA 表示）と Crossref の version-of-record ライセンスで確認した。SRC-208（PRASFIT-ACS）は J-STAGE 掲載ページも確認した。
- 候補は Europe PMC の全文 XML を取得し、主張の要素ごとに数値・条件を照合した。候補のライセンスは Europe PMC の表示と Crossref の VoR の両方で確認し、食い違う場合は採用していない。
- 主出典が試験のカードは ClinicalTrials.gov の登録・結果レコード（COURAGE NCT00007657、ISCHEMIA NCT01471522、STOPDAPT-2 NCT02619760、AFIRE NCT02642419、DIAD NCT00769275）を確認し、結果が未掲載の登録は裏づけに使っていない。
- 主張文と数値は変更していない。

## 特に重要な発見

1. **A は2件**。IH-005 は ISCHEMIA の登録（NCT01471522）の結果レコードで主張全体が置き換えできる（症例数・適格条件・主要複合の 6か月/5年 率・追跡中央値まで一致）。IH-021 は AFIRE の全要素（対象・症例数・有効性と大出血の全数値とハザード比・早期終了とその理由）が CC BY の全文総説に明記されているため A とした（バッチ40 XS-031 の先例に同じ）。
2. **試験登録の結果の有無が判定を分けた**：STOPDAPT-2（IH-018）・COURAGE（IH-004）・DIAD（IH-024）はいずれも登録に結果が未掲載で、登録では裏づけられない。IH-018 は抄録の数値はすべて一致したが、CC BY の全文への数値の再掲もなく C とした。
3. **ライセンス表示の食い違いで候補を1件不採用**：川崎病のステロイドの系統的レビュー・メタ解析（Cardiology Research 2026、PMC13719651）は、Europe PMC が cc by と表示する一方で、Crossref の version-of-record が CC BY-NC 4.0 だった。両経路が食い違うため IH-028 の候補にせず、より弱い別の CC BY 総説を B として使った。
4. **JCS ガイドライン系のカードは、推奨の骨格を述べる CC BY 総説で部分的に裏づけ（B が中心）**。JCS のクラス・レベルの割当て、日本の用量（プラスグレル 20 mg 負荷など）・期間（アスピリン 2〜3か月など）・転送の運用は、国際的な自由全文に再掲がなかった。JCS 固有の内容だけで構成される IH-015（日本用量の P2Y12 順位）・IH-022（二次予防の3推奨の組合せ）は C とした。
5. **サーベイランス**：(1) 2025 ACC/AHA/ACEP/NAEMSP/SCAI の急性冠症候群ガイドライン（JACC 2025）が刊行され、2013年 STEMI・2014年 NSTE-ACS の各ガイドラインを置き換えた。JCS 2018 準拠のカード（SRC-206・207）の国際的な対応ガイドラインの全面改訂で、照合直しの優先度判断の材料となる。(2) AHA の川崎病サイエンティフィックステートメントが2024年に更新された（Circulation 2024;150:e481–e500、© AHA で候補にはならない）。(3) 心筋梗塞の普遍的定義の第5版（2026、Glob Heart、CC BY）が刊行され、IH-009 のトロポニンの裏づけとして使った。
6. **主張チェック**：本質的な数値の食い違いはなし。両値を記録する項目は2件（ISCHEMIA の主要複合の5年群間差の信頼区間：登録 -4.7〜1.0、論文 -3.7〜0.2。アスピリン維持量の範囲：カード 81〜162 mg/日、候補の米国表 81〜325 mg/日）。抄録照合では PRASFIT-ACS・STOPDAPT-2・RAISE・KAICA・第27回川崎病全国調査の数値はすべてカードと一致した。
7. **識別子の誤りは0件**。補完候補は PMCID 3出典分：SRC-204（NEJM ISCHEMIA 論文）= PMC7263833、SRC-209（JAMA STOPDAPT-2 論文）= PMC6593641、SRC-211（JAMA DIAD 論文）= PMC2895332。いずれも Europe PMC の個別レコード（PMID からの照会）で実在と文献の一致を確認した。SRC-211 の PMCID はカード IH-024 には登録済みで出典マスター側が未登録、他2件はカード・マスターとも未登録。いずれも著者稿等の収載でライセンス表示がなく、自由利用にはならない。
8. **区分の訂正（D）は 0件**。主出典14件はすべて CC でないことを Crossref・Europe PMC で個別に確認し、現行区分（RESTRICTED 等）が正しい。SRC-208（PRASFIT-ACS）は Crossref・Europe PMC・J-STAGE 掲載ページのいずれでもライセンス表示を確認できず、UNKNOWN の据え置きが妥当。二重登録は既知の8組のみで、本章分は含まれない。

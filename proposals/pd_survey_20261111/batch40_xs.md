# バッチ40：XS（消化管出血・鉄欠乏性貧血・抗血栓薬と内視鏡・内視鏡の質・低栄養と周術期栄養）30件 ― パブリックドメイン出典の裏づけ調査

- 対象：`targets.json` のうち章プレフィックス XS の30件（XS-001〜023・031〜037）
- 調査日：2026-11-11
- 判定：**A 置き換え可 1件／B 裏づけ追加 16件／C 見つからない 13件／D 区分の訂正 0件**
- ルール：2026-11-11 の新ルールを適用。抄録・添付文書・医学百科は根拠にせず、政府の全文文書・報告書、CC BY の全文、試験登録レコードなど全文として読める資料のみを候補とした。A は自由な全文で主張全体を置き換えできるものだけ、部分的な裏づけは B。主張文と数値は変更していない。
- 本章の構成：急性下部消化管出血（XS-001〜008、BSG ガイドライン2019）、鉄欠乏性貧血と消化管の精査（XS-009〜015、BSG ガイドライン2021）、抗血栓薬服用者の内視鏡（XS-016〜021、BSG/ESGE ガイドライン2021）、大腸内視鏡の質の指標（XS-022・023、ESGE 2017）、低栄養の診断（XS-031〜033、GLIM 基準2019）、周術期の栄養管理（XS-034〜037、ESPEN 実践ガイドライン2021）。主出典は6件に集約される。

## 調査方法

- 主出典6件（SRC-163・164・165・167・168・169）について、Europe PMC の個別照会でライセンス表示・PMID・PMCID を確認し、DOI のあるものは Crossref の version-of-record ライセンスも個別に確認した。両経路で食い違う場合は採用していない。
- CC BY 候補は Europe PMC の全文 XML を取得し、主張の要素ごとに検索して照合した。政府文書の候補である NIH ODS（米国国立衛生研究所栄養補助食品局）の鉄の専門家向けファクトシートは、実際に開いて本文を確認した。
- GLIM の5年アップデート（Clin Nutr 2025）は、ライセンスは Crossref の VoR と Europe PMC の双方で CC BY 4.0 を確認できたが、全文の取得経路が確保できず（出版社サイトで本文を確認できなかった）、判定の根拠には使わず申し送りに回した。
- 出典の説明（誌名・著者・文書の種類）は、出典マスター（data/sources/sources.yaml）の当該 SRC の記載からそのまま取った。カード側の記載とマスターの記載に食い違いはなかった。
- 薬剤の国内承認に関する確認は行っていない（本章の判定に薬剤の承認状況を根拠とするものはない）。

## 特に重要な発見

1. **A は1件（XS-031、GLIM の診断の枠組み）で、決め手は CC BY の総説が基準の枠組み全体を再掲していたことだった。** Chaves Santos ら（J Parenter Enteral Nutr 2026、CC BY 4.0 を Crossref の VoR と Europe PMC の双方で確認）の全文に、2段階の進め方（妥当性が確かめられたスクリーニング法でリスクを見つけ、次に診断と重症度判定を行う）、表現型3基準・病因2基準の内訳、少なくとも1つずつを満たせば低栄養と診断すること、重症度は表現型の基準で分けることがすべて明記されていた。Enge ら（Eur J Nutr 2024、CC BY）も同じ枠組みを明記する。
2. **サーベイランス：GLIM 基準の5年アップデートが公表されている。** 「GLIM consensus approach to diagnosis of malnutrition: A 5-year update」（Cederholm、Jensen ら、Clin Nutr 2025、DOI 10.1016/j.clnu.2025.03.018、PMID 40222089）は Crossref の VoR と Europe PMC の双方で **CC BY 4.0** と確認できた（JPEN への併載版は CC BY-NC で不可）。XS-031〜033 は2019年のコンセンサス報告（SRC-168）準拠のため、このアップデートでの照合直しの対象である。ただし Clin Nutr 版の全文は本調査では取得経路を確保できず、基準の閾値が変わっていないかの全文照合は未完である。登録時に全文で照合されたい。
3. **BSG 系ガイドライン3件（SRC-163・164・165）は CC BY-NC 4.0 で、現行の RESTRICTED が正しい。** Crossref で SRC-165・164 の VoR ライセンス（CC BY-NC 4.0）を確認し、SRC-163 も出典マスターとカードの記録どおり CC BY-NC 4.0 である。SRC-164・165 は PMC にも収載されている（PMC8515119、PMC8355884）が、いずれも Europe PMC の表示は CC BY-NC であり、自由利用にはならない。
4. **下部消化管出血（XS-001〜008）は、英国の全国監査の数値が分かれ目になった。** Antonucci ら（Diagnostics 2026、CC BY）の総説が、ショック指数と CT 血管造影の位置づけ（XS-002）、大腸内視鏡のタイミングに関するエビデンスの整理（XS-006）、原因の頻度順（XS-008）の骨格を支え、この3件は B。一方、発生率と死亡率の数値群（XS-001）と「疑われた出血の11〜15%は上部消化管出血だった」（XS-003）は監査・引用研究固有で再掲がなく C。監査の原著（Oakland ら、Gut 2018、PMID 28148540）自体も OA ではない。Oakland スコア（XS-004）は Mohammadyari ら（Front Med 2025、CC BY）が構成要素と8点以下のカットオフを再掲し B（「95%」の由来づけは候補と異なり両値を記録）。制限的輸血の閾値（XS-005）は自由な全文への再掲を確認できず C（NICE NG24 に同趣旨の閾値があるが独自ライセンスのため候補にしていない）。
5. **鉄欠乏性貧血（XS-009〜015）は、政府文書と CC BY の監査論文が部分的に支えた。** NIH ODS の鉄の専門家向けファクトシート（GOV_US）がフェリチンの30 µg/L の目安と炎症の影響を裏づけ XS-010 は B。Iqbal（Cureus 2026、CC BY）の監査論文が、両方向内視鏡を最初の検査とすることと CT コロノグラフィーによる代替（XS-011）、陰性後のカプセル内視鏡等の追加検査（XS-014）の枠組みを裏づけ B。経口鉄剤の投与法（XS-015）は García-Erce ら（J Clin Med 2026、CC BY）が B（用量の範囲はカード50〜100 mg に対し候補40〜80 mg で両値を記録）。一方、WHO の貧血基準は WHO 文書が CC BY-NC-SA のため使えず XS-009 は C、閉経前女性の精査の切り分け（XS-012）とセリアック病の全例スクリーニング等（XS-013）も BSG 本文固有で C。
6. **抗血栓薬服用者の内視鏡（XS-016〜021）は全件 C だった。** 処置の出血リスク分類、休薬・再開のスケジュール、高血栓リスク状態の列挙はいずれも BSG/ESGE ガイドライン本文固有で、CC BY 全文への再掲は見つからなかった。コールドスネアの安全性など個別の手技については CC BY の原著研究があるが、ガイドラインの分類・推奨そのものの再掲ではないため候補にはしていない。
7. **大腸内視鏡の質の指標（XS-022・023）は、ESGE 指標への遵守状況を調べた CC BY 論文が一部を再掲した。** Zagari ら（Front Med 2022、CC BY）の全国調査論文に、主要業績指標の枠組みと、盲腸到達率90%以上・ADR 25%以上という最低基準、合併症率 約0.5% が ESGE の最低基準であることが明記され、両件とも B（前処置の基準値・目標値、抜去時間、ポリープ切除の基準値は再掲がなく留保）。主出典 SRC-167 自体は、Crossref の VoR が Wiley の利用条件のみで Europe PMC でも OA でなく、自由利用ではない。
8. **周術期の栄養管理（XS-034〜037）は CC BY 総説が ESPEN の記載を再掲し、全件 B だった。** Baji ら（Cureus 2022、CC BY）が重度の栄養リスクの患者像と7〜14日の術前栄養（XS-034）、絶食時間（清澄水2時間・固形食6時間、XS-035）を ESPEN の推奨として明記し、Brăgaru ら（Nutrients 2026、CC BY）が術後24時間以内の早期摂取と経腸優先（XS-036）を、Borriello ら（Nutrients 2025、CC BY）がリフィーディングの段階的増量・電解質とチアミンの管理（XS-037）を裏づけた。ESPEN 固有の数値ルール（XS-036 の増量ペースと静脈栄養併用の条件）は再掲がなく留保している。
9. **区分の訂正（D）は0件。明確化の申し送りが2件ある。** SRC-167（ESGE 質指標）と SRC-169（ESPEN 外科栄養）はいずれも出典マスターで UNKNOWN だが、Crossref と Europe PMC の両経路で CC ライセンスの表示がなく（SRC-167 の VoR は Wiley の利用条件のみ、SRC-169 は Elsevier の TDM 表示のみ）、出版社の著作物であることが確かめられたため、UNKNOWN→RESTRICTED への明確化が適切である（バッチ36・39の扱いに倣い D には数えず申し送りとする）。SRC-163・164・165・168 は現行の RESTRICTED が正しいことを確認した。
10. **識別子の誤りは0件。補完候補は6出典分ある。** いずれも Europe PMC の個別レコードで実在を確認し、出典マスター・カードの双方に未登録のもの：SRC-163 PMID 30792244、SRC-164 PMID 34497146・PMCID PMC8515119、SRC-165 PMID 34362780・PMCID PMC8355884、SRC-167 PMID 28507745・PMCID PMC5415221、SRC-168 PMID 30181091（PMCID はない）、SRC-169 DOI 10.1016/j.clnu.2021.03.031・PMID 34242915。PMC に収載のあるもの（SRC-164・165 は CC BY-NC の刊行版、SRC-167 はライセンス表示のない収載）も自由利用にはならない。**SRC-169 の補完では同題の Letter との取り違えに注意**：同じ題名「ESPEN practical guideline: Clinical nutrition in surgery」の Letter（Zhang ら、Clin Nutr 2021、DOI 10.1016/j.clnu.2021.07.012、PMID 34455265）が別に存在し、ガイドライン本体は Weimann らの DOI 10.1016/j.clnu.2021.03.031・PMID 34242915 である。本章の出典に新規の二重登録はなく、出典マスター全体の DOI 重複は既知の8組のみで本章分は含まれない。

## 方法と留保

- 新ルール（抄録・添付文書・医学百科は根拠にしない）を適用した。A・B の根拠は、実際に開いて確認した政府の全文文書（CDC MMWR 2003 の cdc.gov 掲載全文で、治療原則・母乳継続・検査不要の記述を照合）のみである。本章は観察研究・登録研究・メタ解析が主出典で単一試験のカードがないため、ClinicalTrials.gov の結果レコードの経路は使えなかった。
- ライセンスは Crossref の version-of-record と Europe PMC の license 表示で個別に相互確認した。誌名や PMC 収載の有無では判断していない（例：CMAJ は誌としてオープンアクセスでも2008年の論文には両経路ともライセンス表示がなかった。Hernia の Springer 論文は Crossref が TDM 用のみだった。PMC に著者稿があってもライセンス表示のないものは自由利用ではない前提で扱った）。
- 確認経路の記述は実際に確認できた手段だけを書いた。具体的には、PE-005・006 は MMWR の全文を開いて記述を照合したこと、D の2件はライセンス表示の相互確認によるもので数値の全文照合はしていないこと、PE-026 の数値の一致は CiNii 抄録による主張チェックにとどまること、PE-034 の PMID は PubMed の書誌レコード（題名・著者・誌名の一致）で同定したことを各行に明記した。
- 数値の照合（主張チェック）は、MMWR 全文との突き合わせと PE-026 の抄録照合が中心で、結果は発見2・7のとおりである。抄録は判定の根拠には使っていない。
- 候補のうち出典マスターに無いもの（CDC MMWR 2003）はいずれも新規登録候補であり、SRC 番号は付けていない（採番は登録側）。MMWR 2003 は小児の急性胃腸炎・経口補水に関する政府全文で、他の章の裏づけにも使える可能性がある。
- 出典マスターの本章出典については DOI・PMID を個別に照合し、二重登録はなかった。マスター全体の既知の重複は8組（バッチ16の記録）で、本章の出典は含まれない。
- PDF の新規保存は行っていない。Drive 台帳への IN 番号も付けていない。

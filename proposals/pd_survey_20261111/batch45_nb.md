# バッチ45（NB 27件）の調査結果

集計：A 置き換え可 2件／B 裏づけ追加 13件／C 見つからない 12件／D 区分の訂正 0件

判定ルールは新ルール（2026-11-11、レポジトリ側決定）を適用した：**抄録・添付文書・医学百科は根拠にしない**。使える候補は政府の全文文書・報告書（CDC・NEI・ClinicalTrials.gov 等）、CC BY の全文など、全文として読める資料のみ。A は「全文の自由資料で主張全体を置き換えできるもの」だけとし、一部しか裏づけられないものは B とした。既に裏づけ・置き換えが登録されているカードはなかったため、再評価の対象はなかった。

## 調査方法

- 対象27件の主出典は、出典マスター（data/sources/sources.yaml）の記載で同定し、Europe PMC の個別レコードと Crossref の version-of-record ライセンスで扱いを確認した。出典の説明はマスターの記載から機械的に取った。
- 候補は Europe PMC の全文 XML（CC BY 総説等）、CDC と NEI の政府ページ（GOV_US、実際に開いて本文を確認）、ClinicalTrials.gov の登録・結果レコード（API で直接確認）で、主張の要素ごとに照合した。
- 候補のライセンスは Europe PMC の表示と Crossref の VoR の両方で確認し、食い違う場合は採用しなかった。補完候補の PMID・PMCID は、PMID または DOI で個別に再照会し、タイトルと著者が当該文献と一致することを確認してから記載した。
- 主張文と数値は変更していない。数値が候補と食い違う場合は、両値を「数値照合」欄に記録した。

## 特に重要な発見

1. **置き換え可（A）が 2 件**あった。**NB-029**（TOP 試験、未熟児の輸血閾値）は、ClinicalTrials.gov の結果レコード（NCT01702805）に登録症例数1,824例、主要評価項目の発生数（高閾値群423/845例・低閾値群422/847例＝50.1%・49.8%）と、調整相対リスク1.00（95%信頼区間0.92〜1.10）まで掲載され、カードの全数値と一致した。**NB-007**（早産児の呼吸窮迫症候群の管理）は、同一ガイドラインの前版である欧州コンセンサスガイドライン2022年版が CC BY で、その全文に周産期の最適化・体温維持・臍帯結紮前の自発呼吸・非侵襲的サポート・細径カテーテルによる早期サーファクタント・肺保護管理の全要素が明記されていた。
2. **同一ガイドライン系列で版ごとにライセンスが異なる例があった。** 欧州 RDS ガイドラインは2022年版が CC BY（OPEN）であるのに対し、主出典の2025年版（SRC-3360）は Crossref の VoR と Europe PMC の双方で CC BY-NC を確認し、カード側の記録どおり RESTRICTED が正しい。ほかに主出典のライセンスを両経路で確認したものでは、SRC-3361（CC BY-NC-ND）、SRC-3362（CC BY-NC-SA）、SRC-3441（CC BY-NC）、SRC-1028（CC BY-NC-ND）はいずれもマスターの RESTRICTED と一致し、**D はゼロ**だった。区分の明確化に相当するもの2件（SRC-3363、SRC-3444）は D に数えず申し送りにとどめた（申し送り参照）。
3. **政府資料が B の主な経路になった。** NB-020 は CDC の GBS ガイドライン（MMWR 2010、パブリックドメイン）、NB-021 は CDC のビタミンK欠乏性出血症のページ群、NB-022 は CDC の MMWR 2013年報告（保護者の拒否による遅発型の集積）、NB-026 は NEI の未熟児網膜症ページが裏づけになった。いずれも出典マスター未登録で新規 SRC 登録候補である。
4. **試験・レビューの数値が抄録と政府・CC BY 全文で分かれた例。** NB-011（CAP 試験）は登録・結果レコードを確認できなかったが、CC BY 総説が試験の主要な数値（2,006人、36% 対 47%、調整オッズ比0.63、陽圧換気中止が1週早い）を再掲しており B（信頼区間と生の分母・分子は再掲がなく A にはしない）。逆に NB-016（同種免疫性溶血性疾患への IVIG のコクランレビュー）は、統合値（典型相対リスク0.35）と質の留保を再掲する自由な全文がなく、抄録は根拠にできないため C とした。NB-008（LISA 対 INSURE の系統的レビュー）も統合値の再掲がなく C（別の CC BY 系統的レビューは比較の枠組みと数値が異なり裏づけにならない）。
5. **主出典の識別子補完候補が24出典分ある**（申し送り参照）。大半はカード側に PMID・PMCID の記載があるがマスター未登録のもので、いずれも個別に再照会してタイトル・著者の一致を確認した。SRC-1028 の PMCID PMC9887297 はカード側にもなく新規に確認した。主出典の DOI・PMID に誤りはなく、本バッチの範囲で新たな二重登録はなかった（NB-013・014 が同一出典 SRC-3431 を共有するのは登録上の共有であり二重登録ではない）。
6. **サーベイランスが1件ある。** NB-012（新生児慢性肺疾患）の病型分類について、厚生労働科学研究班の新たな分類案（2023年）の検証論文（PMID 41566982、J Perinatol 系、CC BY-NC のため候補にできない）が公表されており、カード側の記録どおり新分類案の本文での照合直しが必要である。なお NB-007 の候補化にあたっては、同じガイドラインでも版でライセンスが変わるため、今後の版更新時は版単位の再確認が要る。

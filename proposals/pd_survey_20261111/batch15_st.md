## 方法と留保

- ライセンスは Crossref の version-of-record と Europe PMC の license フィールド、政府サイト（MedlinePlus・DailyMed）の表示で個別に確認した。PMC に全文や著者稿があっても、ライセンス表示がなければ自由利用ではない前提で扱った（本章では PMC 収載が著者稿にとどまる出典が11件あった）。
- NCBI（PubMed）の抄録は NCBI E-utilities（efetch）と Europe PMC REST API（resultType=core）で照合した。AHA/ASA ガイドライン2件（PMID 35579034・34024117）は efetch の返却に抄録文が含まれず、抄録自体が未収載であることを確認した。DailyMed は公式 API で SPL XML を取得し、適応・用法用量の節を目視した。
- 候補のうち出典マスターに無いもの（PMID 40392372・42927341・42587568・42394924、MedlinePlus の項目ページ、DailyMed のラベル2件、難病情報センターのページ）は新規登録候補であり、SRC 番号は付けていない（採番は登録側）。難病情報センターのページと PMDA の個別ページは本調査では未目視で、登録時の確認事項として残した。
- 薬剤名のあるカードでは国内承認・保険適用の記述も出典側情報と照合したが、新たな食い違いはなかった（発見8）。
- PDF の新規保存は行っていない。Drive 台帳への IN 番号も付けていない。

# 自由に使える出典の調査（未調査の68枚）結果

- 調査日：2026-11-23
- 対象：ES・UG・HP の旧形式カード、ME カードほか68枚（ES 23枚、HP 9枚、HS 2枚、ME 14枚、ND 2枚、NI 2枚、UG 16枚）
- 依頼文：free_sources_68.md（2026-11-23、登録側作成）
- 照合の前提：hm-cmed/cleanroom-facts の最新版（commit b33b922、2026-11-23）を取得し、対象カードの主張文全文・出典・区分を最新版で確認した。出典マスターとの重複確認も同じ最新版（data/sources/sources.yaml）で行った。
- 方法：依頼文 §2 の順序（ClinicalTrials.gov の結果登録 → FDA → NIH／CDC／AHRQ → 日本の公的資料 → CC BY／CC0 論文 → 現在の出典の再確認）に従った。新ルール（2026-11-11）を適用し、抄録・添付文書・医学百科は根拠にしていない。使ったのは政府の全文文書・報告書、CC BY 全文、試験登録レコード等の全文で読める資料のみで、PMC の著者原稿（author manuscript）は自由な全文として扱っていない。ライセンスは論文・資料ごとに、Crossref の刊行版（version of record）license、Europe PMC のレコード、PMC 全文のライセンス要素、出版社・公的機関の公式ページで個別に確認した。識別子（NCT・DOI・PMID・PMCID）は、そのページ／API レコードで確認できたものだけを書いた。
- **主張文と数値は変更していない。** 数値が資料間で違う場合は「不一致」として両方の値をそのまま書いた。

## 重要な発見・申し送り

1. **HS-001 の D 判定は、2つの決定の切り分けについて最終確認を要する。** 現行出典 SRC-2641（救急領域における止血機能異常症の診療ガイド 第2版）は、厚生労働科学研究成果データベース（mhlw-grants.niph.go.jp）に2023年度課題の報告書添付資料（202319015A-sonota1.pdf）として掲載され、全49ページを通読しても ©・著作権・転載禁止の記載が一切ない。このため 2026-11-15 の決定（mhlw-grants の研究報告書で、資料自体に著作権主張がなければ GOV_JP）を直接適用して HS-001 を D、HS-004 を同資料による B とした。一方で本書の表題は「診療ガイド」であり、2026-11-13 の決定（研究班のガイドラインは厚労省サイト掲載でも RESTRICTED）を優先する解釈も成り立つ。その場合は HS-001 は B（CC BY の Medicina 2020 で除外診断・病期分類のみ）、HS-004 は C に変わり、集計は A13・B36・C18・D1 となる。確定は登録側・本人の判断に委ねる。
2. **数値の不一致・未確認が14件ある**（詳細は判定表の各行）。主なもの：
   - ES-014：カードの進展率（NDBE 年0.05〜0.2%、LGD 年約0.7%）を裏づける自由な資料はなく、CC BY レビューは別の指標・値（NDBE→LGD 発生 年4.3% 等）を報告する。
   - UG-004：輸血割合 49% vs 86% と45日死亡は候補と一致するが、その分母は解析対象 889例（444／445）で、カード冒頭の無作為化数 921例とは別である。
   - UG-001：カードの「見逃し率1%以下」は ACG の定義基準であり、統合解析の実測は GBS 0 で介入 2%、≤1 で 4% と基準を超える。
   - UG-005：カードの「輸血を受ける患者数が43%減」は自由な全文で再現できなかった（候補の指標は輸血単位数 MD −1.35単位）。
   - ND-041：患者数はカード「約3万人」に対し現行の公的資料は「3万人を超える」。割合も資料により「約2/3・約1/3」と「約7割・約3割」に分かれる。
   - 候補側の誤記と確認できたもの：ME-013（Kim 2006 の表の対象期間「1966–2003」、原著・カードは1969–2003）、ME-016（SUPPORT Summary の信頼区間「0.63〜1.20」、原著・カードは0.63〜1.02）、ME-023（Behling 2017 の Fatmi 引用「7 of ten studies」、原著・カードは14件中7件）。いずれもカード側は原著と一致していた。
3. **試験登録に結果がなく登録数値を使えなかったもの**：ES-058 の PREDESCI（NCT01059396）、ES-065 の原試験、HP-002・003 のボノプラザン第III相（NCT01505127、hasResults=false を API で確認）、UG-004 の Villanueva 試験（NCT00414713）、UG-015 の STING（NCT01836900）、UG-016 の根拠 RCT（NCT00153725）。いずれも ClinicalTrials.gov で結果未登録を確認したうえで、CC BY 全文等で代替の裏づけを探した。
4. **PMDA の確認結果（ES-024・ES-091）**：PMDA の審査報告書には製造販売業者等の著作権物が含まれ無断複製・転載・頒布は禁止され、添付文書等も製造販売業者が著作権を有する。したがって PMDA 資料は GOV_JP・OPEN の候補にはならない（従来の UNKNOWN の扱いと実質同じ結論）。ES-024 の米国承認日は FDA の Orphan Drug データベース（GOV_US）で確認し、カードと完全一致した。
5. **区分の明確化（D には数えない訂正候補）**：現行出典の再確認で、UNKNOWN のままでは不正確と分かったものがある。SRC-5220（Murakami 2016、Gut）は PMC 全文で CC BY-NC 4.0 と確定し RESTRICTED が正しい。ES-020 の現行出典（Imamura 2020、Asia Pac Allergy）・ES-077（Abdi 2022）・ES-078（Chen 2022）はいずれも CC BY-NC で RESTRICTED。ES-084（Mertens 2024）はライセンス表示なし。UG-008・UG-016 の ESGE 2015 系（SRC-5229 等）は Thieme の © 表示で RESTRICTED。詳細は §3-2 にまとめた。
6. **WHO 文書2件（ME-024・ME-025）は D にならなかった**：WHO 公式ページ・IRIS と本文の権利表示を直接確認し、いずれも「© World Health Organization、All rights reserved」で CC 表示はなく、現行 RESTRICTED が正しい。

## 3. 主張文の修正が必要と思われる点

修正案は示さず、理由と根拠だけを書く。

### 3-1. 主張文そのものに関する点

- **ES-014**：カードの進展率（NDBE 年0.05〜0.2%、LGD 年約0.7%）は現行の制限付き出典（ACG 2022）のみに依存し、自由に使える資料では照合できなかった。CC BY レビュー（Stawinski 2023）は進展について別の指標・値（NDBE→LGD 発生 年4.3% 等）を報告しており、「どの母集団・指標の年率か」が資料によって大きく異なる領域である。数値の出所が ACG 2022 の推定であることが分かる形になっているか、点検が要ると思われる。
- **ES-017**：カードは Seattle protocol の生検間隔を「2 cm間隔」と固定して書くが、CC BY レビュー（Stawinski 2023）の記載は「1〜2 cm間隔」と幅がある。原典（ACG 2022）の表記との間で幅の有無が異なる点に留意が必要と思われる。
- **UG-001**：「見逃し率1%以下」は ACG の低リスク定義の基準値であり、Boustany 2023 の統合解析では GBS 0／≤1 群で院内介入を要した実測の統合割合は 2%／4% と基準を超えている。定義の説明なのか実測値なのかが読み手に分かる書き方か、点検が要る。
- **UG-004**：カードは「n=921：制限群461例、非制限群460例」としたうえで輸血割合 49% vs 86% と45日死亡率を並べているが、49%／86% の分母は解析対象の 444／445例（計889例、Teutsch 2023 の表で確認。無作為化後に計32例が脱落）であり、921例ではない。死亡率 5% vs 9% も同じ解析対象に基づく。無作為化数と解析対象数が混在して読める点の点検が要る。
- **UG-014**：カードは高用量 PPI の regimen を「提案されている」とし、uncertainty に「原文の推奨強度は要確認」とあるが、ACG 2021 の抄録（PMID 33929377）では同 regimen は "recommended"（推奨）の表現で記載されている。「提案」への弱め方が原典と合っているか点検が要る（抄録は根拠資料としては使わず、強さの確認のみに用いた）。
- **HP-018**：「年間19.4万人」という表現について。患者調査の「総患者数」は調査時点を起点とする推計概念であり、厳密には「年間患者数」ではない。ただし裏づけ資料（SRC-031）自体が "194,000 per year" と表現しており、カードはその記載に沿っている。
- **ND-041**：現行の公的資料（大阪市資料・難病情報センター現行版）はいずれも患者数を「3万人を超える」とし、カードの「約3万人と推定」と表現が異なる。また割合について兵庫県難病相談センター資料は「約7割（孤発性）・約3割（遺伝性）」とする。いずれも近似値の範囲だが、カードの数値表現は旧版の診断・治療指針（「約3万人」「2/3・1/3」）に基づくものである点は、取り込み側で把握しておくのがよい。
- **NI-007**：134℃・18分という条件について、CDC 歯科ガイドラインは「WHO が提示する方法の中で最も緩やかなもの」と位置づけており、WHO ガイドラインには乾燥した脳組織が付着した最悪条件では感染性が完全には除去されない旨の注記がある。カードは「134℃・18分など」と例示の形であり主張自体と矛盾しないが、この条件を単独で十分な不活化と読む余地がある点は留意されたい。
- ME 章については、主張文の修正が必要と思われる点はなかった。見つかった数値の食い違いはいずれも候補側の誤記である（ME-013・ME-016・ME-023。カード側の数値は原著と一致していた）。

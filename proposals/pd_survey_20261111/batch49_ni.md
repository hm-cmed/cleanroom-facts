# バッチ49：NI（26件）パブリックドメイン出典の裏づけ調査

集計：A（置き換え可）2件／B（裏づけ追加可）22件／C（見つからない）2件／D（区分訂正）0件（カード判定としては。区分訂正は別枠で4件）。対象26件すべてを判定した。

判定ルール（2026-11-11 のレポジトリ側決定）：抄録・添付文書・医学百科は根拠にしない。使えるのは政府の全文文書・報告書（GOV_US／GOV_JP）、CC BY の全文（OPEN）、試験登録レコードなど、全文で読める資料のみ。抄録は数値の食い違いの確認にだけ使う。カードの主張・数値は変えない。区分訂正がカード判定と重なる場合は、カード判定は A/B/C のいずれかに数え、区分訂正は別枠の節に分離して記録する。

調査方法：対象章のカードと出典マスター（sources.yaml）から主出典を1件ずつ取り、Europe PMC と Crossref を PMID/DOI で個別に照会してライセンスと書誌を確認した上で、自由な本文（政府の全文ページ、CC BY の全文）を実際に取得して読み、カードの主張と照合した。識別子は一括照会の結果を信用せず、候補ごとに個別に再照会してタイトルと著者を確認した。主出典の現行区分の点検でも、PMC に収載があるものは Europe PMC の個別レコードのライセンス表示を1件ずつ確認した。政府ページ（CDC、難病情報センター）は実際に開いて本文を読み、内容を確認した

特に重要な発見：

1. A（置き換え可）は2件（NI-002・NI-003）。いずれも、出典となった古典的なコンセンサス文書（AAN の PML 診断基準 2013、Frascati の HAND 分類 2007）を、ドイツ神経学会の CC BY ガイドラインや Frontiers の CC BY 診断ガイドが全文で再掲していたもので、主張の全要素が自由な全文で置き換え可能だった。
2. ドイツ神経学会のガイドライン英語版（Neurol Res Pract、CC BY）は本章で広く使えた（NI-001・003・008）。学会ガイドラインの英語版が CC BY で刊行される経路は、今後の章でも有望である。
3. 髄膜炎へのステロイド併用（NI-010・011）は、試験の数値の再掲が CC BY のレビュー本文にあり裏づけられた。特に NI-011 では、主出典の試験の肺炎球菌 subgroup の数値（予後不良26%対52%）が候補の本文にそのまま再掲されていた。
4. 区分訂正は UNKNOWN の4出典で、いずれも CC BY-NC かライセンス表示なしで、自由利用でないことが確定した。PMC に著者原稿が収載されても自由利用にはならない例が本章でも繰り返された（著者原稿の収載は主出典7件で確認）。
5. 新しい版の出現として、結核性髄膜炎の国際診療ガイドライン（Lancet Infect Dis 2026、CC BY）と HTLV-1関連脊髄症（HAM）診療ガイドライン2025 がある。NI-016・017・004 は次回改訂時の再照合対象（フラグ参照）。
6. C は2件で、日本のガイドライン固有の枠組み（NI-009）と、特定の症例集積に固有の数値（NI-019）は自由な全文に再掲がなかった。国内ガイドラインの英語論文は自由利用ではなかった。

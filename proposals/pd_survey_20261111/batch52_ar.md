# バッチ52：AR（24件）パブリックドメイン出典の裏づけ調査

集計：A（置き換え可）0件／B（裏づけ追加可）4件／C（見つからない）20件／D（区分訂正）0件（カード判定とは別枠。訂正が必要な主出典はなかった）。対象24件すべてを判定した。

判定ルール（2026-11-11 のレポジトリ側決定）：抄録・添付文書・医学百科は根拠にしない。使えるのは政府の全文文書・報告書（GOV_US／GOV_JP）、CC BY の全文（OPEN）、試験登録レコードなど、全文で読める資料のみ。抄録は数値の食い違いの確認にだけ使う。カードの主張・数値は変えない。区分訂正がカード判定と重なる場合は、カード判定は A/B/C のいずれかに数え、区分訂正は別枠の節に分離して記録する。

調査方法：対象章のカードと出典マスター（sources.yaml）から主出典を1件ずつ取り、Europe PMC と Crossref を PMID/DOI で個別に照会してライセンスと書誌を確認した上で、自由な本文（政府の全文ページ、CC BY の全文、試験登録レコード）を実際に取得して読み、カードの主張と照合した。識別子は一括照会の結果を信用せず、候補ごとに個別に再照会してタイトルと著者を確認した。主出典の現行区分の点検でも、PMC に収載があるものは Europe PMC の個別レコードのライセンス表示を1件ずつ確認し、刊行版の表示を Crossref の表示に優先させた。試験登録レコードは ClinicalTrials.gov の API で結果セクションを取得して照合した。

特に重要な発見：

1. A（置き換え可）は0件、B は4件だった。数値まで一致したのは AR-011（ELDERCARE-AF、登録レコードのハザード比0.339がカードの0.34と一致）と AR-032（先天性QT延長症候群の診断経路のうち Schwartz スコア3.5点以上と病的変異の2つが CC BY 総説と一致）の2件で、AR-035（Brugada 症候群への ICD）と AR-037（心房期外収縮と心房細動の関連）は原則・方向の裏づけに留まる。
2. 試験登録レコードで裏づけが付いたのは ELDERCARE-AF（NCT02801669、結果セクションに発症数とハザード比を掲載）のみだった。他の古典的試験（AFFIRM NCT00000556、CAST NCT00000526、AVID NCT00000531、CASTLE-AF NCT00643188、EAST-AFNET 4 NCT01288352）は登録レコード自体は存在するが結果セクションの掲載がなく、MADIT-II は結果を掲載する登録レコードが確認できなかったため、いずれも C とした。
3. JCS/JHRS 2019 不整脈非薬物治療ガイドライン（SRC-181、8件の主出典）は、刊行版（PMC8339126）と Crossref の VoR のいずれでも CC BY-NC-ND 4.0 で、マスターの license_note と一致し、自由利用にはならない。JCS/JHRS 2022 診断・リスク評価ガイドライン（SRC-4379、3件の主出典）も PMC 版にライセンス表示がなく自由利用にはならない。区分の訂正（D）は0件で、本章の主出典15件すべての現行区分（RESTRICTED）が個別確認と一致した。
4. 識別子の補完候補が4件ある（PMCID は SRC-181 の PMC8339126 と SRC-4379 の PMC11317726、PMID は SRC-4378 の 20404258 と SRC-4379 の 39139890。いずれもカード側には記載があるがマスター未登録）。
5. ガイドラインの世代交代のフラグが2件ある。JCS/JHRS 2024 Guideline Focused Update on Management of Cardiac Arrhythmias（2025年刊行）が 2019 非薬物治療ガイドライン以降の推奨を見直しており、SRC-181 を主出典とする8件は次回改訂時の照合が要る。先天性QT延長症候群の診断基準（AR-032）は 2013 年の専門家合意に基づくが、ESC 2022 はスコアと QTc の閾値を変えており（CC BY の解説で全文確認済み）、こちらも次回改訂時の照合事項である。
6. AR-011 の uncertainty（エドキサバン15 mg の国内承認の条件は未確認）は、2021年8月の国内の一部変更承認（第一三共の発表）で解消可能であることをフラグに挙げた。

## 区分の訂正（D、カード判定とは別枠）

訂正が必要なものは0件だった。本章の主出典15件（24カード。SRC-181 は AR-020・022・029・030・031・032・034・035、SRC-4379 は AR-037・041・042 で共通）すべてについて Europe PMC と Crossref で個別に確認した。内訳は次のとおり。

1. 区分の訂正（D）は0件だった。対象24件の主出典15件（SRC-171・172・174・175・176・177・178・179・180・181・182・183・184・4378・4379）すべてについて Europe PMC と Crossref で個別に確認し、現行の RESTRICTED と矛盾するものはなかった
2. SRC-181（AR-020・022・029・030・031・032・034・035 の主出典、JCS/JHRS 2019 不整脈非薬物治療ガイドライン）：Europe PMC の個別レコード（PMC8339126）でライセンスは cc by-nc-nd、Crossref の VoR も CC BY-NC-ND 4.0 で、マスターの license_note（CC BY-NC-ND 4.0）と一致する。オープンアクセスだが NC・ND のため自由利用にはならず、現行の RESTRICTED が正しい
3. SRC-4379（AR-037・041・042 の主出典、JCS/JHRS 2022 不整脈の診断とリスク評価ガイドライン）：PMC 収載版（PMC11317726）にライセンス表示がなく Europe PMC でオープンアクセスではなく、Crossref の VoR は Wiley の利用条件（termsAndConditions#vor）で CC ではない。現行の RESTRICTED が正しい。マスターの license_note は空欄のため、この確認結果の追記を申し送る
4. SRC-4378（AR-036 の主出典、Binici らの Circulation 2010）：Europe PMC の個別レコード（PMID 20404258 で個別に確認、タイトルは Excessive supraventricular ectopic activity and increased risk of atrial fibrillation and stroke）でオープンアクセスの表示がなく、ライセンス表示もない。現行の RESTRICTED が正しい。マスターの license_note は空欄のため、追記を申し送る
5. SRC-171・174・175・176（Elsevier 系の雑誌論文）はマスターの license_note（Elsevier の TDM 用ライセンスのみ、CC の表示なし）と矛盾せず、SRC-172（JAMA、AMA の著作物）、SRC-177・179・180（NEJM の利用規約）、SRC-178・182・183・184（出版社の著作物）も CC の表示がなく、いずれも現行の RESTRICTED が正しい

## フラグ（要再照合・申し送り）

1. JCS/JHRS 2024 Guideline Focused Update on Management of Cardiac Arrhythmias が刊行されている（J Arrhythm. 2025;41(3):e70033、PMID 40524851、DOI 10.1002/joa3.70033。Circulation Journal 版は CJ-24-0073）。不整脈の薬物治療と非薬物治療を統合した改訂で、JCS/JHRS 2019 不整脈非薬物治療ガイドライン（SRC-181）以降の推奨を見直している。SRC-181 を主出典とする8件（AR-020・022・029・030・031・032・034・035）は、次回改訂時に同 Focused Update（あわせて 2021 年の非薬物治療 Focused Update）との照合が要る
2. AR-011 の uncertainty に残る「エドキサバン15 mg の国内承認の条件は本出典では確認していない」は解消可能である。第一三共は2021年8月25日、ELDERCARE-AF 試験（出血リスクの高い80歳以上の非弁膜症性心房細動患者984例）に基づき、年齢・患者の状態に応じて1日1回15 mg に減量できる用法・用量の追加について、国内の製造販売承認事項一部変更承認を取得している（同社の発表資料で確認）
3.

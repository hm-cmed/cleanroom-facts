# バッチ48（VD 27件）の調査結果

集計：A 置き換え可 0件／B 裏づけ追加 19件／C 見つからない 8件／D 区分の訂正 0件（カード判定とは別に、出典マスターの区分訂正が3件あり、末尾の「区分の訂正（D）」の節に内訳を示す）

判定ルールは新ルール（2026-11-11、レポジトリ側決定）を適用した：**抄録・添付文書・医学百科は根拠にしない**。使える候補は政府の全文文書・報告書（CDC の臨床ガイダンス、ClinicalTrials.gov の結果レコード等）、CC BY の全文など、全文として読める資料のみ。A は「全文の自由資料で主張全体を置き換えできるもの」だけとし、一部しか裏づけられないものは B とした。本章（弁膜症）の主出典は8出典で、日本循環器学会の弁膜症治療ガイドライン2020（SRC-230、6件）と感染性心内膜炎ガイドライン2017（SRC-237、6件）、ACC/AHA 2020（SRC-231、9件）、英国心エコー図学会（BSE）のガイドライン2件（SRC-233・234、計3件）、NEJM の2大試験（SRC-238・239）、Nature Reviews Cardiology の総説（SRC-4393）が中心である。

## 調査方法

- 対象27件の主出典は、出典マスター（data/sources/sources.yaml）の記載で同定し、出典の説明はマスターの title の記載から機械的に取った。主出典のライセンスは Crossref の version-of-record と Europe PMC の個別レコードの両方で確認し、食い違う場合は刊行物自体（PDF）の表示も確認したうえで、自由利用の根拠にはしなかった。
- 候補は Europe PMC の全文 XML（CC BY の総説）、米国 CDC の臨床ガイダンス（実際に開いて本文を確認）、ClinicalTrials.gov の結果レコードで、主張の要素ごとに照合した。候補のライセンスは Europe PMC の表示で確認した。
- 候補の PMID・PMCID は、PMID または DOI（PMCID のみのものは PMCID）で個別に再照会し、タイトルが当該文献と一致することを確認してから記載した。候補はいずれも出典マスター未登録であることを、識別子でマスターを検索して確認した。
- 主張文と数値は変更していない。数値が候補と食い違う場合は、両値を「数値照合」欄に記録した。

## 特に重要な発見

1. **置き換え可（A）は 0 件**だった。本章の主張はガイドラインの推奨表明・CQ・重症度基準の表に依拠するものが多く、CC BY の総説が再掲するのは定義・分類・閾値の核までで、推奨の格付けや運用の細部までは届かなかった。一方で裏づけ追加（B）は 19 件あり、章の約7割に自由な裏づけが付く。
2. **2025 ESC/EACTS 弁膜症ガイドラインが刊行されている（サーベイランス）**。本章の基盤は JCS 2020 と ACC/AHA 2020 で、ESC 2025 は MR の分類を機序ベース（一次性／心室性二次性／心房性二次性）に再編し、無症状の一次性 MR への弁形成術の Class I 推奨を新設した。VD-001・003・004・021 をはじめ章全体が次回改訂時の再照合対象である（フラグ参照）。
3. **感染性心内膜炎の診断基準も置き換わりつつある**。2023年の Duke-ISCVID 基準（Clin Infect Dis 2023;77:518-526）と ESC 2023 ガイドラインが刊行され、VD-027〜032 の基盤である JCS 2017（修正 Duke 基準）は次回改訂で再照合が要る。なお Duke-ISCVID 論文自体は自由利用ではない（Crossref の VoR は Oxford University Press の標準再利用条件、Europe PMC でもライセンス表示なし）。
4. **BSE ガイドライン2件のライセンスは「CC BY-NC-ND」で確定し、マスターの RESTRICTED が正しい**。SRC-234 は Crossref の version-of-record ライセンス欄が CC BY 4.0 を示したが、刊行版 PDF 自体と Europe PMC の個別レコードはいずれも CC BY-NC-ND 4.0 で、刊行物の表示を優先して自由利用とは扱わなかった。Crossref のメタデータだけで OPEN に訂正しないよう申し送る。SRC-233 も刊行版 PDF・Europe PMC とも CC BY-NC-ND で、マスターの license_note にある「Springer ページは CC BY と表示」という食い違いは今回の PDF 確認では再現しなかった。
5. **試験登録の結果の有無が VD-015 と VD-016 で分かれた**。PARTNER 3（NCT02675114）は結果が掲載され、主要評価項目の実数（TAVI 42/496＝8.5%、外科 68/454＝15.0%）がカードの Kaplan-Meier 推定値（8.5%・15.1%）と一致して B。一方 INVICTUS（NCT02832544）と RIVER（NCT02303795）は結果未掲載で、VD-016 は CC BY 総説による結論の方向の再掲で B とし、制限平均生存時間の差（−76日）などの数値は留保した。
6. **米国政府の全文が1件使えた**。VD-011（リウマチ熱の二次予防）は CDC の臨床ガイダンス（GOV_US）がベンザチンペニシリン筋注3〜4週ごとという投与方法の核を裏づけた。ただし期間の表（10年間か40歳まで等）と用量は CDC に再掲がなく B にとどまる。
7. **数値照合（両値記録）が1件ある**。VD-029 の疣腫検出感度は、カード（JCS の記載として TTE 自己弁約70%・TEE 90%以上）に対し、自由なメタ解析では TTE 64%（95%信頼区間57〜70%）・TEE 94%（同92〜96%）で、方向と水準は概ね一致するが同一ではない。カードは JCS の記載として正確であり、誤りとは断定しない。

## フラグ（再照合・サーベイランス）

1. **新版ガイドライン**：2025 ESC/EACTS 弁膜症ガイドラインが刊行された（Eur Heart J Imaging Methods Pract 2026 の CC BY 総説で確認）。本章のカードは JCS 2020 と ACC/AHA 2020 が基盤で、ESC 2025 は MR の分類を機序ベース（一次性／心室性二次性／心房性二次性）に再編し、無症状の一次性 MR に対する弁形成術の Class I 推奨を新設している。VD-001・003・004・021 をはじめ章全体が次回改訂時の再照合対象。
2. **診断基準の更新**：感染性心内膜炎では 2023年に Duke-ISCVID 基準（Clin Infect Dis 2023;77:518-526、PMID 37138445、PMCID PMC10681650、自由利用ではない）と ESC 2023 ガイドラインが刊行され、修正 Duke 基準は置き換わりつつある。VD-027〜032 は JCS 2017（修正 Duke 基準の時代）の内容で、JCS の次回改訂時に再照合が要る。
3. **数値の近接**：VD-029 の疣腫検出感度は、JCS の記載（TTE 自己弁約70%）に対し自由なメタ解析では TTE 64%（95%信頼区間57〜70%）で、方向と水準は概ね一致するが同一ではない。カードは JCS の記載として正確であり、誤りとは断定しない。
4. **登録に結果なし**：INVICTUS（NCT02832544）と RIVER（NCT02303795）は ClinicalTrials.gov に結果が掲載されておらず（2026-11-12 確認）、VD-016 の数値（制限平均生存時間の差 −76日）は NEJM 本文にのみ依拠する。SPORT 型の「登録で裏づけられない」事例として記録する。
5. **国内データの版**：VD-030 の起炎菌分布（MRSA 7.5% など）は JCS 2017 掲載時点の国内データで、その後の変化は自由な全文では追えなかった。
6. **ガイドライン間の立場の違い**：感染性心内膜炎の予防投与は、ACC/AHA 2020（VD-010）が高度リスク群に限るのに対し JCS 2017（VD-032）は中等度リスク群にも提案しており、対象読者が混同しないよう既存の相互参照（VD-010 と VD-032）を維持するのが望ましい。

以上がバッチ48（VD 27件）の調査結果であり、集計は A 0件・B 19件・C 8件・D 0件（カード判定）、出典マスターの区分訂正は別途3件である。

# バッチ51：UR（25件）パブリックドメイン出典の裏づけ調査

集計：A（置き換え可）0件／B（裏づけ追加可）7件／C（見つからない）18件／D（区分訂正）5件（カード判定とは別枠。いずれも UNKNOWN→RESTRICTED で、対象は SRC-692・693・698・709・711）。対象25件すべてを判定した。

判定ルール（2026-11-11 のレポジトリ側決定）：抄録・添付文書・医学百科は根拠にしない。使えるのは政府の全文文書・報告書（GOV_US／GOV_JP）、CC BY の全文（OPEN）、試験登録レコードなど、全文で読める資料のみ。抄録は数値の食い違いの確認にだけ使う。カードの主張・数値は変えない。区分訂正がカード判定と重なる場合は、カード判定は A/B/C のいずれかに数え、区分訂正は別枠の節に分離して記録する。

調査方法：対象章のカードと出典マスター（sources.yaml）から主出典を1件ずつ取り、Europe PMC と Crossref を PMID/DOI で個別に照会してライセンスと書誌を確認した上で、自由な本文（政府の全文ページ、CC BY の全文、試験登録レコード）を実際に取得して読み、カードの主張と照合した。識別子は一括照会の結果を信用せず、候補ごとに個別に再照会してタイトルと著者を確認した。主出典の現行区分の点検でも、PMC に収載があるものは Europe PMC の個別レコードのライセンス表示を1件ずつ確認した。試験登録レコードは ClinicalTrials.gov の API で結果セクションを取得して照合した。

特に重要な発見：

1. A（置き換え可）は0件だった。本章の主出典は学会ガイドライン（EAU、IDSA、AUA、ACOG、NICE）と単一研究（コホート・症例集積・症例報告）が中心で、主張の全要素を自由な全文だけで置き換えられる例はなかった。B は7件で、そのうち数値まで一致したのは UR-001（超音波の感度・特異度）、UR-003（再発率）、UR-007（閉塞後利尿の定義）、UR-011（RIVUR の再発数）の4件。
2. RIVUR 試験（UR-011）は、ClinicalTrials.gov の結果レコード（NCT00405704）が主要アウトカムの実数（再発39例対72例）をそのまま掲載しており、NEJM 論文を読まずに裏づけが付いた。登録レコードに載るのは実数と瘢痕のアウトカムまでで、ハザード比と耐性の割合は論文側にしかない。
3. 主出典の区分が UNKNOWN だった5件（SRC-692・693・698・709・711）は、個別確認の結果すべて RESTRICTED への訂正に倒れた。BMJ 2016 のメタアナリシス（SRC-692）は PMC に収載されオープンアクセスだが CC BY-NC で、自由利用にはならない。本章の対象カードに残る UNKNOWN の主出典はこれで解消する。
4. PMCID の補完候補が10件ある（SRC-692・694・695・698・699・704・715・717・719・4726）。PMC に収載のある主出典が軒並みマスター未登録だった。
5. NICE NG123 を主出典とする2件（UR-037・038）は、Open Government Licence の扱いが分かれ目になった。バッチ1以来の先例（OGL は区分枠＝OPEN／GOV_US／GOV_JP／CC 系の外）に従い C とし、区分への算入は登録側の判断事項としてフラグに申し送る。両カードの uncertainty に残る「NICE の権利表示の最終確認は取り込み側に委ねる」という宿題も、この判断とあわせて解消できる。
6. UR-002 では、より新しい CC BY メタアナリシス（2026年、2010〜2025年の無作為化試験）が主出典（2016年）より小さい統合値を示した。方向は一致するため B としたが、数値の世代差としてフラグに挙げた。

## 区分の訂正（D、カード判定とは別枠）

訂正が必要なものは5件で、いずれも UNKNOWN から RESTRICTED への訂正である。本章の主出典21件（25カード。SRC-695 は UR-005〜007、SRC-4723 は UR-035・036、SRC-4724 は UR-037・038 で共通）すべてについて Europe PMC と Crossref で個別に確認した。内訳は次のとおり。

1. SRC-692（UR-002 の主出典）：Europe PMC の個別レコードでライセンスは cc by-nc（PMC 掲載版は CC BY-NC 4.0）。オープンアクセスだが NC のため自由利用にはならず、UNKNOWN から RESTRICTED への訂正が必要
2. SRC-693（UR-003 の主出典）：Journal of Urology 1996年の出版社の著作物。Europe PMC でオープンアクセスの表示がなく、PMC にも収載がなく、ライセンス表示はない。UNKNOWN から RESTRICTED への訂正が必要
3. SRC-698（UR-011 の主出典）：NEJM 2014年。PMC に著者原稿が収載される（PMC4137319）がライセンス表示はなく、Europe PMC でもオープンアクセスではない。UNKNOWN から RESTRICTED への訂正が必要
4. SRC-709（UR-024 の主出典）：Journal of Pediatric Surgery 1992年の出版社の著作物。オープンアクセスの表示はなく、ライセンス表示も確認できない。UNKNOWN から RESTRICTED への訂正が必要
5. SRC-711（UR-026 の主出典）：Journal of Urology 2002年の出版社の著作物。オープンアクセスの表示はなく、ライセンス表示も確認できない。UNKNOWN から RESTRICTED への訂正が必要
6. SRC-694（UR-004 の主出典）と SRC-4726（UR-043 の主出典）は Europe PMC の個別レコードで CC BY-NC-ND 4.0、SRC-695（UR-005〜007）は CC BY-NC 4.0、SRC-699（UR-012）は CC BY-NC（マスターの license_note は CC BY-NC 3.0）、SRC-704（UR-017）は CC BY-NC、SRC-715（UR-030）は CC BY-NC-SA 3.0、SRC-719（UR-034）は CC BY-NC-ND で、いずれも自由利用にはならず現行の RESTRICTED が正しい。
7. SRC-717（UR-032 の主出典、コクランレビュー2017）は、PMC に著者原稿が収載される（PMC6483329）がライセンス表示はなく、現行の RESTRICTED が正しい。PMCID は補完候補として記録する

## フラグ（カードの再照合が要る事項）

1. UR-002 の統合値の世代差：カードは主出典（Hollingsworth ら、BMJ 2016）の統合値（排石のリスク比1.49、大きな結石で1.57、排石までの期間は平均3.79日短縮）に基づく。2026年の CC BY メタアナリシス（2010〜2025年の無作為化試験、Arab J Urol）はより小さい統合値（リスク比1.25、5〜10 mmの結石で1.35、期間の平均差−2.96日）を示した。次回改訂時に、どのメタアナリシスの値を採るかの再照合が要る
2. UR-007 の輸液補充の割合と頻度の枠組み：カードの管理は「前1時間の尿量の50%を輸液で補う方法」。CC BY のミニレビュー（Eur Urol Open Sci. 2025）が再掲する唯一の管理の研究では尿量の67%の補充だった。また頻度は、カードは「完全な両側閉塞の解除後では最大で約半数」とするのに対し、同レビューは尿閉のコホート全体で15〜78%と幅を示す。次回改訂時に原著の枠組み（対象集団と補充方法の出典）の再確認が要る
3. UR-037・UR-038 の NICE NG123（Open Government Licence）の区分算入：OGL を自由な出典の区分（OPEN／GOV_US／GOV_JP）に含めるかどうかは、バッチ1以来ずっと登録側の判断事項になっている。算入されれば両カードは主出典自体が自由な出典になる。あわせて、両カードの uncertainty にある「NICE の権利表示（Notice of rights、OGL の適用範囲を含む）の最終確認は取り込み側に委ねる」という宿題も、この判断とあわせて解消できる
4. UR-001 の版：主出典は EAU 尿路結石ガイドラインの2025年版（SRC-691、European Urology に掲載の版）。EAU のガイドラインは毎年更新されるため、次回改訂時に最新版との照合が要る。なお本章では、UR-035・036 の主出典が同じ EAU の小児泌尿器ガイドライン2026年版であり、版の新しさに章内で差がある

以上で、UR 章の対象25件すべての判定を終えた。A は0件、B は7件、C は18件で、区分の訂正（UNKNOWN→RESTRICTED）が5件、PMCID の補完候補10件を申し送る。

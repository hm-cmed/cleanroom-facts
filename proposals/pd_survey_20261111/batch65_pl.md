## 申し送り

- PL-020：重症の境界表記差（カード「AHI 30以上」／候補「30超」）。バッチ64 の CX-008・CX-016 と同種の論点であり、次回改訂時に主出典 SAS 診療ガイドライン2020 の表記で確認することを推奨する。
- PL-021：SAS の有病割合の後半（AHI 15以上かつ日中の眠気を伴う例が男性約5%・女性2〜3%）は、公式英語版（候補）には再掲がなかった。英語版は治療編（CQ16〜36）が中心の構成で、疫学部分の記述が日本語版本文より薄い。日本語版での再照合が必要な場合は日本語版全文の確認が要る。
- PL-022：候補は主出典 SRC-495 の公式英語版であり、内容は日本語版と同一のガイドラインだが、出版物としては別（Sleep Biol Rhythms 2022、DOI 10.1007/s41105-021-00353-6）。「主出典の英語版」を裏づけ出典としてどう位置づけるかは登録側の判断事項として申し送る。
- PL-031：頻度は主出典（症例報告・シリーズの集計値）と候補（単一コホート135例）で母集団が異なり、皮下気腫は約70%対約30%、胸痛も60〜100%対51.9%と値が異なる。定義・機序・経過の骨格の裏づけにはなるが、頻度の値そのものの裏づけにはならない。
- SRC-567：Europe PMC の fullTextXML 取得で HTTP 500 が繰り返し返り、XML のライセンス要素を直接読めなかった。区分判断は Europe PMC のメタデータ（isOA=N・ライセンスなし）、Crossref（ライセンスなし）、NCBI 収載テキストの © 表示で代替した。本バッチで API のレート制限（429）は発生していない。
- SRC-370（BTS 胸膜疾患ガイドライン2023）：PDF の「No commercial re-use」は BMJ の標準表示であり CC BY ではない。Crossref にライセンス表示はなく Europe PMC でも非 OA のため、現行 RESTRICTED が正しい（区分訂正なし）。

## 重要な発見

1. **厚生労働省の重篤副作用疾患別対応マニュアル（GOV_JP）が重症薬疹4件の裏づけになった。** (1) 「薬剤性過敏症症候群」（平成19年6月、PMDA 掲載の全文 PDF）は、DiHS の概念・遷延する経過・HHV-6 再活性化・原因薬剤を扱い SK-023 を部分的に裏づけ、同マニュアルが採用する研究班の診断基準（公的資料に全文掲載）は SK-038 の診断基準7項目・典型/非典型の区分・原因薬剤の一覧と一致した。(2) 「スティーヴンス・ジョンソン症候群（皮膚粘膜眼症候群）」（平成18年11月、平成29年6月改定）は、SJS の定義・主要徴候・被疑薬の種類（抗菌薬・解熱消炎鎮痛薬・抗てんかん薬が中心）・感染も契機となる点を扱い SK-036 を部分的に裏づけ、治療の骨格については SK-037 の弱い部分裏づけとした。いずれも出典マスター未登録で、新規 SRC 登録候補である。なお SK-036・037 の主出典（日本皮膚科学会ガイドライン2016）には2025年の補遺があることがカード自身に明記されており、新版照合の申し送りは既存のものである。

2. **CALISTO 試験は ClinicalTrials.gov の結果レコードで数値が裏づけられた（SK-026）。** NCT00443053 の登録表示で、登録者3,002人、主要複合の実数 13対88 を確認し、カードの 0.9% 対 5.9%（相対リスク減少85%）と整合した（主張チェックでも食い違いなし）。肺塞栓症・深部静脈血栓症の内訳と大出血の件数は、本調査で取得した登録表示の範囲では照合していない。

3. **D は0件だが、区分の明確化・補完が3件ある。** (1) SRC-3092（WAO HAE 2025）はマスターの license_note が空欄だったが、Crossref の version-of-record で **CC BY-NC-ND 4.0** を確認した。現行 RESTRICTED は正しく、license_note への補完候補である。(2) SRC-4523（ESVS 2021）は Crossref の version-of-record が Elsevier の open-access userlicense 1.0 で、オープンアクセスではあるが CC BY ではない。自由利用にはならないため、UNKNOWN から RESTRICTED への明確化が適切である。(3) SRC-1083（結節性紅斑総説）は PMC に全文があるが、ライセンスは著者から Springer への exclusive licence で CC 表示はなく自由利用ではない。現行 UNKNOWN から RESTRICTED への明確化が適切である（SK-020・039）。

4. **サーベイランス：遺伝性血管性浮腫の WAO ガイドラインが2025年版に更新され、分類が再編された。** 2025年版（SRC-3092、SK-033）では C1インヒビター欠損・機能不全によるものが HAE-C1-INH に統合され、C1インヒビター正常型は HAE-nC1-INH と整理された。SK-013 は2021年改訂版準拠を明示しているため矛盾ではないが、照合直しの対象である。あわせて SK-033 の uncertainty にあるセベトラルスタットの国内承認（2025年12月22日承認、承認用量は国内1回300mg で WAO 本文の600mg と異なる）などの記載は、本調査で新たな食い違いは見つからなかった。

5. **CC BY の候補はあるが全文照合が未完のものが4件ある（SK-014・022・027・035）。** Swiss Practice Recommendations（Int J Dermatol 2026、PMC13745628。SK-014・035 の慢性痒疹）、SCORTEN の系統的レビュー（Australas J Dermatol 2026、PMC13176803。SK-022）、特発性凍瘡の系統的レビュー（Biology 2022、PMID 36421364、PMC9687160。SK-027）はいずれも Europe PMC の license 表示・フィルタで CC BY を確認したが、Europe PMC の取得障害（後述）のため全文で主張の要素を照合できなかった。C としたうえで、照合が完了すれば B になりうる候補として申し送る（SK-027 は範囲が患者特性・症状・リスク因子に限られる点も留保）。

6. **識別子の誤りは0件。補完候補は PMCID 5出典分と SRC-3092 の license_note（発見3）。** 出典マスターで PMCID が未登録のままの SRC-1073（PMC9365318）・SRC-1076（PMC9968263）・SRC-1078（PMC9023902）・SRC-1079（PMC10796623）・SRC-1083（PMC7938036）について、PMCID の実在を Europe PMC で確認した。いずれも自由利用できるライセンス表示はなく（CC BY-NC／CC BY-NC-ND、またはライセンス表示のない PMC 収載）、自由利用にはならない（区分は不変）。SRC-1071・1080〜1082・1084・1085・1088〜1092・1547・1548・4523 には PMCID が無いこともあわせて確認した。SRC-3092 の PMID は出典マスター未登録のままで、本調査でも確定できなかった。本章の主出典（SRC-1071〜1092・1547・1548・3092・4521〜4523）に DOI の重複はなく、マスター全体の既知の重複8組（バッチ16の記録）にも含まれない。

7. **数値の食い違いは見つからなかった（主張チェック）。** CALISTO の登録レコードとの突き合わせ（発見2）のほか、SK-040 では ESVS 本文中の CALISTO 紹介文の「フォンダパリヌクス2.5 mg 1日2回」が推奨45の正式表記「1日1回」と異なる表記ゆれを確認したが、カードは推奨文を採用しており、CALISTO の実レジメン（1日1回45日間）とも一致する。SK-014・SK-030 の薬剤の国内承認に関する「未確認」注記は、カード作成時の再点検（2026-10-31、PMDA・厚生労働省の公的情報）で既に解消済みであることを確認した。一方、SK-002・003・004 の多製剤にわたる国内承認の注記は、本調査では PMDA 全文での個別確定に至らず未解消である。

## D 区分の訂正（0件）

本章では主出典自体が CC BY のものはなかった。Crossref の version-of-record で個別に確認した結果、SRC-1077（蕁麻疹ガイドライン）は CC BY-NC 4.0、SRC-1078（WAO/EAACI HAE 2021）と SRC-1086（Allergol Int DiHS 総説）と SRC-3092（WAO HAE 2025）は CC BY-NC-ND 4.0、SRC-1076（うっ滞性皮膚炎）と SRC-1079（慢性痒疹）は CC BY-NC 4.0 で、いずれも現行 RESTRICTED が正しい。SRC-1073（脂漏性皮膚炎、Dove Press）はマスター記録の CC BY-NC 3.0 のとおりである。SRC-1071（アトピー性皮膚炎ガイドライン英語版）と SRC-1081（薬疹総説）は Wiley の利用条件のみで CC 表示はなく、SRC-1071 の RESTRICTED と SRC-1081 の UNKNOWN の据え置きはいずれも妥当だった。SRC-1092（インド SJS/TEN ガイドライン）は Crossref にライセンス表示がなく UNKNOWN の据え置きが妥当である。明確化の申し送りは発見3の2件（SRC-4523 の Elsevier open-access userlicense、SRC-1083 の exclusive licence。いずれも自由利用ではなく RESTRICTED への明確化が適切）である。PMC に全文が収載されていてもライセンス表示がないもの・exclusive licence のものは自由利用ではない前提で扱った。

## 方法と留保

- 新ルール（抄録・添付文書・医学百科は根拠にしない）を適用した。A・B の根拠は、実際に確認した政府の全文文書（厚生労働省の重篤副作用疾患別対応マニュアル。PMDA 掲載 PDF の本文抜粋で定義・主要徴候・原因薬剤・診断基準を確認）、CC BY の全文の存在とライセンス（Europe PMC の license 表示・フィルタ）、ClinicalTrials.gov の登録レコード（API v2 で登録・結果の実数を確認）のみである。
- ライセンスは Crossref の version-of-record で個別に確認し、出典マスターの license_note と照合した。誌名や PMC 収載の有無では判断していない（例：SRC-1083 は PMC 全文があるが exclusive licence、SRC-4523 はオープンアクセスだが Elsevier の userlicense で CC BY ではない）。
- 主出典の PMCID・ライセンスは Europe PMC でも相互確認した（応答に時間を要する照会があり、一部は後着の結果で補完した。補完の内訳は発見6）。一方、CC BY 候補4件（発見5）は license 表示の確認に留め、全文照合が未完である旨を明記して C に残した。照合できていない候補を B とはしていない。
- 数値の照合（主張チェック）は ClinicalTrials.gov の結果レコード（CALISTO）とカードの突き合わせが中心で、結果は発見2・7のとおりである。抄録は判定の根拠には使っていない。
- 候補のうち出典マスターに無いもの（厚労省マニュアル2件、色素性痒疹の CC BY 総説、ClinicalTrials.gov の登録レコード）はいずれも新規登録候補であり、SRC 番号は付けていない（採番は登録側）。厚生労働省の重篤副作用疾患別対応マニュアルは、他の章の重症薬疹・副作用関係のカードの裏づけにも使える可能性がある。
- 出典マスターの本章出典については DOI・PMID を個別に照合し、二重登録はなかった。マスター全体の既知の重複は8組（バッチ16の記録）で、本章の出典は含まれない。

## 方法と留保

- ライセンスは Crossref の version-of-record と Europe PMC の license フィールド、政府サイトの表示で個別に確認した。PMC に全文や著者稿があっても、ライセンス表示がなければ自由利用ではない前提で扱った（ND-064 の ICM 版は COVID-19 緊急ライセンスという特殊な事例だった）。
- NCBI（PubMed／PMC）のページは bot ブロックで直接開けない場面があり、その場合は Europe PMC REST API（resultType=core）の抄録・ライセンス、NCBI E-utilities（efetch）のレコード、検索インデックス上の表示で照合し、確認経路を JSON の `searched` に記録した。Lancet Commission 2024 と Gold Coast 基準は、efetch で PubMed レコードに抄録が収載されていないこと自体を確認した。
- USPSTF/AHRQ のエビデンスレビューが主出典のカードは本章になかった。ND-002 の裏づけは CDC の一般向けページによるもので、Bookshelf の表示確認は発生していない。
- 候補のうち出典マスターに無いもの（CDC・VA・MedlinePlus Genetics・NIH GARD の各ページ、Ferullo 2024）は新規登録候補であり、SRC 番号は付けていない（採番は登録側）。ND-051・053 の候補とした PMDA の個別承認ページは本調査では未目視で、登録時の確認事項として残した。
- PDF の新規保存は行っていない。Drive 台帳への IN 番号も付けていない。

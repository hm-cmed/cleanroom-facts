## 重要な発見

1. **D は26件で、2出典に集中する。** SRC-018（肝硬変診療ガイドライン2020英語版、LV-001〜022の22件）は Crossref の version-of-record と Europe PMC の両方で CC BY 4.0 を確認（バッチ7の GD 章で申し送った同一出典の訂正と一致）。SRC-074（Sugawara ら『Acute liver failure in Japan』、LV-068〜071の4件）は Crossref にライセンスメタデータがなく、マスターの license_note も『記事ページにCC種別の表示なし』としていたが、Europe PMC の license 表示（cc by）と PMC 本文（PMC3423565）のライセンス文（Creative Commons Attribution License の下で配布）で CC BY を確認した。**マスターの区分訂正だけで26件が解決する。**
2. **A は2件のみ（先例依存1件・非先例1件）。** LV-035（MASLD の定義・命名）は、Delphi 原典 SRC-066 が J Hepatol 版・Hepatology 版とも CC BY-NC-ND で使えない一方、同じ定義体系を採用した EASL-EASD-EASO MASLD ガイドラインの Diabetologia 版（PMID 38869512、PMCID PMC11519095）が CC BY であり、新規 SRC 登録を提案する（非先例の A）。LV-037（MetALD の飲酒量）は Delphi 原典の抄録に数値がそのまま載る先例に基づく A。LV-036 の5項目の閾値は同ガイドラインの ESM Table 3 にあり本文では確認できず B とした。
3. **識別子の誤りは0件。補完候補は5出典分。** SRC-018：DOI 10.1007/s00535-021-01788-x・PMID 34231046（マスターは PMCID のみ登録）。SRC-074：PMID 22825549・PMCID PMC3423565。SRC-066：PMID 37364790。SRC-084：PMID 19058303・PMCID PMC2773872（カード側には PMID 登録済みで、マスター側のみ未登録）。SRC-3974：PMID 38174913・PMCID PMC11040545。
4. **『英語版ガイドライン＝CC BY』パターンは肝癌・B型肝炎では不発だった。** SRC-067（肝癌診療ガイドライン2021英語版PDF）の誌上総説版（Hasegawa ら、Hepatol Res 2023、PMID 36826411）は CC BY-NC-ND、SRC-085（B型肝炎治療ガイドライン第4版簡易版）は学会 PDF で CC 表示なし。いずれも現行 RESTRICTED が正しい。
5. **『PMC に全文がある≠自由利用』の再確認が3件。** AASLD の HCC ガイダンス2023（PMCID PMC10663390）と HBV ガイダンス2018（PMCID PMC5975958）、ACG アルコール性肝疾患ガイドライン2024（SRC-3974、PMCID PMC11040545）はいずれも著者稿で CC 表示がなく、現行の扱いが正しい。EASL の嚢胞性肝疾患CPG（SRC-4227）と良性肝腫瘍CPG（SRC-4229）は Crossref に TDM ライセンスしかなく、ESMO 転移性大腸癌GL（SRC-4228）の version-of-record は Elsevier の open-access userlicense（著者稿向け）で CC BY ではない。
6. **両値記録（枠組み・境界の差）3件。** (a) LV-095 の R 値境界：カードは R≥5／2<R<5／R≤2、LiverTox（RUCAM 章）は R>5／2〜5／R<2 で、R=2 と R=5 の帰属が異なる（分類の骨格と補助規則は完全一致）。(b) LV-098 の ALT 閾値：日本の固定値31 U/L に対し、EASL 2017 は『ALT 上昇』という表現で数値提示なし（DNA 2,000 IU/mL は一致）。(c) LV-112 の死亡率：カードは Maddrey 判別関数32以上での30日死亡率約20〜50%、ACG 抄録は重症例（MELD >20）の1か月死亡リスク20〜50% で、指標は異なるが範囲は近似する。
7. **米国政府資料の裏づけが効いた。** NCI PDQ の肝癌治療要約は LV-041（washout による非侵襲診断、特異度95–100%）・LV-045（Milan 基準）・LV-048（一次治療 atezolizumab＋bevacizumab）・LV-049（二次治療3剤と ramucirumab の AFP 400 ng/mL 条件）など HCC 治療系の広い裏づけになり、大腸癌治療要約は LV-106〜108（肝転移切除が唯一の根治的治療、奏効後の切除転換、FOLFOX 周術期）の裏づけになった。LiverTox は LV-095 の R 値分類を補助規則まで含めて裏づけた。
8. **C 5件はいずれも日本固有の運用・数値である。** LV-040（3マーカーの閾値と単位）、LV-042（NBNC 約半数という全国集計の割合）、LV-096（DDW-J 2004 の感度）、LV-097（DLST の感度）、LV-102（再活性化モニタリングの間隔と開始閾値）。自由な出典側に相当する記載自体が存在しない。

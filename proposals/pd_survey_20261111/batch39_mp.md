# バッチ39：MP（心筋症・心膜疾患・心臓外傷）31件 ― パブリックドメイン出典の裏づけ調査

- 対象：`targets.json` のうち章プレフィックス MP の31件（MP-001〜005・007・012〜016・022〜030・033〜036・038〜044）
- 調査日：2026-11-11
- 判定：**A 置き換え可 1件／B 裏づけ追加 19件／C 見つからない 8件／D 区分の訂正 3件**
- ルール：2026-11-11 の新ルールを適用。抄録・添付文書・医学百科は根拠にせず、政府の全文文書・報告書、CC BY の全文、試験登録レコードなど全文として読める資料のみを候補とした。A は自由な全文で主張全体を置き換えできるものだけ、部分的な裏づけは B。主張文と数値は変更していない。
- 本章の構成：心筋症ガイドライン系（MP-001〜005）、マバカムテン（MP-007）、心アミロイドーシス（MP-012〜016）、劇症型心筋炎（MP-022）、心膜疾患（MP-023〜026・043・044）、たこつぼ症候群（MP-027・028）、心臓震盪（MP-029・030）、虚血性心筋症と血行再建試験（MP-033〜035）、心臓転移（MP-036）、心臓外傷（MP-038〜042）。

## 調査方法

- 主出典16件（SRC-241・243・246・251〜254・4383〜4386・4388・4442〜4444・4965）について、Europe PMC の個別照会でライセンス表示・PMID・PMCID を確認し、主要な DOI は Crossref の version-of-record ライセンスも個別に確認した。両経路で食い違う場合は採用していない。
- 試験が主出典のカードは ClinicalTrials.gov の API で結果レコードの有無と解析値を直接確認した（STICH＝NCT00023595、REVIVED-BCIS2＝NCT01920048、参考に ATTR-ACT＝NCT01994889、EXPLORER-HCM＝NCT03470545）。
- CC BY 候補は Europe PMC の全文 XML を取得し、主張の要素ごとに検索して照合した。政府文書は難病情報センターの指定難病28「全身性アミロイドーシス」の概要・診断基準等（既登録 SRC-247）を実際に開いて確認した。
- 薬剤の国内承認に関する更新は Web 検索で当たりを付け、判定根拠には使わず申し送りに回した。

## 特に重要な発見

1. **A は1件（MP-034、STICH）で、決め手は試験登録レコードだった。** ClinicalTrials.gov（NCT00023595）の結果レコードに仮説1の解析値——全死亡 HR 0.86（p=0.12、有意差なし）、心血管死 HR 0.81（95%CI 0.66–1.00、p=0.05）、死亡または心血管入院 HR 0.74（p<0.001）——が掲載され、対象（LVEF 35%以下・CABG 適応の冠動脈疾患）も登録の適格基準と一致するため、カードの主張の全要素が登録で確認できた（バッチ36の AZA-001 と同じ基準）。対照的に REVIVED-BCIS2（MP-035）は登録（NCT01920048）に結果が未掲載（hasResults=false）で登録による裏づけは成立せず、CC BY 総説（Lacalle ら 2026）の再掲（700人、HR 0.99、死亡と心不全入院に差なし）で B とした（バッチ35の PEITHO と同じ扱い）。
2. **D は3件。** MP-029・030 の主出典 SRC-254（Peng ら、Sports Med 2023）は、Crossref の VoR ライセンスと Europe PMC の表示の両方で CC BY 4.0 と確定し、UNKNOWN→OPEN が適切。MP-007 の主出典 SRC-243 は PMDA の審査報告書そのもので、同種の政府文書である SRC-417（審査報告書）が GOV_JP に区分されている先例に合わせ、UNKNOWN→GOV_JP が適切とした。
3. **心筋症ガイドライン系（MP-001〜005）は、英語版ガイドラインも自由利用でないことを確認したうえで、CC BY 総説が骨格を支えた。** 主出典 SRC-241 の英語版（SRC-4383、Circ J 2021）は Europe PMC で OA でなく、Crossref にもライセンス表示がなく、UNKNOWN の据え置きが妥当（MP-033 の備考）。代わりに CC BY の HCM 総説（Vio ら、J Clin Med 2021）で定義・壁厚基準（15 mm／家族例13 mm）・圧較差30 mmHg・有病率1:500・原因遺伝子が、突然死リスク総説（Costantino ら 2026）で危険因子が裏づけられ、5件とも B。ただし日本の疫学の固有数値（1998年調査 17.3/10万人、心尖部肥大型 約15% 対 米国 約3%）は自由な全文に再掲がなく裏づけ範囲外である。
4. **心アミロイドーシス（MP-012〜016）では政府文書（SRC-247）と CC BY 総説（Yi ら 2026）の組み合わせが効いた。** 病型分類（AL・ATTRwt・ATTRv）とタファミジスの承認事実（TTR 四量体安定化薬、ATTRv への保険収載、ATTRwt 心筋症への適応追加）は厚労省の指定難病文書で、PYP シンチの Grade 2以上、M蛋白スクリーニング一式、MGUS 併存時の扱いは CC BY 総説で裏づけられた。一方 MP-013 の固有数値（男性80〜98%、手根管症候群40〜50%・平均約7年先行）は自由な全文に再掲がなく C。
5. **心膜系は ESC 2025 ガイドライン（SRC-4965）のライセンスが分かれ目になった。** Crossref の VoR は OUP の標準再利用条件のみで CC BY ではなく、現行 RESTRICTED が正しい。MP-023〜026（ESC 2015 要約が主出典）は CC BY の心膜疾患総説（Kim ら、Rev Cardiovasc Med 2026）で診断基準（4項目中2つ）・コルヒチンの体重調整用量と3か月・ステロイド第一選択回避・心膜切除等が裏づけられ B。一方、2025年版の表に固有の MP-043（原因の内訳の割合）・MP-044（右房虚脱の持続時間比0.34 等）は再掲がなく C。なお MP-023〜026 は ESC 2025 での照合直し対象であることがカードの uncertainty に既記されている（サーベイランス）。
6. **劇症型心筋炎（MP-022）は、原著の集計が CC BY の系統的レビューの表にほぼ完全な形で再掲されていた。** Briglio ら（Cureus 2024）の表に Aoyama 2002 の「52人中30人が救命され日常生活に復帰（57.7%）、平均962日の追跡で死亡10%」が明記される。再入院10% のみ再掲がなく B。
7. **たこつぼ症候群（MP-027・028）は InterTAK の数値の一部だけが自由な全文に残る。** 女性割合89.8% は CC BY の症例集積（Radkova ら 2026）が引用し、長期転帰（死亡 5.6%/人年、主要心脳血管イベント 9.9%/人年）は CC BY 総説（Hayman ら 2026）に再掲がある。誘因の内訳や LVEF の値は再掲がなく、両件とも B。
8. **外傷系（MP-038〜042）は明暗が分かれた。** 鈍的心臓損傷のスクリーニングは CC BY の診断精度メタ解析（Kyriazidis ら、World J Emerg Surg 2023）が「心電図とトロポニンI の併用で除外できる」という結論で骨格を支持し MP-038 は B。MP-039（モニタリング推奨、胸骨骨折は予測因子でない）・MP-040（Beck の三徴 約10%、心エコー精度96〜97%）・MP-042（手術手技）は再掲がなく C。MP-041 は主張チェック：CC BY の胸部外傷総説にも「受傷機転と生命徴候で適応を決める」枠組みはあるが、生命徴候なしを禁忌としており EAST の条件付き推奨とは向きが異なり、生存率も EAST の集積値（21.3%・8.3%）とは別の範囲を示す。カードの記述は EAST 原典どおりで、ガイドライン固有のため C とした。
9. **識別子の誤りは0件。補完候補は11出典分。** 新規に確認したもの：SRC-251 PMID 11999637、SRC-252 PMID 26853248、SRC-253 PMID 26332547、SRC-254 PMID 37382827・PMCID PMC10356869、SRC-4383 PMID 34305070（カードは「確認できなかったため null」としていた）。カード側に登録済みで出典マスター未登録のもの：SRC-4384 PMID 21463150、SRC-4385 PMID 36027563、SRC-4386 PMID 17098886、SRC-4388 PMID 23114485、SRC-4442 PMCID PMC10226890、SRC-4444 PMCID PMC9451503。著者稿の PMCID（SRC-4384 の PMC3415273、SRC-4386 の PMC1860601）も実在を確認したが自由利用にはならない。主出典の DOI はすべて Europe PMC の個別レコードと一致した。
10. **主出典の区分の確認と、明確化の申し送り。** SRC-4442（Mediastinum）と SRC-4444（Can J Surg）は Europe PMC で cc by-nc-nd を確認し RESTRICTED と一致、SRC-4965（ESC 2025）も RESTRICTED が正しい。SRC-253（Templin ら NEJM 2015）は OA でなくライセンス表示もないため UNKNOWN→RESTRICTED への明確化が適切だが、バッチ36の扱いに倣い D には数えず申し送りとする。SRC-252（Acta Cardiol 要約）は Crossref に当該 DOI のレコード自体がなく、UNKNOWN の据え置きが妥当。本章の出典に新規の二重登録はなく、マスター全体の DOI 重複は既知の8組のみで本章分は含まれない。
11. **薬剤・制度の申し送り。** (1) MP-014 の「2020年時点では PYP シンチグラフィの保険適用はなかった」は歴史的な記述で、現行の診療報酬上の扱いは本調査では政府の全文文書で確定できなかった（指定難病の診断基準では同検査が ATTRwt の診断項目に含まれている）。登録時に確認されたい。(2) MP-007 のマバカムテンの承認日は、主出典の PMDA 審査報告書（2025年3月7日付）と PMDA の承認情報で登録時に確定でき、カードの uncertainty の解消経路として申し送る。(3) MP-024 のコルヒチンの心膜炎への国内保険適用は、本調査でも政府の全文文書で確定できなかった。

## 方法と留保

- レポジトリ側の指示（2026-11-11）による新ルールを適用した。**抄録・添付文書・医学百科は根拠にしない。** PubMed 抄録レコードに基づく「先例に基づく A」は廃止し、判定の根拠は政府の全文文書（厚労省の人口動態統計の公表表、NCI PDQ の専門家版サマリー）、CC BY の全文、試験登録レコード（ClinicalTrials.gov）など、全文として読める一次・公的資料のみとした。抄録は数値の食い違いの照合（主張チェック）にのみ用いた。
- 本章は肺癌の第III相試験のカードが多いため、ClinicalTrials.gov の結果レコード（API で取得）が裏づけの主な経路になった。登録レコードで裏づけられるのは B までであり、A にはしていない。
- 主出典のライセンスは Crossref の version-of-record と Europe PMC の license 表示で相互確認し、判定に関わるものは個別に再照会した。識別子は PubMed（eutils）で個別に確認したものだけを書いた。
- Bookshelf はボット確認で開けないため、NCI PDQ は cancer.gov の専門家版で代替した。
- Europe PMC の一括照会は応答が極端に遅かったため、判定に関わる項目はすべて個別照会で確定した。一括照会の結果は後に届き、全件を照合した（大半は個別照会の値と一致）。その過程で SRC-478（Cleve Clin J Med）の PMID 25085985 が新たに確認でき、補完候補に反映した。判定への影響はない。

## 特に重要な発見

1. **主出典の二重登録（既知の8組の1組）**：LC-035・036 の主出典 BTS 胸膜疾患ガイドラインは、出典マスターに **SRC-370 と SRC-485 の2件**で登録されている（同一 DOI 10.1136/thorax-2023-220304・同一書誌）。バッチ16のマスター全体の DOI 走査で確認済みの既知の重複であり、新規の重複ではない。統合の要否は登録側の判断。
2. **SRC-370 の書誌の申し送り**：マスターの書誌（Thorax 2023;78:1143-1156、PMID 37553157）はガイドラインの要旨版に対応する。全ガイドライン本文は Thorax 2023;78 Suppl 3（PMID 37433578、DOI 10.1136/thorax-2022-219784）で別書誌。
3. **識別子の補完候補（誤りは0件）**：
   - PMID 8出典分：SRC-370（37553157）、SRC-475（21252716）、SRC-476（31751012）、SRC-477（23094000）、SRC-478（25085985、Europe PMC と PubMed の DOI 照会で確認）、SRC-479（35118246）、SRC-565（29707502）、SRC-569（39268857）。SRC-569 はカードの「PMID は未照合」を解消できる。
   - DOI 2出典分：SRC-473（10.1056/NEJMoa1102873、カードは「DOI は未確認」としていた）、SRC-475（10.1097/JTO.0b013e318206a221）。
   - PMCID 8出典分：SRC-473（PMC4356534）、SRC-475（PMC4513953）、SRC-477（PMC3476611）、SRC-479（PMC8794420）、SRC-550（PMC8280089）、SRC-552（PMC9015199）、SRC-554（PMC10036605）、SRC-565（PMC5900094）。いずれも著者稿等でライセンス表示はなく、補完しても自由利用にはならない。
4. **主張チェック（両値記録）**：
   - LC-001：肺癌死亡数は確定数ベース 75,725人（カード）に対し、厚労省の月報年計の概数は 75,762人。集計段階の違い。
   - LC-036：胸水の提出量は BTS の 25〜50 mL に対し、NCI PDQ は「最低 250 mL」と述べており一致しない。PDQ の値は裏づけに使えない。
   - LC-040：OS のハザード比は初回報告 0.60（カード）に対し登録レコードの解析値 0.63（後のデータカット）。
   - LC-042：奏効率はカード 28.4% 対 16.0%（測定可能病変のある集団）に対し登録側 30.0% 対 17.8%（全無作為化集団）。死亡または遠隔転移までの期間も解析時点の違い（23.2 対 14.6 か月 vs 28.3 対 16.2 か月）。
   - LC-046：12か月時点の累積 CNS 進行率はカード 9.4% 対 41.4% に対し登録側 11.8% 対 45.0%。
   - LC-047：頭蓋内奏効率はカード 82% 対 23%（測定可能な脳転移のある集団）に対し登録側 65.8% 対 20.0%（ベースラインに脳転移のある集団）。
   - LC-051：OS のハザード比は3年報告 0.73（カード）に対し登録側 0.74。
   - LC-015 は逆に解消方向：カードの uncertainty にある CI 上限の記載差（抄録 0.997・本文 0.996）は、登録レコードの解析値 0.9963 が本文側と整合する。
5. **サーベイランス**：TNM 分類は第9版が刊行され適用が始まっている。LC-048 は第8版への改訂提案の論文を対象とする記述で誤りではないが、病期分類の現行版は第9版に移行している（小細胞肺癌への TNM 適用の枠組み自体は継続）。WHO 胸部腫瘍分類第5版（2021）でも AIS・MIA は維持され、TNM 第9版でも Tis・T1mi は存続する。
6. **ライセンスの確定・明確化**：SRC-479・SRC-560 は CC BY-NC-ND 4.0 で現行の RESTRICTED が正しい。SRC-477（Dtsch Arztebl Int の総説）は Crossref・Europe PMC・PMC 掲載ページのいずれでも CC ライセンスの一次表示を確認できず、**UNKNOWN の据え置きが妥当**（D にはしない）。SRC-565 は Europe PMC に license 表示がなかったが、誌の記事ページに基づく CC BY-NC-ND の記録と RESTRICTED は妥当。
7. **C の内訳の要点**：5年追跡の長期成績は登録レコードに載らないため LC-041・043 は C。国内試験 JCOG0802（LC-044）は ClinicalTrials.gov に登録自体がなく、CALGB 140503（LC-045）は登録はあるが結果未掲載。縦隔の総説群（LC-016〜018・021〜024）は、PMC で全文が読めてもライセンス表示がなければ自由利用ではないという原則どおり C とした。

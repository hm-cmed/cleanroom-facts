# バッチ55報告：KX 23件（パブリックドメイン出典の裏づけ調査）

**集計：A 0件／B 13件／C 10件／D（区分訂正）0件、計23件。区分訂正は別枠で記録する方式のため、カード判定は A・B・C のいずれかに数えた（区分訂正は0件だった）。**

## 判定ルール

- A：自由に使える出典（OPEN／GOV_US／GOV_JP）が主出典を置き換えられるもの。
- B：自由に使える出典を裏づけ（corroboration）として追加できるもの。
- C：政府の全文文書・報告書、CC BY 全文、結果が読める試験登録レコードのいずれでも、カードの主張を再述する資料が見つからなかったもの。
- D：出典マスターの区分（source_class）の訂正が必要なもの。カード判定とは別枠に分離して記録する（今回はなし）。

## 調査方法

- 対象は targets.json の接頭辞 KX 全23件（主出典は SRC-573・SRC-665〜SRC-690 の18件）。
- 主出典18件は、Europe PMC と Crossref で PMID・DOI ごとに個別に刊行版ライセンスを確認した。
- 候補の探索は Europe PMC の CC BY 全文を中心に行い、候補はいずれも全文を読み、カードの主張要素ごと・数値ごとに照合した（抄録・添付文書・医学百科は根拠にしていない）。
- 識別子（PMID・PMCID・DOI、巻・ページ）は候補ごとに個別に再照会して確定した（過去のバッチで一括照会の誤帰属が繰り返し起きたため）。
- 現行出典の説明は、出典マスター（sources.yaml）の書誌記載をそのまま転記し、提出前に SRC 番号との一致を照合した。

## 特に重要な発見

- **主出典18件は、いずれも自由に使える出典にはならず、現行の区分（全件 RESTRICTED）はすべて正しかった。** ガイドライン・総説級の主出典は、CC BY-NC-ND（KDIGO 2024、KDIGO 腎移植2009、ABO 不適合移植の集計）、CC BY-NC-SA（尿沈渣総説、中毒の体外除去総説）、CC BY-NC（血圧低下総説、ISPD 腹膜炎2022、共同意思決定総説）など、非営利条件付きのライセンスが大半を占める。PMC に全文があってもライセンス表示がないもの（BMJ 総説、腎生検総説、透析中血圧低下総説、結石の画像診断総説）も自由利用にはならなかった。
- **license_note の精密化候補が2件ある（区分は不変）。** SRC-573（KDIGO 2024）はマスターの注記が「出版社の著作物（CC の表示なし）」だが、Crossref の version of record と Europe PMC の個別レコードのいずれでも刊行版ライセンスは CC BY-NC-ND 4.0 である。SRC-686（KDIGO の薬剤投与量の更新）は注記が「TDM 用ライセンスのみ」だが、Crossref では version of record に Elsevier の open-access user license 1.0 も付されている。どちらも自由利用にはならないため区分の訂正ではなく、注記の書き換え候補として別枠に記録した。
- **B 判定13件の裏づけは、診断・評価の枠組みの再述が中心である。** 確度の高いものは、日本腎臓学会の CKD 診療ガイドライン2018の要点（CC BY、日本人の eGFR 推算式の逐条再掲と CGA 分類）、国内の腎生検ガイドブック2020（CC BY、相対的禁忌と日本の全国調査の合併症頻度）、ISPD 腹膜炎の診断基準を逐条で再掲した多施設研究（CC BY）、英国腎臓学会のバスキュラーアクセス診療ガイドライン2025（CC BY、「適切なアクセスを、適切な患者に、適切な時期に」とライフプランの枠組み）である。
- **数値が主出典固有で裏づけられない C が目立つ。** 米国の献腎移植の時代別10年生存率（KX-024）、ABO 不適合移植441例の生存率・生着率の系列（KX-030）、B 型肝炎ワクチンの抗体陽転率（KX-028）、血液透析での経験的な増量幅（KX-026）は、いずれも単一の解析・研究に固有の値で、自由な全文に再掲がなかった。
- **KDIGO 腎移植ガイドライン（2009年版）を主出典とする3件（KX-022・023・031）には、治療標準のその後の変化をフラグに挙げた。** 抗体関連型拒絶反応の治療標準の総説（2025年、CC BY）は、リツキシマブやステロイドの根拠を KDIGO 2009 より慎重に評価している。
- **PMCID の補完候補が7件ある**（マスターに pmcid が未登録の主出典について、個別照会で確認したもの。登録はレポジトリ側で PC の --online 照合後に行う）。

## 区分訂正の内訳

**区分（source_class）の訂正が必要なものはなかった。** 主出典18件（SRC-573・SRC-665〜SRC-690）はいずれも個別に刊行版ライセンスを確認した結果、政府の全文文書・報告書、CC BY 全文、結果が読める試験登録レコードのいずれにも当たらず、現行の RESTRICTED が正しい。

区分の訂正ではないが、出典マスターの license_note の記載を精密化できるものが2件ある。

- **SRC-573（KDIGO 2024、KX-006・KX-009 の主出典）**：マスターの license_note は「出版社の著作物（CC の表示なし）」だが、Crossref の version of record と Europe PMC の個別レコード（PMID 38490803）のいずれでも、刊行版ライセンスは CC BY-NC-ND 4.0 である。自由利用にはならないため区分は RESTRICTED のままでよいが、注記の記載は「CC BY-NC-ND 4.0（Crossref の license 欄、version of record）」への精密化が可能である。
- **SRC-686（KDIGO の薬剤投与量の更新、KX-025・KX-026 の主出典）**：マスターの license_note は「Elsevier の TDM 用ライセンスのみ（Crossref の license 欄。CC の表示なし）」だが、Crossref では version of record に Elsevier の open-access user license 1.0 が付されている。これは Elsevier 独自の利用許諾で CC ではなく自由利用にはならないため区分は RESTRICTED のままでよいが、注記の記載は精密化が可能である。

## フラグ（カードの再照合が要る事項）

- **KX-022・KX-023・KX-031（主出典 SRC-684）**：主出典の KDIGO 腎移植レシピエント診療ガイドラインは2009年版のままである。抗体関連型拒絶反応の治療については、2025年の治療標準の総説（NDT、CC BY）が血漿交換と免疫グロブリン静注を軸としつつリツキシマブやステロイドの根拠を KDIGO 2009 より慎重に評価しており、治療標準はその後も動いている。次回改訂時に拒絶反応治療とウイルス予防の記載の再照合が要る。
- **KX-030（主出典 SRC-690）**：カードは1989〜2001年の歴史的コホートの成績であり、uncertainty にも時代の留保がある。CC BY の総説（Frontiers in Immunology. 2017）では、現在の ABO 不適合腎移植の移植腎生着率は適合移植と同等とされる。主張の置き換えではなく、次回改訂時に現代の成績との併記を検討する材料として挙げる。
- **KX-006・KX-009（主出典 SRC-573）**：license_note の精密化候補（区分は不変）を上記「区分訂正の内訳」に記録した。SRC-686（KX-025・KX-026 の主出典）についても同様である。

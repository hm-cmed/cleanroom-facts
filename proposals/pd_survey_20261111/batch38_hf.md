# バッチ38：HF（心不全）31件 ― パブリックドメイン出典の裏づけ調査

- 対象：`targets.json` のうち章プレフィックス HF の31件（HF-001〜031）
- 調査日：2026-11-11
- 判定：**A 置き換え可 4件／B 裏づけ追加 21件／C 見つからない 6件／D 区分の訂正 0件**
- ルール：2026-11-11 の新ルールを適用。抄録・添付文書・医学百科は根拠にせず、政府の全文文書・報告書、CC BY の全文、試験登録レコードなど全文として読める資料のみを候補とした。A は自由な全文で主張全体を置き換えできるものだけ、部分的な裏づけは B。主張文と数値は変更していない。
- 本章の特殊事情：HF は2026-11-08の旧ルール調査（自由に使える出典の調査）で多くのカードに裏づけが登録され、一部は主出典の置き換え（SRC-4990〜4993）まで適用済みである。本バッチはそれらを新ルールで再評価したもので、旧調査の結論と異なる判定（HF-014・015・018 の B、HF-019・022 の C）にはその理由を明記した。

## 調査方法

- 主出典18件（SRC-185〜201・4380。適用済み置き換え後の主出典 SRC-4990〜4993 を含む）について、Europe PMC の個別照会でライセンス表示と PMCID を確認し、主要な DOI は Crossref の version-of-record ライセンスも個別に確認した。
- 試験が主出典のカードは ClinicalTrials.gov の API で結果レコードの有無と、主要評価項目の件数・ハザード比・有害事象を直接確認した。
- CC BY 候補は Europe PMC の全文 XML を取得し、主張の要素ごとに検索して照合した。政府・公的資料のうち本章で使えたのは ClinicalTrials.gov の結果レコードのみである。
- 薬剤・医療機器の国内承認の更新は Web 検索で当たりを付け、判定根拠には使わず登録時の確認事項として申し送りに回した。

## 特に重要な発見

1. **A は4件で、いずれも登録側で適用済みの置き換え（SRC-4990〜4993）が新ルールでも維持できることを全文照合で確認したもの。** HF-006（SRC-4990、Baba ら 2019 の総説に Breathing Not Properly 研究の1,586人・診断精度83.4%・陰性的中率96% が明記）、HF-023（SRC-4991、J Clin Med 2026 総説に IABP-SHOCK II の600人・39.7%対41.3% が明記）、HF-024（SRC-4992、CULPRIT-SHOCK の経済評価論文に706人・45.9%対55.4%・相対リスク0.83 が明記）、HF-029（SRC-4993、Sampath-Kumar ら 2025 に利尿薬＋原因治療が管理の軸であること、右室そのものに証明された薬物療法がないこと、心臓MRI が基準標準であることが明記）。
2. **試験登録レコードの掲載範囲が判定を分けた。** PARADIGM-HF（HF-014）は登録に件数と有害事象はあるがハザード比（0.80・0.84）の掲載がなく B（従来の照合は FDA ラベル併用で、新ルールでは根拠にできない）。DAPA-HF（HF-015）は登録に件数とハザード比0.74 があるが、糖尿病の有無による効果の一貫性は登録にサブグループ結果がなく B。EMPEROR-Preserved（HF-018）は登録が100患者年あたりのイベント率表示で、カードの累積割合（13.8%対17.1%）そのものは登録になく B。いずれも「登録に全数値があれば A」というバッチ36（AZA-001）の基準に照らした判定である。
3. **既登録の裏づけが現状では成立しないものが2件ある（申し送り）。** HF-019（CARE-HF）の裏づけとされる ClinicalTrials.gov レコード NCT00170300 は、本調査で API を確認したところ結果が未掲載（hasResults=false）だった。長期追跡の別レコード（NCT00318357）には結果があるが原著（追跡中央値29.4か月）とは対象期間が異なる。HF-022（SHOCK 試験）の登録レコード NCT00000552 も結果未掲載で、数値を再掲する唯一の CC BY 総説（J Cardiovasc Dev Dis 2026）は表に誤記がある（発見4）。両件とも新ルールでは C とし、カード側の裏づけ記録の見直しを申し送る。
4. **主張チェック（候補側の誤り、両値を記録）**：HF-022 の候補総説（Aubdool AA, et al. J Cardiovasc Dev Dis. 2026、PMC13116365）は、本文では SHOCK 試験の6か月死亡率を 50.3%対63.1% と正しく述べるが、表では 50.3・63.7 を「30日」の値として誤記し、対照側も 63.7（正しくは6か月の63.1）と誤っている。カードの数値（30日 46.7%対56.0%、6か月 50.3%対63.1%）は原著どおりで、誤りは候補側にある（従来の裏づけ記録の指摘を本調査でも再確認した）。このほか HF-001 では HFimpEF の初回値の表記がカード「40%以下」と候補の再定義基準「40%未満」で等号のみ異なり、HF-020 では心係数の閾値がカード「2.2以下」と候補「2.2未満」で等号のみ異なる（いずれも両値を明細に記録）。
5. **StatPearls による既登録の裏づけは新ルールで根拠から外した（HF-010・012）。** 両カードの裏づけは StatPearls（NBK554557）のみだったため、CC BY の急性心不全総説で骨格の裏づけを付け直して B とした。トルバプタンの併用（HF-010）など日本固有の要素は自由な全文の範囲外である。
6. **主出典に CC BY はなく、D は0件。** SRC-185（JCS/JHFS 2025）は J-STAGE 表示の CC BY-NC-ND で RESTRICTED が正しく、SRC-187（Circ Rep 2022）も Europe PMC で cc by-nc-nd を再確認した。SRC-186（Circ J 2008）は Crossref・Europe PMC のいずれでもライセンス表示がなく UNKNOWN の据え置きが妥当。その他の主出典（NEJM 群、Eur Heart J、JACC、Crit Care Med、Wiley、AHA 科学声明）はいずれも CC 表示がなく RESTRICTED と一致する。Universal Definition 原典（HF-001 の原典候補）は J Card Fail 版・Eur J Heart Fail 版とも Crossref で出版社利用条件のみで CC BY ではなかった。
7. **識別子の誤りは0件。補完候補は2出典分**：SRC-187 の PMCID PMC8901245（カード側には登録済み、出典マスター未登録。Europe PMC で実在を確認）と、SRC-4380 の PMID 29650544（カード側には登録済み、出典マスターは null。Europe PMC で DOI と一致を確認）。主出典の DOI・PMID はすべて Europe PMC の個別レコードと一致した。同一文献の二重登録は本章の出典にはなく、マスター全体の DOI 重複は既知の8組のみだった。
8. **サーベイランス（版・承認の変更）**：
   - **第2版 Universal Definition（2026）が刊行された**（解説：ESC Heart Fail. 2026、CC BY、PMID 42744306）。中核の症候群定義はほぼ不変だが、固定の LVEF カットオフを「恣意的」と批判し見直しを提起している。JCS/JHFS 2025 は第1版準拠のため、HF-001 は将来の照合直しの対象になりうる。
   - **フィネレノン（ケレンディア）が2025年12月に慢性心不全（左室駆出率40%以上）の追加適応で国内承認された。** HF-017 の uncertainty（「フィネレノンの心不全への国内承認状況は本出典では確認していない」）は登録時に PMDA の全文文書で解消できる。企業発表は判定根拠にしていない。
   - **Impella は国内で「心原性ショック等の薬物療法抵抗性の急性心不全」を適応として承認済み**で、HF-025 の uncertainty（「国内での保険適用の条件は未確認」）も PMDA 公開文書で解消できる見込み（同上）。
   - SCAI 分類の2022年改訂版（HF-021）はカードの uncertainty に既記で、本調査でも新規の論点はない。

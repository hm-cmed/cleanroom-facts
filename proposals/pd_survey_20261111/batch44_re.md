# バッチ44（RE 28件）の調査結果

集計：A 置き換え可 2件／B 裏づけ追加 20件／C 見つからない 6件／D 区分の訂正 0件

判定ルールは新ルール（2026-11-11、レポジトリ側決定）を適用した：**抄録・添付文書・医学百科は根拠にしない**。使える候補は政府の全文文書・報告書（NCI PDQ・NEI・ClinicalTrials.gov 等）、CC BY の全文など、全文として読める資料のみ。A は「全文の自由資料で主張全体を置き換えできるもの」だけとし、一部しか裏づけられないものは B とした。既に裏づけ・置き換えが登録されているカードはなかったため、再評価の対象はなかった。

## 調査方法

- 対象28件の主出典は、出典マスター（data/sources/sources.yaml）の記載で同定し、Europe PMC の個別レコードと Crossref の version-of-record ライセンスで扱いを確認した。出典の説明はマスターの記載から機械的に取った。
- 候補は Europe PMC の全文 XML（CC BY 総説等）、NCI PDQ と NEI の政府ページ（GOV_US、実際に開いて本文を確認）、ClinicalTrials.gov の登録・結果レコードで、主張の要素ごとに照合した。
- 候補のライセンスは Europe PMC の表示と Crossref の VoR の両方で確認し、食い違う場合は採用しなかった。補完候補の PMID・PMCID・DOI は、PMID または DOI で個別に再照会し、タイトルと著者が当該文献と一致することを確認してから記載した。
- 主張文と数値は変更していない。数値が候補と食い違う場合は、両値を「数値照合」欄に記録した。

## 特に重要な発見

1. **置き換え可（A）が 2 件**あった。いずれも試験が主出典のカードで、**RE-004**（BRAVO 試験、網膜静脈分枝閉塞症）と **RE-005**（CRUISE 試験、網膜中心静脈閉塞症）は、ClinicalTrials.gov の結果レコード（NCT00486018・NCT00485836）に6か月時点の視力変化と15文字以上の改善割合がすべて掲載され、カードの全数値と一致した。同じく登録で数値が支えられた **RE-003**（Protocol T）と **RE-015**（SCORE2）は、視力の数値がすべて登録と一致したが、重篤な有害事象の総括（RE-003）と非劣性マージン5文字での非劣性解析（RE-015）が登録レコードになく B にとどまる。**RE-012**（MARINA 試験）は登録レコード（NCT00056836）に結果が未掲載で、新ルールでは裏づけとして成立せず C とした。
2. **D はゼロ**。主出典（重複を除く27出典）を Europe PMC と Crossref で個別に確認し、CC BY の主出典はなかった。SRC-1292（中心性漿液性脈絡網膜症の総説）と SRC-4622（EULAR Behçet 推奨2025年改訂版）は両経路で CC BY-NC-ND を確認し、マスターの RESTRICTED と一致する。SRC-1278（網膜芽細胞腫の総説、Indian J Ophthalmol）は Europe PMC で CC BY-NC-SA を確認したが、UNKNOWN から RESTRICTED への明確化は申し送りにとどめ、D には数えていない（バッチ43の扱いに同じ）。SRC-4377（飛蚊症の調査、Int J Ophthalmol）は両経路でライセンス表示を確認できず、UNKNOWN の据え置きが妥当である。
3. **主出典の識別子補完候補が9出典・11件**ある。SRC-1283 の PMCID PMC4422053、SRC-1294 の PMCID PMC5710547、SRC-1271 の PMCID PMC5475221、SRC-1272 の PMCID PMC8526627、SRC-1278 の PMCID PMC11232864、SRC-1312 の PMCID PMC8935739、SRC-1313 の PMCID PMC9073858、SRC-4376 の PMID 32313173 と PMCID PMC7182575、SRC-4377 の PMID 23826541 と PMCID PMC3693028 で、いずれも PMID で個別に再照会しタイトル・著者の一致を確認した（PMCID は著者稿等でライセンス表示がなく自由利用ではない）。主出典の DOI・PMID に誤りはなく、本バッチの範囲で新たな二重登録はなかった。候補として挙げた文献の DOI はすべて出典マスターに未登録であることを確認した。
4. **主張チェックが3件**ある。（1）**RE-024**（ぶどう膜悪性黒色腫）の発症率は、カードが「ヨーロッパと米国で年間100万人あたり約6人」とするのに対し、CC BY の候補総説は「米国とヨーロッパで約4〜6人」の範囲で示し、NCI PDQ の米国の値は約4.3人／100万人である（両値を明細に記録）。（2）**RE-023**（網膜芽細胞腫）は、候補の PDQ が遺伝性25〜30%／非遺伝性70〜75%という分け方で、カードの片側性60〜70%／両側性30〜40%とは割合の軸が異なる（矛盾ではない）。（3）**RE-030**（飛蚊症の調査）の「近視で3.5倍、遠視で4.4倍」は候補にも再掲があるが、候補の表現は「飛蚊症のある人の中での多さ」で、カードの「中等度以上の飛蚊症の訴え」という枠組みとは表現が異なる。なお RE-018（硝子体出血）の頻度と原因の内訳は1997年の主出典固有の値で、抄録とは一致するが新ルールでは根拠にできない。
5. **腫瘍系とぶどう膜炎系の裏づけの経路**。腫瘍系では NCI PDQ（RE-023、網膜芽細胞腫）と CC BY の分子生物学総説（RE-024、ぶどう膜悪性黒色腫）が B の経路になった。ぶどう膜炎系の分類基準のカード（RE-026・027）は、CC BY の再掲が分類の原則や構成要素の列記にとどまり充足形式そのものの再掲はなく、いずれも B。RE-031（Behçet病の EULAR 推奨）は、視力を脅かすぶどう膜炎への抗TNF療法の第一選択という方向は CC BY 総説で裏づけられるが、推奨4の具体（寛解の目標、用量、単独療法の回避、段階付け）は再掲がなく B にとどまる。

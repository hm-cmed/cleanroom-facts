# バッチ43（HS 28件）の調査結果

集計：A 置き換え可 2件／B 裏づけ追加 18件／C 見つからない 8件／D 区分の訂正 0件

判定ルールは新ルール（2026-11-11、レポジトリ側決定）を適用した：**抄録・添付文書・医学百科は根拠にしない**。使える候補は政府の全文文書・報告書（難病情報センター・NIH ODS・ClinicalTrials.gov 等）、CC BY の全文など、全文として読める資料のみ。A は「全文の自由資料で主張全体を置き換えできるもの」だけとし、一部しか裏づけられないものは B とした。既に裏づけ・置き換えが登録されているカードはなかったため、再評価の対象はなかった。

## 調査方法

- 対象28件の主出典は、出典マスター（data/sources/sources.yaml）の記載で同定し、Europe PMC の個別レコードと Crossref の version-of-record ライセンスで扱いを確認した。出典の説明はマスターの記載から機械的に取った。
- 候補は Europe PMC の全文 XML（CC BY 総説等）、難病情報センターの疾患ページ（GOV_JP）、NIH ODS のファクトシート（GOV_US）、ClinicalTrials.gov の登録・結果レコードで主張の要素ごとに照合した。政府ページは実際に開いて本文を確認した。
- 候補のライセンスは Europe PMC の表示と Crossref の VoR の両方で確認し、食い違う場合は採用しなかった。補完候補の PMID・PMCID・DOI は、PMID または DOI で個別に再照会し、タイトルと著者が当該文献と一致することを確認してから記載した（本バッチでも、主出典の PMCID の対応づけを個別照会で検証した。下記「特に重要な発見」5）。
- 主張文と数値は変更していない。数値が候補と食い違う場合は、両値を「数値照合」欄に記録した。

## 特に重要な発見

1. **置き換え可（A）が 2 件**あった。**HS-007**（免疫性 TTP の治療推奨）は、CC BY の TTP 治療総説（Rodgers 2026、Front Pharmacol）の表に、ISTH の3推奨とその強さ（血漿交換＋ステロイド＝強い推奨、リツキシマブ・カプラシズマブ＝条件付き推奨）がすべて明記されていた。候補が引用する2025年 focused update は2020年版の当該推奨を変更していないため、主張と実質同一である。**HS-035**（APS の二次予防）は、CC BY の APS 総説（Stańczewska ら 2025、Metabolites）の推奨表に、EULAR 2019 の「初めての静脈血栓塞栓症では VKA（INR 2.0〜3.0）」「三重陽性ではリバーロキサバンを使用すべきでない」が再掲されていた。
2. **試験登録レコードが数値の核を支えた2件**（HS-010・011）。ラブリズマブの完全 TMA 反応 53.6%（HS-011）は ClinicalTrials.gov（NCT02949128）の結果レコードと完全一致し、構成要素（血小板正常化 83.9%、LDH 正常化 76.8%、クレアチニン25%以上の改善 58.9%）と8週ごとの維持投与まで登録で確認できた。一方エクリズマブ（HS-010）では、血漿療法継続群の TMA イベントフリー 80% は登録と一致したが、**血小板数の26週変化は登録が +65.18×10⁹/L でカードの +73×10⁹/L と異なる（主張チェック、両値を記録）**。透析離脱（5例中4例）と eGFR の早期開始の解析は登録の評価項目になかった。
3. **難病情報センター（GOV_JP）の疾患ページが3件で B の経路になった**。TTP（指定難病64、HS-006）は ADAMTS13 活性10%未満という診断の核とインヒビター測定が、後天性血友病A（指定難病288、HS-026・027）は診断基準とバイパス止血療法・免疫抑制療法の骨格が、オスラー病（指定難病227、HS-031）は診断基準と責任遺伝子が、それぞれ政府の全文で裏づけられた。いずれも国際ガイドラインの推奨の格付けや固有の数値までは届かず B にとどまる。
4. **D はゼロ**。主出典（重複を除く24出典）を Europe PMC と Crossref で個別に確認し、CC BY の主出典はなかった。DIC 診療ガイドライン2024の英語版2件（SRC-2655・2656、Int J Hematol）は Crossref が Springer の TDM リンクのみで、バッチ42 で章ごとに CC BY のものがあった JSH ガイドライン英語版とは扱いが異なることを確認した。Blood Advances の ASH ガイドライン群は Crossref のライセンス欄が空で、Europe PMC で CC BY-NC-ND を確認できたのは SRC-2643・2664 のみだったが、いずれも RESTRICTED と矛盾しない。UNKNOWN の2出典（SRC-2650・449）は自由利用でないことは確かだが、RESTRICTED への明確化は申し送りにとどめた。
5. **主出典の識別子補完候補が4出典・5件**ある。SRC-2643 の PMCID PMC13696133、SRC-2659 の PMCID PMC7805326、SRC-2660 の PMCID PMC7327664 は、いずれも PMID で個別に再照会しタイトル・著者の一致を確認した（著者稿等でライセンス表示がなく自由利用ではない）。SRC-449 の PMID 32894695 は DOI 照会で確認し、カード側のリサーチ記録とも一致した。SRC-2651 の DOI 10.2491/jjsth.29.288 は Crossref でタイトル・巻・ページ・著者が一致することを確認した。なお **SRC-2666 の PMCID PMC11034817 は誤帰属ではない**：2019年の論文が後年になって PMC に収載されたもので、PMID 31092409 の個別レコードで本論文の PMCID であることを確認した。主出典の DOI・PMID に誤りはなく、本バッチの範囲で新たな二重登録はなかった。
6. **カード側の記載と出典マスターの食い違いが1件**（HS-003）。カードの uncertainty は主出典を「ASH 2019年版のfocused update」と記載するが、出典マスターの記載と Europe PMC の実レコードは「American Society of Hematology 2026 guidelines for immune thrombocytopenia: initial and second-line therapy for adults with primary ITP」（Blood Adv. 2026;10:7076-7097）である。主張文の内容（初期治療でのリツキシマブ・トロンボポエチン受容体作動薬の併用の条件付き推奨、第二選択での同薬の強い推奨）は2026年版の題名の範囲と整合するが、記載を勝手に寄せず申し送りとする。
7. **サーベイランス**：（1）遺伝子組換え ADAMTS13 製剤（アジンマ®）は、日本血栓止血学会誌の総説（J-STAGE）によれば2024年3月に先天性 TTP の適応で国内承認されており、HS-008 の uncertainty の「国内承認・保険適用の状況は確認できなかった」は PMDA の全文文書で解消できる見込みである（学会誌の記載は判定根拠に使っていない）。（2）HS-021 の候補（CC BY の DIC 総説）は JSTH 基準を2016年としており、カード・ガイドラインの「2017年版」と年次表記が異なる（基準自体は同一系統）。

詳細は系統別の3ファイル（brushup_b_stroke.md、brushup_b_nose_hae.md、brushup_b_ms_esmo.md）。ここは判定の要約と、実施に必要な作業の一覧。

|---|---|---|
| 脳卒中 ST-002・005・019・025・049、NX-002・017（7件） | **全件、主張の書き換えは不要** | 改訂2025を新規 SRC として登録し、provenance を付け替える。推奨を書いた3件（ST-005・019・025）は、学会公式の改訂抜粋 PDF（2025-06-30 公開、改訂52項目）で推奨文そのものを原文照合済みで、いずれも骨格が維持されていた |
| 鼻 NL-003（定義・分類・診断） | **付け替えのみで可** | 2024年版（第10版）を新規 SRC 登録し付け替え。local allergic rhinitis の一文追加は任意（本文照合のうえ） |
| 鼻 NL-004（疫学） | **主張の書き換えが必要** | 2019年全国疫学調査の数値に更新（アレルギー性鼻炎 49.2%、花粉症 42.5%、スギ花粉症 38.8%）。現行の年齢別の文（通年性は若年層・スギは中年層）は2019年調査では「5歳以上の全年代でスギ花粉症が最多」となり不正確 |

| HAE SK-013 | **付け替え＋書き換え** | 出典を SRC-1078（WAO/EAACI 2021）から **SRC-3092（WAO 2025、登録済み）** へ付け替え、新薬を反映して書き換える。国内版（補体学会 改訂2023）への付け替えは、ID-011 と役割が重なり版も古くなるため推奨しない |
| MS ND-050 | **付け替え＋拡張** | 2024年改訂論文（Montalban 2025）を新規 SRC 登録し付け替え。主張の構造（髄液陽性が時間的多発を代替）は維持され、定義がオリゴクローナルバンド「または κ遊離軽鎖指数」に拡張。追加カード案：視神経の第5部位、central vein sign／paramagnetic rim lesions、RIS の診断、DIT を要しない診断経路 |

| 小児白血病 PB-014〜016（JSPHO） | **保留（従来どおり）** | 2026年版の書籍・電子版の入手待ち（案B 適用済み） |

## 系統別の要点

### 脳卒中（改訂2025）
- 書誌：『脳卒中治療ガイドライン2021〔改訂2025〕』第3版、日本脳卒中学会、協和企画、2025-08-30、ISBN 978-4-87794-241-0。全140項目中52項目を改訂。
- ST-005：脳出血の降圧は CQ 化され「早期に収縮期140未満へは妥当（B／高）」。ニカルジピン名指し部分は推奨度 C のため、付け替え時に内訳を uncertainty に添えると精密になる。新要素（下限110超の維持、降下幅90超は勧められない等）は拡充候補。
- ST-019：3剤（クラゾセンタン B／中、ファスジル・オザグレル B／低）とも維持。ニモジピンは現在も国内未承認（改訂2025の解説にも明記）。
- ST-025：抗凝固の中核は変更なし（学会誌解説も明記）。DOAC 開始時期の早期化などの周辺変更は主張の範囲外。
- 申し送り：SRC-1561 と SRC-1581 が同一の2021〔改訂2023〕を指している点の整理可否はレポジトリ側の判断。

### 鼻アレルギー（2024年版・第10版）
- 書誌：日本耳鼻咽喉科免疫アレルギー感染症学会 編、金原出版、2024-03-31、ISBN 978-4-307-37140-7。英語要約版は Auris Nasus Larynx. 2025;52(4):426-441（DOI 10.1016/j.anl.2025.05.005、PMID 40544726）。
- **現行の SRC-1373（Allergol Int 2020）は日本語2016年版ベースの英語版で、実質2つ前の版**だった。差し替えの優先度は当初の想定より高い。
- 主な改訂：生物学的製剤の節の新設、LAR の分類への追加、疫学の2019年調査への更新、血管収縮薬の短期使用＋ステロイド併用の CQ 化、舌下免疫の持続エビデンス追加、治療選択の簡素化。

### HAE（WAO 2025）
- WAO 2025（Vázquez DO, et al. World Allergy Organ J. 2026;19(5):101335、PMID 42165046）は第45回で SRC-3092 として登録済み。2021年版（WAO/EAACI 共同）から分類の再編、発作時の経口セベトラルスタット追加、長期予防へのガラダシマブ・ドニダロルセン追加、treat-to-target 化。
- 国内承認の確定：**ガラダシマブは2025-02-20 に国内承認済み**、**セベトラルスタットは2025-12-22 承認・2026-03 薬価収載済み**。SK-013 の uncertainty の「国内承認は未確認」は失効している。ドニダロルセンは国内未承認（開発中）。
- 副次事項：ID-011 の uncertainty に残るセベトラルスタットの「薬価収載・発売時期は未確認」も解消済み（訂正メモの候補）。

### McDonald 2024
- 書誌：Montalban X, et al. Lancet Neurol. 2025;24(10):850-865（DOI 10.1016/S1474-4422(25)00270-4、PMID 40975101）。
- ND-050 の主張は維持。切り替え時の uncertainty の宿題（取り込み側の判断待ち）は解消できる。
- なお ID-007 と SD-029 は著者名（McDonald-McGinn、McDonald EJ）の一致による別文献で、McDonald 基準とは無関係だった。SD-029 は StatPearls 置き換えの別枠で扱う。

## 実施の形（登録側への提案）

差し替え・書き換えは、内容が変わらないものは出典の付け替え、変わるものは新カード作成＋旧カード retired（StatPearls redo と同じ形）で進めるのがよい。必要な登録は次のとおり。

- 新規 SRC：脳卒中 改訂2025、鼻アレルギー2024年版（日本語版。英語要約版を別登録するかは判断事項）、McDonald 2024 論文
- 付け替えのみで新規 SRC が不要なもの：SK-013（→ SRC-3092 登録済み）
- 本文照合が前提で保留：NL-021（日本語版の治療表）、ESMO 2026（本文または Living Guideline）、PB-014〜016（書籍入手）

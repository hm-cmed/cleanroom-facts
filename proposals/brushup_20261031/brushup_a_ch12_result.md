# レベル a 1件項目の仕分け（第Ⅻ章・感染症）

対象13項目について、既存の1件のカードの主張と、隣接項目のカードが担う側面を確認したうえで仕分けた。

| 項目 | 既存カード | 判定 | 理由／2件目の側面と出典の見込み |
|---|---|---|---|
| Ⅻ-1-A-⑱ ウイルス性髄膜炎 | NI-008 | 増強が要る | NI-008 は髄液所見の型（細菌性は好中球優位・糖低下、ウイルス性はリンパ球優位・糖正常）の判別を書いたカードで、細菌性髄膜炎と兼用の側面のみ。ウイルス性髄膜炎そのものの原因ウイルス（エンテロウイルス、ムンプス、HSV-2 など）、臨床経過（多くは予後良好）、治療（支持療法、単純ヘルペスが否定できない場合のアシクロビル先行投与）はどのカードにもない（NI-001 は単純ヘルペス脳炎で、髄膜炎ではない）。2件目：原因・臨床像・治療。新規の一次資料（ウイルス性髄膜炎の総説・ガイドライン級）が要る見込み |
| Ⅻ-2-A-① クラミジア肺炎 | CM-001 | 増強が要る | 疫学（市中肺炎の約10%、潜伏期約21日、遷延する咳）のみ。臨床像の進み方、診断（血清診断の限界、核酸検査、集団発生）、治療（マクロライド・テトラサイクリン系）が欠ける。2件目：診断と治療。新規の一次資料（肺炎ガイドラインの非定型肺炎の節や病原体総説）が要りそう |
| Ⅻ-2-A-② 性器クラミジア感染症 | UR-020 | 増強が要る | 米国 CDC 2021 の治療レジメン（ドキシサイクリン等）のみで、地域も米国。臨床像・疫学（無症状感染が多い、若年層に多い）、診断（核酸増幅検査）、合併症（骨盤内炎症性疾患、卵管性不妊）、日本の推奨が欠ける。UR-016（尿道炎の総論）は原因微生物として触れるにとどまる。2件目：臨床像・診断・合併症と日本の位置づけ。新規の一次資料（国内の性感染症ガイドライン等）が要る見込み |
| Ⅻ-2-A-③ マイコプラズマ肺炎 | CM-002 | 増強が要る | 日本のマクロライド耐性率の推移のみで、単一の研究グループのデータ（出典の表から換算）だけを写した形。一般像（若年者の異型肺炎、乾性咳嗽の遷延、肺外症状）、診断（抗体価、遺伝子検査）、治療（マクロライド第一選択、耐性例での代替薬）が欠ける。2件目：臨床像・診断・治療。新規の一次資料（成人肺炎診療ガイドライン等）が要る見込み |
| Ⅻ-2-B-⑤ 表皮ブドウ球菌感染症 | BA-010 | 増強が要る | コアグラーゼ陰性ブドウ球菌の位置づけ・主要菌種・人工物関連感染・耐性の課題までを総論としてはカバーするが、本菌に固有で最も重要な臨床上の問題である「血液培養のコンタミネーションと真の菌血症の区別」と、カテーテル関連血流感染・人工物感染の診断と治療（デバイスの扱いを含む）が欠ける。2件目：臨床像と診断・治療。新規の一次資料（カテーテル関連血流感染症のガイドライン等）が要りそう |
| Ⅻ-2-B-⑥ 淋菌感染症 | UR-019 | 増強が要る | 米国 CDC 2021 の治療レジメン（セフトリアキソン単回筋注）のみで、地域も米国。臨床像（男性の尿道炎、女性の子宮頸管炎、咽頭・直腸感染、播種性淋菌感染症）、診断（核酸増幅検査と培養・感受性）、薬剤耐性の状況と日本の推奨用量が欠ける。UR-016（尿道炎の総論）は原因として触れるにとどまる。2件目：臨床像・診断・耐性と日本の推奨。新規の一次資料（国内の性感染症ガイドライン等）が要る見込み |
| Ⅻ-2-B-⑩ モラクセラ・カタラリス感染症 | BA-015 | 1件で十分 | ヒト専用の呼吸器病原体という性格、年齢による保菌率の差、起因頻度（小児の急性中耳炎の15〜20%、成人の COPD 増悪）、β-ラクタマーゼ産生とアンピシリン耐性まで、病原体項目の骨格を1件でカバーしている。治療の各論は中耳炎・COPD 増悪という疾患側のカードの範囲 |
| Ⅻ-2-B-⑭ クレブシエラ感染症 | BA-023 | 増強が要る | 耐性遺伝子の供給源・運び手という総論のみで、カード自身が「臨床像に踏み込んでいない」と明記している。臨床像（院内肺炎、尿路感染、菌血症、過毒力型による肝膿瘍と糖尿病・東アジアとの関連）と、ESBL・カルバペネマーゼ産生菌への治療の考え方が欠ける。2件目：臨床像と治療。新規の一次資料（臨床像の総説、耐性菌治療のガイダンス等）が要りそう |
| Ⅻ-2-B-⑮ セラチア感染症 | BA-024 | 増強が要る | NICU の新生児に限った感染像・伝播・耐性で、カード自身が「成人での感染像は扱っていない」と明記している。成人・院内全般の感染像（肺炎、尿路感染、血流感染）と、内因性耐性（AmpC 産生、アンピシリン・初期セファロスポリンへの耐性）を含む治療の側面が欠ける。2件目：成人の臨床像と耐性・治療。新規の一次資料が要りそう |
| Ⅻ-2-B-⑱ 緑膿菌感染症 | BA-029 | 増強が要る | 病原体の適応・生存・耐性機構とバイオフィルムの総論で、臨床像と治療がない（薬剤名を扱わない形になっている）。臨床像（院内肺炎、熱傷・創部感染、悪性外耳道炎、好中球減少時の菌血症）と、抗緑膿菌薬の選択を含む治療が欠ける。2件目：臨床像と治療。出典は IDSA の薬剤耐性グラム陰性菌ガイダンス等が候補で、国内承認の確認とセットで新規の一次資料が要る見込み |
| Ⅻ-2-B-⑲ アシネトバクター感染症 | BA-030 | 増強が要る | 耐性機構の列挙のみ。臨床像（人工呼吸器関連肺炎、血流感染、ICU でのアウトブレイクと環境表面での長期生存）と、カルバペネム耐性株への治療が欠ける。2件目：臨床像と治療。新規の一次資料（耐性菌治療のガイダンス等）が要りそう |
| Ⅻ-2-B-⑳ ガス壊疽 | BA-031 | 増強が要る | BA-031 自体は「IDSA の皮膚軟部組織感染症ガイドライン2014に推奨が収められている」という所在の提示のみ。臨床像・治療の実質は隣接項目の SD-034（Ⅲ-3-J-⑧ ガス壊疽）が担っている（筋壊死の定義、急速な進展、緊急デブリードマンと抗菌薬）。残る欠けはウェルシュ菌の病原性の側面で、α毒素と筋壊死の関係は BA-031 自身が「一次資料は照合できていない」と明記している。2件目：病原性（α毒素）と検査所見。新規の一次資料が要る見込み。なお代替として、SD-034 へ本項目の番号を付記すれば臨床像・治療の面は受けられる |
| Ⅻ-2-B-㉒ バクテロイデス感染症 | BA-032 | 1件で十分 | 共生から腸管外逸脱による菌血症・膿瘍という病原性、嫌気性菌感染症の大部分に関与する地位と関連死亡率、B. fragilis の分離頻度、耐性機構と耐性増加まで、病原体項目の骨格を1件でカバーしている。治療の各論（膿瘍ドレナージ、嫌気性菌カバーの選択）は腹腔内感染症など疾患側のカードの範囲 |

## 集計

- 増強が要る：11件（Ⅻ-1-A-⑱、Ⅻ-2-A-①、Ⅻ-2-A-②、Ⅻ-2-A-③、Ⅻ-2-B-⑤、Ⅻ-2-B-⑥、Ⅻ-2-B-⑭、Ⅻ-2-B-⑮、Ⅻ-2-B-⑱、Ⅻ-2-B-⑲、Ⅻ-2-B-⑳）
- 1件で十分：2件（Ⅻ-2-B-⑩ モラクセラ・カタラリス感染症、Ⅻ-2-B-㉒ バクテロイデス感染症）

## 傾向

- 欠け方には3つの型がある。(1) 病原体の総論・耐性のみで臨床像と治療がない型（クレブシエラ、緑膿菌、アシネトバクター、セラチアの成人像）。(2) 米国ガイドラインの治療レジメンのみで、臨床像・診断・日本の推奨がない型（性器クラミジア、淋菌）。(3) 疫学・耐性率など単一の数値的主題のみで一般像がない型（マイコプラズマ肺炎、クラミジア肺炎）。
- 2件目はいずれも臨床像・診断・治療の側面で、出典は既存カードの出典では足りず、新規の一次資料（国内ガイドライン、耐性菌治療のガイダンス、病原体の臨床総説）を用意する必要のあるものが大半。
- 数え方の注記2件。NI-008 は細菌性髄膜炎との兼用カードで、ウイルス性髄膜炎の側面は髄液所見の判別にとどまる。BA-031 は所在提示のみのカードで、ガス壊疽の実質は Ⅲ の SD-034 が担うという章をまたいだ分担になっており、番号付記による代替もありうる。

# kokushi が null のカードの再仕分け（NG 以外 329件）

## 概要

curriculum.kokushi が null のカード550件のうち、NG（総論）を除く329件について、各カードの主張文を読み、医学各論の出題基準項目（令和6年版、全1,482項目）と照合して仕分けた。

- **各論に付けられる：96件**（うち、番号付記でそのまま受けられる「付記可」47件／対応はあるが主張の射程が項目の一部に限られ、付記だけでは不十分な「付記は不十分」49件）
- **null が正しい：233件**

判定の考え方：全項目に最低1件のカードがある現状のため、「対応項目に既にカードがある」こと自体は null の理由にしていない。その項目について実質的に独立した内容を持つカードは「付けられる」に数えた。逆に、症候側の一般論や検査・制度の情報で、項目の疾患そのものを扱っていないものは null とした。

# レベル a 1件項目の仕分け（第Ⅲ章）

対象：医学各論 Ⅲ のレベル a でカードが1件だけの68項目。各項目の既存カードの主張を読み、「増強が要る」（重要な側面が欠け、2件目に書くべき側面を具体的に挙げられる）か「1件で十分」（その1件で項目の範囲が実質カバーされている）かを判定した。

## Ⅲ-1 皮膚（湿疹・薬疹・血管など）

| 項目 | 既存カード | 判定 | 理由／2件目の側面と出典の見込み |
|---|---|---|---|
| Ⅲ-1-A-③ 脂漏性皮膚炎 | SK-007 | 1件で十分 | 好発部位・年齢、乳児型、マラセチアの関与、臨床診断、軽〜中等症の外用治療まで揃っている |
| Ⅲ-1-A-④ 皮脂欠乏性湿疹 | SK-031 | 増強が要る | 定義と症状のあと、保湿外用軟膏の小規模臨床研究（30例）の結果だけが書かれ、治療原則として読めない。2件目は保湿・入浴と掻破対策・外用ステロイドなど一般的な管理。既存出典は単一の小規模研究のため、新規の総説・ガイドライン級資料が要りそう |
| Ⅲ-1-C-① 結節性痒疹 | SK-014 | 増強が要る | 慢性痒疹の定義とデュピルマブ等の生物学的製剤に寄った内容で、臨床像、背景疾患（腎・肝・甲状腺・悪性腫瘍など）の検索、従来治療（外用ステロイド・抗ヒスタミン薬・光線療法）が欠ける。2件目は臨床像・診断の進め方と従来治療。新規の総説・ガイドライン級資料が要りそう |
| Ⅲ-1-D-① Stevens-Johnson症候群 | SK-021 | 増強が要る | 米国入院データによる発症頻度と死亡割合・死亡予測因子のみで、疾患の中身が書かれていない。2件目は定義とSJS/TENの分類（剥離面積）、原因薬剤、臨床像、支持療法を中心とする治療原則。重症薬疹の診療ガイドライン等の新規資料が必要 |
| Ⅲ-1-D-③ 薬剤性過敏症症候群 | SK-023 | 増強が要る | DRESSと同一概念であること、ウイルス再活性化、合併症とスコアリングの提案までで、診断基準（発熱・発疹・リンパ節腫脹・血液異常・臓器障害）、主な原因薬剤（抗てんかん薬、アロプリノール等）、ステロイド治療が欠ける。2件目は診断基準・原因薬剤・治療。診断基準やガイドラインの新規資料が要りそう |
| Ⅲ-1-E-① 多形滲出性紅斑 | SK-019 | 1件で十分 | 標的病変という特徴的所見、最多の誘因であるHSV、治療方針（対症療法、再発性HSV関連型への予防投与、重い粘膜病変での入院）まで揃っている |
| Ⅲ-1-E-② 結節性紅斑 | SK-020 | 増強が要る | 定義（中隔性脂肪織炎）、原因の内訳と基礎疾患検索の重要性、自然経過まで揃うが、治療が書かれていない。2件目は安静・NSAIDsなどの対症療法と基礎疾患の治療。既存出典（総説）で足りる可能性が高い |
| Ⅲ-1-G-① 血栓性静脈炎 | SK-026 | 増強が要る | CALISTO試験（フォンダパリヌクス）の結果のみ。2件目は表在性静脈血栓症の定義・臨床像、深部静脈血栓症・肺塞栓症への進展リスクと、抗凝固療法の適応（血栓の長さや接合部からの距離など）の原則。ガイドライン級の新規資料が要りそう |
| Ⅲ-1-G-② 凍瘡 | SK-027 | 1件で十分 | 病態（血管攣縮）、臨床診断と生検所見、背景の自己免疫疾患の確認、管理（保温・禁煙・ニフェジピンとその限界）まで揃っている |

## Ⅲ-3 皮膚疾患各論（水疱症・感染症・発汗・脱毛など）

| Ⅲ-3-J-③ ひょう疽 | SD-029 | 1件で十分 | 指腹の閉鎖区画感染という病態、拍動性疼痛、虚血と波及のリスク、切開排膿＋抗菌薬という治療まで揃っている |
| Ⅲ-3-J-④ 丹毒 | SD-030 | 1件で十分 | 定義（真皮浅層・表在リンパ管）、主な原因菌、境界明瞭な隆起性発赤という臨床像、βラクタム系による治療まで揃っている |
| Ⅲ-3-J-⑤ 伝染性膿痂疹 | SD-031 | 増強が要る | 外用抗菌薬の有効性を示す系統的レビューの結果のみ。2件目は痂皮性・水疱性の臨床像と原因菌（黄色ブドウ球菌、A群溶連菌）、経口抗菌薬の適応、感染対策。臨床像側は新規資料が要りそう |
| Ⅲ-3-J-⑥ ブドウ球菌性熱傷様皮膚症候群 | SD-032 | 増強が要る | 毒素がデスモグレイン1を切断する機序、剥離レベル、診断（凍結標本）、TENとの鑑別、年齢別の死亡率まで揃うが、治療が書かれていない。2件目は抗ブドウ球菌性抗菌薬と支持療法。既存出典（総説）で足りる可能性が高い |
| Ⅲ-3-J-⑦ 壊死性筋膜炎 | SD-033 | 増強が要る | 定義、多菌性・単一菌性の区別、早期デブリードマン＋広域抗菌薬という治療の要はあるが、診断の手がかり（進行する皮膚所見、水疱・壊死、画像、LRINECなど）が欠ける。2件目は臨床所見と診断。新規のガイドライン・総説級資料が要りそう |
| Ⅲ-3-N-① 単純ヘルペス | SD-044 | 増強が要る | 「総説が疫学・病因・症状・診断・管理をまとめている」という紹介文にとどまり、内容自体が書かれていない。2件目は群集性小水疱・神経節潜伏などの臨床像と、アシクロビルの適応を含む治療。既存出典（その総説）で足りる可能性が高い |
| Ⅲ-3-N-② カポジ水痘様発疹症 | SD-045 | 増強が要る | 定義と臨床診断の特徴、後方視的解析の所見（発熱・リンパ球減少）までで、治療が欠ける。2件目はアシクロビルの早期投与と、眼合併症・二次感染などの合併症。既存出典は後方視的解析のため、治療には新規資料が要りそう |
| Ⅲ-3-N-③ 尋常性疣贅 | SD-046 | 増強が要る | HPVによる良性角化性病変で自然消退も多いことと、ガイドラインが治療選択肢をまとめていることに触れるだけ。2件目は病型を含む臨床像と、凍結療法・サリチル酸外用などの治療の具体。既存出典（BADガイドライン）で足りる可能性が高い |
| Ⅲ-3-O-① 尋常性痤瘡、酒皶様皮膚炎 | SD-047 | 1件で十分 | 痤瘡は診療ガイドラインの推奨（過酸化ベンゾイル、外用レチノイド、ドキシサイクリン、重症例へのイソトレチノイン）が段階別に詳しく、酒皶様皮膚炎もステロイド外用を契機とする病態として押さえられている |
| Ⅲ-3-P-① 円形脱毛症 | SD-048 | 増強が要る | 定義、免疫特権の喪失という病因、経過の予測しがたさ、心理的負担までで、「根治療法はない」としながら実際の治療選択肢が書かれていない。2件目はステロイド外用・局注、接触免疫療法、重症例へのJAK阻害薬などの治療。診療ガイドライン等の新規資料が要りそう |

- 対象：68項目
- **増強が要る：43項目**
- **1件で十分：25項目**

増強が要る項目の傾向：

- **Ⅲ-10（口腔・咽頭・頸部）が13項目中12項目と突出**している。この領域のカードは単一施設の症例集積や単一研究の結果だけを写したものが多く、疾患の一般像（臨床像・診断・治療原則）が欠けるパターンが繰り返し見られた（ヘルパンギーナ、急性ヘルペス性口内炎、扁桃周囲膿瘍、頸部リンパ節炎など）。
- 次に多い型は「**片側だけの欠落**」で、臨床像は詳しいが治療が皆無（Behçet病の眼病変、カポジ水痘様発疹症、多汗症、円形脱毛症）、あるいは治療・エビデンスはあるが臨床像・診断がない（伝染性膿痂疹、壊死性筋膜炎、SJSのように疫学のみのもの）。この型は2件目の範囲が明確で増強しやすい。
- **眼（Ⅲ-4〜Ⅲ-6）と喉頭（Ⅲ-9-B）は比較的揃っており**、増強が要るのは眼3項目・鼻喉頭1項目にとどまる。弱視・斜視・麦粒腫・霰粒腫・クループ・急性喉頭蓋炎などは、定義・臨床像・診断・治療が1件に compact に収まっている。
- 出典の見込みとしては、「増強が要る」43項目のうち約4分の1は既存カードの出典（ガイドラインや総説）で2件目もまかなえる可能性があり、残りは新規の一次資料・ガイドラインの調査が必要な見込みである。

# レベル a 1件項目の仕分け（残り5章：Ⅴ・Ⅹ・Ⅵ・Ⅺ・Ⅱ）

対象37項目について、番号が付いた1件のカードを読み、隣接項目・他章のカードが側面を担っていないかも確認したうえで仕分けた。

判定の凡例：**増強が要る**＝定義・分類／診断／治療／予後などの重要な側面が欠け、2件目に書くべき側面を具体的に挙げられるもの。**1件で十分**＝その1件（必要に応じ隣接・他章のカードとの分担）で項目の範囲が実質カバーされるもの。

## 数え方・兼用に関する注記

- **SZ-001 の兼用**：Ⅱ-2-B-①（妄想型）・②（破瓜型）・③（緊張型）の3項目に同じ1件が付いており、数え方のうえでは各項目1件だが、実体は「3項目で1件」。妄想型（B-①）は今回の対象外だが事情は同じ。
- **MP-025 の兼用**：Ⅴ-6-D-②（心囊液貯留）と Ⅴ-6-E（心タンポナーデ）の2項目を1件が担う。
- **AB-076 の兼用**：Ⅵ-9-B-①（細菌性腹膜炎）・Ⅵ-10-C-①（急性腹膜炎）・Ⅵ-10-E-①（消化管穿孔）の3項目兼用で、内容は腹膜炎の分類のみ。
- **双方向の番号付記**：BP-065 は Ⅵ-6-C-② と Ⅵ-7-C-②（胆囊癌、胆管癌）、OS-007 は Ⅺ-2-E-② と Ⅸ-8-H-②（痛風、偽痛風）にまたがる。
- **他章のカードが実体を担う項目**：Ⅵ-6-E-③ は ⅩⅢ の TX-005、Ⅺ-1-B-③（花粉症）は Ⅲ の NL 群、Ⅺ-1-B-① は Ⅲ の EY-010、Ⅺ-1-B-⑥ は Ⅲ の SK-005・006 が実質を分担している。判定はこの分担を踏まえた。

### 傾向

- Ⅴ・Ⅵ・Ⅱでは対象の全項目が「増強が要る」になった。共通する型は3つある。第1に、ガイドラインの推奨を1点だけ写したカード（AR 群のペースメーカー・アブレーション適応、心房粗動）で、定義・分類・心電図といった土台が欠ける型。第2に、単一の試験・メタ解析・登録データの結果だけのカード（IH-024 の DIAD 試験、HT-016 の CPAP メタ解析、ES-084 のドイツ入院データ、TH-008 の単一地域コホート）で一般像が欠ける型。第3に、複数項目の兼用カードが分類や総論だけを担い、項目固有の側面が残る型（SZ-001、AB-076、MP-025、BP-065）。
- Ⅴでは AR（不整脈）の5項目がそろって「分類・心電図の土台がない推奨のみのカード」で、同じガイドラインから2件目を作れるため、出典の新規開拓なしに増強できる塊になっている。
- Ⅺは対照的で、5項目中4項目が「十分」。アレルギー領域は Ⅲ（眼・鼻・皮膚）のカード群と分担が効いており、番号付記の段階で実質カバーが成立している。残る OS-007（偽痛風）だけが、分類基準のみで臨床像・治療がない。
- Ⅹは半々。HHS（DM-023）のように診断基準と治療プロトコルまで1件に収めたカードと、EN-026・027 のように隣接カード（EN-025・040）と分担が効いた項目は「十分」。一方で DM-024（乳酸アシドーシス）は特定の病態（メトホルミン関連）への特化、DM-025（糖尿病腎症）は国際的な管理論中心で日本の病期分類がない、という偏りが残る。
- 増強が要る28項目のうち、既存カードの出典（同じガイドライン）で2件目を作れる見込みのものが約半数（AR 群5件、MP 2件、BP-006、IE-008、TH 群など）。新規の一次資料の洗い出しが要るのは、IH-024、HT-016、HT-009、ES-084、IN-088、ES-076、TX-005、DM-024、DM-025、OS-007、緊張型・適応障害など。

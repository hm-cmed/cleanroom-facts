# kokushi が null の NG カード（221件）の再仕分け結果（2026-10-31）

医学総論の NG カード221件について、各カードの主張文を読み、医学各論の出題基準項目（令和6年版、1,482項目）に実質対応するものと、総論として null が正しいものに仕分けた。

## 集計

- **各論に付けられる：71件**（対応先は延べ72件。NG-044 は2項目にまたがる）
- **総論として null が正しい：150件**

対応先は4項目に集中した。過敏性腸症候群と便秘症は、Rome IV・Rome V の基準カードと日本のガイドライン（IBS診療ガイドライン2020、便通異常症診療ガイドライン2023）の治療カードが厚く、項目への付記で各論側の厚みが増す。一方、機能性消化管疾患の大半（機能性食道疾患、機能性下痢、機能性腹部膨満、中枢介在性腹痛症候群、げっぷ障害・反芻症候群、便失禁、胃不全麻痺など）は出題基準に独立した項目がなく、null が正しい。

判定の目安：主張の主題がその項目の疾患そのものであれば「付けられる」とした。鑑別疾患として言及されるだけのもの、疾患群全体の概念・分類・疫学にとどまるものは null とした。境界的なものは対応先候補に挙げたうえで「要判断」と注記した。

## 備考

- 番号付記の実施可否はこの仕分けの範囲外で、登録側の判断による。とくに「要判断」としたもの（オピオイド誘発性便秘の各カード、リファキシミン、腹部片頭痛の各カード）は、項目の射程に入るかの確認が要る。
- 小児のカード（小児IBS、小児の機能性便秘）を成人の項目（Ⅵ-3-A-①・②）に付ける案は、項目名が年齢を限定していないことを根拠にした。小児の機能性消化管疾患に独立の項目はなく、その他の小児カードは null とした。
- NG-044（リナクロチド）は便秘型IBSと慢性便秘症の両方に適応をもつ薬剤のカードで、両項目への付記が考えられる唯一の重複候補である。

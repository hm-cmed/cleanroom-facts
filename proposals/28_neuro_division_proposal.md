- 接頭辞はすべて2文字で、既存の接頭辞（§5）とは重ならないことを確認した。
- SRC の範囲は、第Ⅲ章までの割り当て（SRC-1520まで）と StatPearls やり直し分（SRC-1521〜1560）の続きとして 1561 から始めた。既存の番号との重なりがないことはレポジトリ側で再確認してほしい。
- 大項目11「その他の重要な小児領域の疾患」（12項目）は、独立した接頭辞を作らず、主題ごとに振り分けた：脊髄性筋萎縮症・先天性筋疾患 → NM、けいれん性疾患・てんかん → EP、小頭症・脳性麻痺 → AN、SSPE → NI。理由は、項目数が少なく（12項目）、年齢ではなく疾患の主題で探す使い方の方が境界管理がしやすいためである。独立させる場合は接頭辞の候補が要るが、PN（末梢神経）と紛らわしい NP は避けたい。登録時に決めてほしい（§5 の未確定事項）。
- 章の中での重複項目が2組ある。脳血管性認知症（Ⅸ-1-E-③ と Ⅸ-4-A-②）と欠神発作（Ⅸ-6-A-② と Ⅸ-11-C-②）で、どちらも片方だけでカードを作り、もう片方は「そちらで受ける」とした（§3 の各表と §4）。項目数の228は重複を含めた原典どおりの数である。
- Ⅸ-5-C-① 三叉神経痛は、Ⅲ 章の OT（第26回）で作成済みのため、Ⅸ では作らない（§4）。
- NX は CX（循環器）・RX（呼吸器）・KX（腎）・EX（内分泌）・HX（皮膚・頭頸部）と同じ横断の置き方で、対象は神経学的診察と局所診断、意識障害・失神の評価、しびれ・筋力低下・歩行障害の評価、髄液検査、神経伝導検査・針筋電図、脳波、頭部画像の読み方、高次脳機能の評価、リハビリテーションの総論などを想定する。
- 接頭辞の付け方：CV は脳血管、BT は脳腫瘍、NI は神経感染症・炎症、ND は神経変性、PN は末梢神経、NM は神経筋、EP はてんかん・発作性、SP は脊椎・脊髄、BD は骨疾患、OS は運動器（整形外科）、BO は骨・軟部腫瘍、TJ は外傷、AN は形成異常、NX は横断、という読みを意図した。NI は IN（消化器の炎症性腸疾患系）と字面が近いので、気になる場合は NC などへの変更も可能である（ただし NC は他の章で使う可能性がある）。PD は Ⅹ 章・Ⅲ 章の前例どおり、将来の医学各論 Ⅰ のために空けておく。

## 2. 読み取りで確信の持てない箇所（突き合わせで見てほしい）

1. Ⅸ-9-C 転移性骨腫瘍：中項目 C 自体が単独の項目になっており、小項目番号（①）が付いていない（PDF 35ページで確認した）。Ⅲ-2-D リンパ管腫と同じ形で、本案の総数228にはこの1件を含めている。数え方の確定をお願いしたい。
2. 判読不能になった漢字（PDF のテキスト層で欠落）：Ⅸ-1-C の「梗」（「脳塞」「ラクナ塞」と現れ、脳梗塞・脳塞栓症・ラクナ梗塞と読んだ）、Ⅸ-5-C-① 三叉神経痛の「叉」、Ⅸ-7-A-⑨ 脊柱靱帯骨化症・Ⅸ-10-D-① 捻挫<靱帯損傷>・Ⅸ-10-G-⑥ 膝靱帯損傷の「靱」。いずれも文脈からの読みで、原典の画像で確認してほしい。
3. レベル分類の半角表記：Ⅸ-4-G-① 筋萎縮性側索硬化症<ALS> は半角の "a"、Ⅸ-5-D-③ Lambert-Eaton筋無力症候群は半角の "b"、Ⅸ-10-I 水頭症の3項目は半角の b・b・c、Ⅸ-11-C-② 欠神発作は半角の "a" と現れた。レベルとしては a・b・c と読んだが、全角・半角の混在自体が原典の表記なのか確認してほしい（Ⅹ 章・Ⅲ 章の前例と同じ注意点）。
4. Ⅸ-1-C の備考「tissue plasminogen activator<t-PA>」の帰属：③ ラクナ梗塞と ④ 一過性脳虚血発作の間に現れ、本案では ④ の備考として転記したが、中項目 C 全体への備考の可能性がある。同様に、1-C の備考（無症候性脳梗塞、Wallenberg症候群、Weber症候群）の個別の帰属も行の対応がずれている可能性があり、本案では ①・② に付けた。
5. Ⅸ-1-E の備考「脳卒中後の急性期・回復期・維持期リハビリテーション」は ①〜③ をまたぐ位置にあり、どの小項目に付く備考か確定できなかった。本案では ① 偽性球麻痺の備考として転記した。
6. Ⅸ-3-D の中項目名「急性脳炎、急性脳症」と備考「インフルエンザ脳症」の帰属：備考は ① 急性散在性脳脊髄炎の行に現れるが、中項目全体への備考の可能性がある。
7. 2疾患を1項目に併記しているものの数え方：Ⅸ-5-A-②（Guillain-Barré症候群と慢性炎症性脱髄性多発根ニューロパチー）、Ⅸ-10-A-⑤（急性硬膜下血腫と慢性硬膜下血腫）、Ⅸ-5-D-②（皮膚筋炎と多発性筋炎）、Ⅸ-8-H-②（痛風と偽痛風）、Ⅸ-8-I・Ⅸ-10-D-③ など。本案では原典の番号どおり各1項目として数えた。
8. 章の中の重複記載（§1）：脳血管性認知症（Ⅸ-1-E-③／Ⅸ-4-A-②）と欠神発作（Ⅸ-6-A-②／Ⅸ-11-C-②）。原典で本当に2か所に載っていることの確認と、片方に寄せる割り当ての承認をお願いしたい。
9. Ⅸ-11-B-② の項目名「先天性筋強直性ジストロフィー」は行またぎで分かれて現れた。文言の確定をお願いしたい。
10. Ⅸ-7-A-⑧ 後弯症<円背・亀背>、Ⅸ-10-J-② 二分頭蓋、脳瘤、Ⅸ-3-E-② の備考「結核性脊椎炎<脊椎カリエス>」の表記。
11. Ⅸ-10-A-③ の項目名は「びまん性軸索損傷」と読んだ（「びまん性軸索損傷」が正式で、テキスト層では「びまん性軸索損傷」と切れて現れる箇所がある）。
12. 大項目8の中項目 C は「手の疾患」で小項目は2つ（Dupuytren拘縮、強剛母指）だけだった。読み落としがないか確認してほしい。

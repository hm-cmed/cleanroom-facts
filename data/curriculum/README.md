- 事実票の `curriculum.core_curriculum` には、表示用の `index` と不変の `id` を併記する（例：`PS-02-08-05 (id: JkxnuRY)`）。原データの README は、分析・システムでは `id` を使うよう推奨している。
- 原データの `LICENSE` は、英文では厚生労働省の利用規約、和文では文部科学省の利用規約を挙げている。README と和文の記載に従い、文部科学省の利用規約によるものとして扱う（人間の確認事項）。
- 原データ（CSV）には第4層までしかない。パイロット版で使っていた `PS-02-08-05-2` のような第5層の番号は存在しないため、第4層と別表2-7の項目で対応づける。

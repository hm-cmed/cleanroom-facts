# 抗MRSA薬教育AI研究 Project引継ぎファイル
Version 1.0  
作成日: 2026-11-08

## 1. 研究概要
敗血症・MRSA感染症の架空症例を用いて、医師・薬剤師が抗MRSA薬の開始判断、薬剤選択、投与設計、TDM、再評価、デエスカレーションを学習する教育用AI／Webアプリを開発する。

本ツールは実患者の診断・処方・投与量決定を目的としない。教育専用であり、一般公開を想定する。

## 2. 想定利用者
- 医師
- 薬剤師
- その他の医療職・医療系学生

初回に以下を設定する。
- 職種
- 主な職場（大学病院、一般病院、中小規模病院等）
- 経験レベル
- 学習コース
- 練習モード／OSCEモード

利用者の職種・経験に応じて、提示情報、シナリオ難易度、ヒント、フィードバックを調整する。

## 3. 学習コース
1. 抗MRSA薬の開始・薬剤選択
2. VCMの初期投与・TDM設計
3. 薬剤選択と投与設計の統合
4. 専門医の選択哲学
5. 再評価・デエスカレーション

## 4. 専門医アンケートから得られた判断モデル
現時点の解析では、専門医が重視する因子として以下が高順位。
- 想定感染臓器
- 過去の分離菌歴
- 想定菌種
- 重症度
- 腎機能（CCr等）

教育上は、以下の3軸として体験させる。
1. 有効性：感染臓器・組織移行性・殺菌力
2. 安全性：腎機能、血球減少、CK上昇等
3. 実行可能性・出口戦略：TDM体制、経口スイッチ、外来治療等

重要：専門医アンケート由来の判断は「ガイドライン推奨」と表示しない。表示ラベルは「専門医アンケートから得られた判断傾向」とする。

## 5. Knowledge設計の基本原則
医学的正解を生成AIが自由生成しない。

### 情報源の階層
Level 1: 診療ガイドライン・公的文書  
Level 2: 査読済み学術文献  
Level 3: 専門医アンケート・専門家合意  
Level 4: 施設固有情報  
Level 5: 教育上の設計

### AIが担うもの
- 承認済み知識の検索
- 学習者に合わせた説明
- 質問、ヒント、振り返り
- 固定ルーブリックに基づく文章化

### AIに担わせないもの
- 未承認の医学的正解の生成
- 出典の創作
- 実患者への処方提案
- 検証されていない投与量計算

## 6. 著作権方針
ガイドラインからは原則として医学的事実・数値・条件・推奨の意味を抽出し、独自表現でEvidence card化する。

原則としてそのまま複製しない。
- 長文
- 表全体
- 図
- フローチャート
- 独自の見出し構成
- ロゴ・レイアウト

原文表現を示す必要がある場合のみ必要最小限を引用し、出典・版・章/CQ・頁・引用目的を記録する。

一般公開版では、原PDFそのものではなく、原則として独自に作成したEvidence cardをKnowledgeとして使用する。

## 7. 安全境界
本ツールは教育用であり、実患者への以下の用途を禁止する。
- 診断
- 抗MRSA薬選択
- 用量・投与間隔・投与期間の決定
- AUC/TDM判断
- 処方・注射指示
- 緊急時の意思決定代行

実患者入力が疑われる場合は、具体的薬剤・用量・AUCを返さず、所属施設の感染症専門医、AST、担当薬剤師、添付文書、施設プロトコル、検証済みTDMソフトウェアの確認を促す。

患者識別情報の入力は禁止する。

## 8. 初期版の適用範囲外候補
初期版では以下を別モジュールまたは適用範囲外とする。
- 新生児・小児
- 妊産婦
- 間歇的血液透析
- CRRT
- ECMO
- 重症熱傷
- 高度肥満
- 急速に変動する腎機能
- 複雑な薬物相互作用
- 実患者の実測値を用いたベイズ推定

## 9. 練習モード
- 症例情報を段階的に提示
- 初学者には選択肢・ヒント
- 中級者以上は自由記載中心
- 誤答時は一度再考させる
- 最後に根拠、代替案、専門医判断傾向を分離して提示

## 10. OSCEモード
- 検証済み固定症例のみ使用
- 試験中は正誤・ヒント・出典を出さない
- 終了後に固定ルーブリックで採点
- クリティカルエラーは総点と別表示
- 採点基準はセッション中に変更しない

想定評価項目：
- 情報収集
- 重症度評価
- MRSAカバー開始判断
- 薬剤選択
- 投与設計
- TDM・モニタリング
- 感染源コントロール
- 培養結果後の再評価
- 患者・チームへの説明

# 著作権に配慮した情報抽出・利用規程 v1.0

## 1. 基本方針
診療ガイドライン、論文、添付文書等から、医学的事実、数値、条件、推奨の意味を抽出し、
教育ツール独自の構成と表現でKnowledgeを作成する。

## 2. 原則として抽出可能な内容
- 薬剤名
- 適応・非適応に関する事実
- 対象集団
- 用量、投与間隔、目標値等の数値
- 推奨の強さ、エビデンスの確実性
- 比較結果
- 適用条件、除外条件
- 監視すべき有害事象
- 研究デザイン、対象数、主要結果

ただし、情報の正確性と出典の追跡可能性を保持する。

## 3. 原則としてそのまま複製しないもの
- 長い文章
- 表全体
- 図
- フローチャート
- 見出し構成
- 独自の分類体系
- 症例文
- 解説文
- ロゴ、装飾、レイアウト

## 4. 要約・言い換え
- 一つの原文を語尾だけ変える方法は避ける。
- 複数の情報を、教育目的に沿って再構成する。
- 原文の順序、表の列構成、図の分岐構造をそのまま模倣しない。
- Knowledge内では`fact_paraphrase`を標準とする。

## 5. 引用
原文の表現自体を示す必要がある場合のみ、必要最小限を引用する。
引用時には以下を記録する。
- 引用箇所
- 出典
- 版
- 章またはCQ
- 頁
- 引用目的
- 引用部分と独自本文の区別

## 6. 公開AIへの登録
著作物全文を公開AIのKnowledgeへ登録する場合は、
利用規約、公開範囲、権利者の方針、必要な許諾を別途確認する。
公開版には、原則として独自に作成したEvidence cardを登録する。

## 7. 作業記録
各Evidence cardについて、以下を保存する。
- 参照した情報源
- 抽出した事実
- 独自表現を作成した日
- 作成者
- 確認者
- 原文引用の有無
- 公開可否

# 抗MRSA薬教育AI Knowledge／ソース固定パッケージ v1.0

## 目的
このパッケージは、抗MRSA薬の選択・投与設計を学ぶ教育用AI／Webアプリのうち、
今後のガイドライン改訂や薬剤情報更新の影響を受けにくい「構造・運用原則・データ形式」を先に固定するためのものです。

## この版で固定するもの
1. 情報源の優先順位と版管理方法
2. 医学的事実と専門家判断の区別
3. Evidence cardの共通形式
4. 著作権に配慮した抽出・要約・引用ルール
5. 専門医アンケートデータの記録形式
6. 教育シナリオの共通形式
7. 教育用ツールとしての安全境界

## この版では固定しないもの
以下はガイドライン改訂、添付文書改訂、専門家レビュー、実証研究により変更され得るため、
別ファイルで版管理します。

- 個々の薬剤の推奨順位
- 用量、投与間隔、TDM目標値
- 腎機能別・特殊病態別の投与設計
- 正解アルゴリズム
- OSCE配点
- 免責条項の最終的な法的表現
- 一般公開時のプライバシーポリシー

## 基本原則
- 生成AIは、医学的正解を自由生成しません。
- 医学的正解は、承認済みEvidence card、決定ルール、検証済み計算機能から取得します。
- ガイドライン由来の内容と専門医アンケート由来の内容を混同しません。
- 実患者の診療支援には使用しません。
- すべての医学的内容に、出典、版、確認日、レビュー状態を保持します。

- 本パッケージの版: 1.0
- スキーマ変更時: メジャーまたはマイナー版を更新
- 医学的内容だけの更新: 各データファイル側の版を更新
